# M98 — Состояние атакующей сессии

База: архив `game1_diag_2026-10-16_09-01-01.zip` → M96 → M97. Только рефакторинг.

## Ответственность

- `AttackSessionStore` — единственный владелец кратковременного состояния атаки на игрока: cooldown, serial/id, окно HitStart/HitEnd, множество уже задетых целей, единственная headshot-цель, состояние sweep и флаг отскока. Нет RemoteEvents, таймеров, физики или побочных действий.
- `AttackService` — проверяет входящие пакеты и анимационные профили, создаёт/заканчивает сессии, управляет публикацией Roblox-атрибутов и обработкой отскока после контакта.
- `AttackDamageResolver` (M97) — рассчитывает попадания, headshot и повреждения; не владеет жизненным циклом сессии.
- `AttackAimGeometry` (M97) — чистая геометрия направления.

## Совместимость

Сохраняются имена RemoteEvent, атрибуты, формулы, окно HitStart/HitEnd, порядок collision→bounce→damage и ограничение одного попадания в цель за сессию. При освобождении сессии сравниваются Model, serial и clientAttackId, чтобы устаревший таймер не мог очистить новую сессию после респавна.

Патч не меняет NPC/Monster AI, Pathfinding или WeaponEnvironmentCollision. Нет новых циклов, сохранений и миграций.

## Проверка

`python system/verify/verify.py`
`python -W error::ResourceWarning -m unittest discover -s system/verify -p test_*.py -q`

Статические тесты не заменяют проверку Studio Play: быстрые серии ударов, смерть/респавн во время атаки, несколько целей, отскок от зарегистрированного объекта в мирном состоянии, подавление отскока при преследовании и плавность HitStart/HitEnd.
