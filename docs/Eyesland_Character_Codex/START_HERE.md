# Eyesland Base Character — пакет для Codex

Этот пакет содержит **полное ТЗ и исходные референсы**, но **не готовую 3D-модель**. Codex создаст модель через уже подключённый Blender MCP.

## Что внутри

- `AGENTS.md` — требования к поведению агента, которые Codex может учитывать при открытии этой папки как проекта.
- `docs/TECH_SPEC.md` — основное подробное ТЗ (внешность, 15 мешей, 33 кости, швы, веса, UV, крепления, тесты, экспорт).
- `contract/rig_contract.json` — фиксированные имена и связи костей, список meshes, математика симметрии и базовые допуски.
- `contract/equipment_regions.json` — маппинг слотов предметов на заменяемые регионы и отдельные крепления.
- `contract/seam_contract_template.json` — перечень всех требуемых швов; агент должен заполнить его реальными геометрическими профилями.
- `refs/01_PRIMARY_CHARACTER_CONCEPT.png` — главный художественный референс (созданный ранее лист персонажа).
- `refs/02_WORLD_STYLE_CONTEXT.png` — исходный скриншот с интерфейсом и окружением Eyesland.
- `refs/03_FRONT_SIDE_BACK_DETAIL.png` — более крупно фронт/бок/спина.
- `refs/04_GAME_INVENTORY_CONTEXT.png`, `refs/05_IN_GAME_CHARACTER_BACK.png` — дополнительные визуальные контексты.
- `deliverables/` — целевая папка для создаваемых Codex файлов.

## Как запускать

1. Распаковать ZIP в свой рабочий каталог, например `E:\\RobloxProjects\\Eyesland_Character_Codex`.
2. Открыть эту папку в Codex (`cd ...`; `codex`). Открыть Blender и включить уже настроенный Blender MCP.
3. Передать Codex этот промпт:

> Прочитай AGENTS.md, docs/TECH_SPEC.md, все JSON из contract/ и просмотри refs/01_PRIMARY_CHARACTER_CONCEPT.png. Полностью выполни техническое задание, создавая **реальную редактируемую модель, риг и skinned meshes в Blender через доступный Blender MCP**. Работа должна заканчиваться сохранёнными .blend и .fbx и заполненным QA_REPORT, а не планом или заглушками. Это полностью кастомный Eyesland-риг, не ограничивай архитектуру Roblox R15. Обязательно сделай отдельно shield_mount.L/R на предплечьях, weapon_grip.L/R на кистях, крепления наплечников/плаща/волос и зеркальную симметрию. Контролируй швы при смене мешей. По завершении перечисли проверенные файлы, пройденные тесты и проблемы. **Не создавай волосы, плащ и готовую броню, кроме скрытых тестовых муляжей.** Не изменяй существующие проекты и не заявляй о тестах, которые не проводил.

## Нужны ли дополнительные MCP/skills?

**Нет, для этой работы хватает подключённого Blender MCP и встроенного Python (`bpy`).** Проверь, что Codex видит инструменты управления Blender (проверка сцены, выполнение Python, сохранение `.blend`, при наличии viewport preview). Если работающий сервер уже установлен, ничего менять не надо.

Опционально полезен доступ к свежей официальной документации Blender и Roblox (включая Context7), но он не заменяет Blender MCP. **Не устанавливай Rigify/Auto-Rig Pro/генераторы персонажей только ради этого ТЗ.** Rigify может усложнить экспортный skeleton contract; лучше компактный собственный rig.

**Важно:** результат сборки придётся открыть у себя и проверить внутри Roblox Studio отдельно. Реальность экспорта нельзя обещать только на основании Blender viewport.
