# M94 — отскок оружия только в мирном состоянии (после проверки контакта)

База: M94 после удаления `game1_hf_m94_weapon_environment_combat_passthrough.patch`.

## Правило

Стандартная анимированная система `HitStart → HitEnd` и `WeaponEnvironmentCollision.Query` не меняются: оружие может физически проходить сквозь декорации в любое время. При обнаруженном контакте Weapon Attack Volume с зарегистрированной неразрушаемой декорацией сервер вызывает WeaponBounce **только**, если у Character `InCombat ~= true` и нет активных преследователей Monster/NPC.

В бою либо при наличии преследователя контакт не вызывает WeaponBounce. Само обнаружение контакта не отключается: условие поставлено **после** `WeaponEnvironmentCollision.Query`, в отличие от предыдущего неудачного хотфикса. Урон по существам, Headshot и окно атаки не меняются.

### Границы модулей

- `WeaponEnvironmentCollision`: прежний поиск контактов, без изменений.
- `AttackService`: после контакта проверяет боевое состояние и количество преследователей, после чего вызывает либо не вызывает `triggerWeaponBounce`. При `AttackConfig.DebugLogs` первый подавленный контакт за атаку регистрируется строкой `[game1][weapon-bounce] suppressed ...`.
- `HostilePursuitRegistry`: общий серверный реестр преследований Monster/NPC, отдельные записи для каждого врага; очистка при смене цели, смерти и удалении врага или цели.
- Monster/NPC AI сообщают реестру только о переходах целей; игровые состояния и логика преследования не изменены.

Нет миграций SQLite, новых RemoteEvent, изменений в WeaponEquipService, клиентах, моделях и Asset Manager.

## Проверка в Studio

1. Нет врагов, `InCombat = false`: удар зарегистрированного неразрушаемого объекта в фазе `HitStart → HitEnd` должен вызвать прежний отскок.
2. Погоня до первого полученного урона: отскока нет.
3. `InCombat = true` без погони: отскока нет.
4. Несколько преследователей: после потери последнего и завершения `InCombat` снова есть отскок.
5. После смерти/удаления преследователя отскок не должен оставаться заблокированным.

Если мирный отскок отсутствует после **отката предыдущего патча, до установки нового**, значит источник проблемы находится вне новой боевой политики; не следует продолжать установку дополнительных изменений без проверки уже существующего механизма пересечений.

Статические тесты не заменяют проверку Physics/Animation в Roblox Studio.
