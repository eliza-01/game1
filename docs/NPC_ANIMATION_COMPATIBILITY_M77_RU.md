# M77 · NPC Animation Compatibility / Unarmed

## Контракт

* `weaponSet` — исходная классификация анимации и координата файла/публикации (`base`, `unarmed`, `1hs`, `2hs`, `bow`). Не используется вместо совместимости.
* `compatibleWith` — список **контекстов экипировки**, которые разрешают воспроизведение. `base` не является контекстом экипировки. В M77 контексты: `unarmed`, `1hs`, `2hs`, `bow`.
* `NULL` в `monster_animation_bindings.compatible_sets` означает *вычислять исходную совместимость по типу*: `base` → **все**, остальные → собственный тип. Это позволяет безопасно мигрировать старые базы; `[]` означает сознательный запрет во всех контекстах.
* Каждое редактирование Options атомарно сохраняет `compatible_sets`, `weight`, `disarm` и не меняет Clip ID, Roblox Asset ID или историю публикации. Повторное сканирование сохраняет эти поля.
* Rename/Migrate меняет исходный тип и метаданные файла, но сохраняет явное `compatible_sets`. Если ручной совместимости не было — вычисляется новый default.
* `Disarm` разрешён только для `idle_special`: временно скрывает оружие. Ни реальная экипировка, ни условия совместимости из-за Disarm не меняются.

## Runtime

`NpcEquipmentService` выводит контекст из реально экипированного оружия. При отсутствии оружия это `unarmed`, а не `1hs`. Серверный `NpcCombatAIService` продолжает наносить рукопашный урон через свой `DamageService.Apply` и проверку дистанции: оружейный volume для NPC не используется. Анимация `unarmed_attack_01` необязательна для самого факта удара, но, если опубликована и совместима, проигрывается как обычный цикл атаки.

`AnimationCompatibility` — общий чистый семантический резолвер, а `NpcAnimationTracks` — адаптер NPC, фильтрующий опубликованные записи. Для обычной стойки приоритет свой тип → `base` → другой совместимый тип. В одном weighted pool для `idle_special` участвуют **все** совместимые специальные варианты независимо от исходного типа. `death` предпочитает совместимый `base_death`. Нет hardcode по NPC slug.

Реестр анимаций Character сейчас не переводится автоматически на NPC-схему: это отдельный этап миграции типов персонажей, не нужно нарушать существующие опубликованные анимации ради M77.

## UI / проверка

Asset Manager → NPC Animations → **options** рядом с записью. Кнопка **select all** выбирает все типы экипировки, при повторном нажатии **clear all** снимает их все. **Apply** сохраняет совместимости, `Weight` и `Disarm` одной транзакцией; повторный вход в Options отражает сохранённые значения. Изменения начнут действовать в новой игровой сессии после обновления генерируемого NPC Animation Registry через Rojo.
