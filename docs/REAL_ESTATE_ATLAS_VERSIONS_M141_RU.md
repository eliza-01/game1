# M141 — версии текстурных атласов Real Estate

## Контракт имени

`<atlas_key>_<width>x<height>_atlas.png` остаётся базовым контрактом общего Atlas Registry.
В Real Estate `atlas_key` может оканчиваться на `_01`, `_02`, ... : последний
числовой сегмент — версия **атласа**, а не разрешение.

Пример: `restoration_01_2048x2048_atlas.png`,
`restoration_01_1024x1024_atlas.png`, `restoration_02_2048x2048_atlas.png`.

- `restoration_01` и `restoration_02` — независимые семейства Atlas Registry,
  каждое со своим набором разрешений и собственными Image Asset IDs.
- Повторный выбор опубликованного `atlas:variantId` **не** загружает Image Asset.
- Изменение пикселей **внутри той же версии и разрешения** идёт через
  Republish (Roblox выдаёт новый ID; старый остаётся в истории).
- Создание версии `_02` **не** заменяет `_01` и не переключает потребителей
  автоматически; пользователь выбирает её явно.
- `atlas_key` хранится без перекодировки: текущие ID, пути, хеши и связи не мигрируют.
- У старых Location Assets имя без версии продолжает считаться допустимым.

## UI

- В Published Houses отображается текущая версия атласа (`v01` и т. п.).
- Если у семейства меша зарегистрировано несколько версий, появляется
  `Version / resolution` с вариантами, упорядоченными по версии и разрешению.
- Непубликовавшиеся варианты показаны, но выбрать их нельзя.
- Точки для разрешений по-прежнему показывают только **одну** текущую версию.
- В Uploaded Atlases режим `related` включает соседние версии семейства,
  если выбранный дом использует это семейство.
- Для `estate:` reuse имя и предупреждение о стандарте определяются по
  эффективной текстуре владельца, не по пустой локальной записи ссылки.

## Границы изменений

Real Estate — адаптер версии/выбора; каталог и публикации остаются общими
`AtlasRegistry`. Изменения не требуют SQL-миграции, FBX-републикации,
переустановки Studio-плагина или Roblox Image upload. Выбор версии —
обычный Studio Sync привязки, включая `pending_studio_sync`.

**Особенность имён домов:** идентификатор дома `house_level4_01` также уже
содержит `01`. Для выбора между версиями важно использовать именно
опубликованный вариант из Atlas Registry; система не меняет дом или меш по
совпадению имени и не выполняет автоматического переназначения ID.
