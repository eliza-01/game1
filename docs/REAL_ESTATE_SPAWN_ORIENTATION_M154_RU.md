# M154 · Spawn sockets: Tail → Head

По результатам проверки Studio Play договорённость об ориентации авторской кости уточнена:

- У Blender Bone **+Y** направлена от **Head к Tail**.
- **Направление взгляда персонажа: Tail → Head**, то есть **−Y**.
- После импорта в Roblox для `Bone` берём `-socketFrame.UpVector`, затем
  проецируем направление на XZ и строим вертикальный `CFrame`.
- У обычного `Attachment` остаётся прежний контракт: `LookVector` (−Z).
- Позиция спавна, подъём на 3 studs, серверная проверка, RootCollider,
  ControllerManager, двери и геометрия не изменяются.

## Проверка

1. Открыть Studio Play → HS → TP на `house_floor_01_spawn_01_socket`.
2. Персонаж должен оставаться вертикальным, а взгляд направлен от Tail к Head.
3. Проверить остальные spawn-сокеты и вращение камеры после TP.

В M153 использовалось противоположное направление Head → Tail.
M154 исправляет только знак направления для `Bone`.
