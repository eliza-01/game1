# Idle на существующем лице · 31 октября 2026

**Idle включён без новых мешей и без публикации новых ассетов.** Объединённый `eyes_01` не препятствует общему взгляду и синхронному морганию. Независимые левый/правый MeshParts удобны для односторонних изменений формы; они не являются условием запуска idle.

`CombinedFacePresentation` обслуживает текущий eyes_01 и существующие face_eye_ctrl_l/r на опубликованном rig 1. Используется одна локальная статическая копия того же MeshPart вне skinned Model; исходник скрывается только локально, не меняет размера/геометрии/весов. Копия следует face_head и текущему смещению двух управляющих костей. Общее закрытие обоих глаз выполняется размером копии; дополнительных костей/спрайтов нет. При освобождении оригинальная видимость и transforms костей восстанавливаются.

`FaceIdleDefaults` получен из подготовленного Blender face_idle. Длительность — 479/30 с; четыре blink с кадров 79/194/325/441, по 10 кадров. Взгляд отсэмплирован по 480 кадрам и сокращён до 53 точек с допуском 0.00015 расстояния между глазами. Координаты нормированы и заданы в системе face_head. Это программное воспроизведение исходного idle, не опубликованный AnimationTrack. Body animation не перезапускает часы лица. Смена эмоции/respawn сбрасывают временное состояние.

Семантический native emotions_idle для rig 2 остаётся подготовленным/LOCAL_ONLY. Пока совместимого проигрываемого лицевого клипа нет, существующая комбинированная раскладка использует idle default. Совместимый native-клип имеет приоритет. Адаптер следует удалить при окончательном переходе этого компонента на независимые части; независимые состояния/варианты формы не объявляются готовыми этим исправлением.

Исходные данные: `assets/authoring/animations/human_male/idle_runtime_source.json`. Воспроизводимая подготовка: открыть human_male_face_bones.blend headless и выполнить `system/blender-extensions/tools/export_idle_defaults.py`; затем обычным Python выполнить `system/blender-extensions/tools/build_idle_defaults.py`. Скрипты не публикуют ассеты и не сохраняют изменения .blend.

Проверено на настоящем human_male в Studio Play: высота глаз изменялась с 0.215769 до 0.020002 stud, смещение управляющих костей за интервал проверки достигло 0.068865 stud; глаза закрывались и возвращались в исходную форму. Отдельный fixture проверяет цикл, движение костей, независимость от body animation, закрытие и восстановление исходника. verify.py прошёл; полный набор 753 теста сохраняет единственную прежнюю ошибку oldPreview атласа и один skip.

Рабочая сборка/rig Asset ID сохранены. Камера для визуальной проверки была временной и восстановлена. Два примитива предыдущего теста сохранены в ServerStorage.codex_face_test_archive_20261031, без удаления.
