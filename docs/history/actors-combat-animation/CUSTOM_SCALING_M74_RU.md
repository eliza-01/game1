# M74 — Custom Animation Scaling

> **Исторический документ.** Фиксирует состояние на момент указанного этапа; отдельные механизмы могли быть заменены. Действующие контракты: [актуальное ТЗ](../../spec/CURRENT_PROJECT_SPEC_RU.md), [архитектура](../../architecture/CURRENT_ARCHITECTURE_RU.md).


## Правила

- Общие stat → playback профили продолжают применяться ко всем Characters/NPC, а отдельно — к монстрам.
- Индивидуальное правило хранится под неизменяемым Roblox Animation Asset ID; не под именем файла или NPC.
- Приоритет: Studio-only transient override → сохранённый custom override → правило состояния → 100% fallback.
- При удалении custom override базовые параметры не меняются и начинают использоваться автоматически.
- Одна анимация может быть привязана к нескольким архетипам: её override действует во всех местах использования Asset ID.

## Runtime

- `AnimationSpeedScaling` — единственный резолвер скорости по Asset ID, стату и каналу.
- Серверные NPC/монстры и клиентский Character читают настройки через него. При активном отладочном override скорость уже проигрываемых треков обновляется через `Animator:GetPlayingAnimationTracks()` в ответ на изменение, а не покадровыми операциями.
- Для одновременного управления Hit и playback временем NPC / Monster AI вычисляет скорость того же конкретного клипа, что и аниматор.
- Studio Play `CustomScaling` — экранное окно только для Studio, не входит в игровые билды. Изменения хранятся исключительно в атрибутах Workspace текущей симуляции, автоматически сбрасываются при остановке Play.
- Сохранение в Asset Manager синхронизирует generated `AnimationSpeedScalingRegistry.luau` через Rojo; после изменения постоянных настроек следует перезапустить Play.

## Миграция

Файл `animation-speed-scaling.json` сохраняет `schemaVersion:1`, существующие `profiles` и `legacyProfiles`. Необязательный массив `customScaling` добавляется при первом сохранении custom записи. Никакие опубликованные анимации не переиздаются.
