# M71 — непрерывные атаки NPC и общие правила скорости анимаций

## Атаки NPC

- NPC реагирует на агрессию и преследует через прежний AI; MonsterAIService не меняется.
- Пока цель жива, видима и находится внутри Attack Radius / Pursuit Radius, одна анимация Attack продолжает циклически играть, **без переключения в Combat Idle после события Hit**.
- Для каждой итерации клипа сервер разрешает один Hit: при наличии Attack Timeline берётся нормализованная позиция Hit, при отсутствии — середина клипа; никакой weapon volume у NPC.
- При завершении цикла AI проверяет цель. При уходе цели из зоны атаки переходит в Chase, после убийства завершает текущий цикл и переходит в ReturnWait/Return.
- `CombatStateService` хранит общие временные флаги боя; NPC presentation следует собственному AI combat state и больше не реагирует на кратковременное истечение `InCombat` в процессе удара.
- Трек Attack зацикливается только у NPC. Смерть NPC немедленно завершает трек и запускает Death; смерть цели обрабатывается после текущего цикла.

## Animation Speed Scaling

- Реестр правил единый (`AnimationSpeedScalingRegistry`): профиль `humanoid/all` для **всех** игровых Character и NPC, независимо от архетипа или оружия.
- Каналы `walk`, `run` → игровой `RunSpeed`; `combat_idle`, `attack` → `AttackSpeed`.
- Каждому каналу назначается независимое `unitsPerPercent`, а `playback %` вычисляется общим `AnimationSpeedScaling.ResolveForModel`.
- Прежние настройки Human Female однократно переносятся в `humanoid/all` с текущими значениями. Бывшая запись сохраняется в `legacyProfiles` манифеста для аудита, но не исполняется.
- Монстры продолжают использовать отдельные профили. Их исходные значения сохраняются.
- Отсутствие NPC walk/run клипа не блокирует спавн. При отсутствии run, но наличии walk, NPC запускает walk со scaling соответствующего канала.

## Проверка в Studio

1. NPC с Attack анимацией: получить агрессию, войти в радиус удара и наблюдать несколько полных циклов без `combat_idle`.
2. Уйти из радиуса → NPC преследует; вернуться в радиус → атаки вновь. Убить игрока на Hit → последний цикл завершается до возврата домой.
3. Проверить Animation Speed: изменить Attack / Combat Idle / Walk / Run для `All Characters & NPCs`, перезапустить Play и сравнить Character и NPC.
4. Отдельно убедиться, что скорость монстра не изменилась.

Фактическая работа Roblox Animator проверяется в Studio, а локальные тесты проверяют контракты данных и интеграцию исходников.
