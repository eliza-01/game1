# Историческая заметка: крепление фонаря за сокет дома

> **Исторический фрагмент из исходной документации с нестандартной кодировкой имени** (документ `...pivot_...md` сохранён в корне `docs/` без переноса, чтобы не повредить ссылку/путь при `git apply` на Windows). Это не подтверждение, что механизм уже реализован. Действующие требования: [ТЗ](../../spec/CURRENT_PROJECT_SPEC_RU.md).

Авторская модель: у дома есть `house_armature/outside_lantern_01_socket`, у фонаря самостоятельные `lantern_01_armature`, `lantern_01` mesh и `light_01_socket` для света. При присоединении к сокету должен перемещаться и поворачиваться **весь фонарный rig**, а не только его MeshPart. Относительные координаты `light_01_socket` и визуальной геометрии должны сохраняться; домовая кость остаётся на месте относительно дома. Конкретная реализация attachment solver, ownership состояния и Studio/runtime проверка этой заметкой не определяются.

Это конспект существовавшей идеи, а не автоматическое добавление фонаря в текущие обязательные House Sockets.
