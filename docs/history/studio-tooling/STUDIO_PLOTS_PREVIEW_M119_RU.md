# M119 · Studio Plots preview

> **Исторический документ.** Фиксирует состояние на момент указанного этапа; отдельные механизмы могли быть заменены. Действующие контракты: [актуальное ТЗ](../../spec/CURRENT_PROJECT_SPEC_RU.md), [архитектура](../../architecture/CURRENT_ARCHITECTURE_RU.md).


Toolbar `game1` → `Plots` (только Roblox Studio Edit Mode).

Одна кнопка управляет локальным циклом:

1. Нажатие: полупрозрачные голубые **volume** для `Workspace.Plots/01..50`.
2. Нажатие: те же volume и плавно появляющиеся модели чисел `1..50`.
3. Нажатие: volume и числа плавно скрываются.

При повторном нажатии во время анимации предыдущие Tween отменяются.
Продолжительность анимации — 0,4 секунды.

## Контракт объектов

- Каталоги `01`–`50` — `Workspace.Plots/<номер>` типа Folder.
- В каталоге Part `plot_01_volume` (принимается также `plot_1_volume`).
- Число — Model `1` внутри соответствующего Part. Для старой иерархии
  поддерживается также `Workspace/Numbers_1-50/Numbers_1_50/1`.
- Отсутствующие объекты пропускаются с количеством в Output, без создания
  или изменения иерархии. Размеры/ориентации Part не изменяются.

## Безопасность

`StudioPlotsCatalog` только обнаруживает объекты. `StudioPlotsVisibility`
управляет временным отображением. Контуры — `BoxHandleAdornment`, размещённые
в `CoreGui` и привязанные к исходным Part через Adornee (не сохраняются в Place).
Оригинальные volume на время работы плагина локально скрываются через
`LocalTransparencyModifier`, а не `Transparency`. Числа плавно показываются
через тот же локальный модификатор. Исходные значения запоминаются отдельно
для каждого Part и восстанавливаются при выгрузке плагина / входе в Play.

Нет миграций, FBX, Image/Model IDs, перемещения, WeldConstraints или изменений
публикации. M120: на входе в Play/Run сохраняется текущее состояние (0/1/2).
В Edit скрытые volume и номера временно получают Locked=true, CanCollide=false,
CanQuery=false, CanTouch=false — не перехватывают клики и лучи.
Для видимых в симуляции volume выставляются Anchored=true, Color и
Transparency предпросмотра; скрытые также получают Transparency=1,
CanCollide=false, CanQuery=false, CanTouch=false. Модели не удаляются из
Workspace: физически и визуально они инертны, но остаются в иерархии.
Пауза не сбрасывает состояние. После Stop возвращается Edit-предпросмотр,
при Unloading — исходные значения всех временных свойств.

ВНИМАНИЕ: Locked/CanQuery/CanCollide и другие временно изменяемые поля
являются сериализуемыми свойствами Roblox. Не сохраняйте/публикуйте Place,
пока Plots скрыты/включены. Перед сохранением выгрузите плагин либо
временно восстановите авторские свойства. Edit-предпросмотр не является
постоянным контрактом для опубликованной игры.

Финальную видимость BoxHandleAdornment в Studio, работу Tween и отображение
при наличии нестандартных MeshPart необходимо проверить интерактивно.

## M121 · Click-through без перемещения Part

M120 `Locked`/`CanQuery=false` не гарантировали выбор объектов позади
невидимого volume: инструменты Studio используют собственный selection raycast.
M121 использует стандартную `StudioSelectable` collision group. При скрытии
объём и номер получают группу `Game1PlotsPreviewHidden`, которая не пересекается
с `StudioSelectable`. В Edit после этого клики проходят сквозь невидимые части,
а другие объекты внутри участка остаются доступны в viewport.

Группы создаются лениво при первом скрытии. Игровые collision pairs не
перенастраиваются. Исходная CollisionGroup каждого Part сохраняется как
временный атрибут `__Game1PlotsOriginalCollisionGroup` для восстановления
после аварийного закрытия Studio и удаляется при показе/выгрузке плагина.
`CFrame`, `Size`, `Parent`, номера и WeldConstraint не изменяются.
В Play группа возвращается к исходной, действует существующая M120 политика
видимости и Anchored.

Группы столкновений и временные атрибуты сериализуемы. Не сохраняйте и не
публикуйте Place при активном предпросмотре Plots: даже при видимом volume
плагин временно меняет `LocalTransparencyModifier`. Перед сохранением
выгрузите плагин и убедитесь, что свойства восстановлены. При случайном
сохранении скрытого состояния метаданные помогут восстановить CollisionGroup
при следующей загрузке плагина, но это не заменяет проверки перед публикацией.
Не удаляйте `Game1PlotsPreviewHidden` из настроек collision groups, пока
используется Plots.
