## Проверенный факт и границы

Воспроизведение частиц, позиция ассетов и взаимодействие в реальном Studio Place не подтверждены данным обзором.
- **M435–M437:** Atlas Favorites, Mechanics House и новые дефолты регистрации присутствуют. Зарегистрированные Asset IDs и существующие размещения документальным обновлением не менялись.
- **M427–M430:** индивидуальные расстояния Location Assets, индивидуальные House parts, общий hysteresis, Studio Preview schema v2; отдельный Runtime Draft создаёт артефакты и сохраняет `publishAllowed=false`.
- **M434:** исторический LOD Probe и счётчики debug удалены; разделять их с действующим Studio Preview.
- **Персистентность MMO:** production inventory, ресурсы, крафт, квесты и межсерверное сохранение не подтверждены. Показанные `-5 Wood`/`-1` ингредиенты — stub-представление, не расход из инвентаря.

## Исправление реестра Kanban

- До M439 у `KBN-0007`, `KBN-0015`, `KBN-0017` тексты спецификаций уже отличались от SHA256, записанных в JSON. `KanbanStore.list_cards()` прекращал работу при первой такой карточке с ошибкой 409; вся страница и экспорт оказывались заблокированы.
- M439 обновляет согласованно **все 17** техкарт, их `specSha256`, `revision`, `updatedAt` и append-only `history/*.jsonl` без изменения исходных статусов/checkbox/acceptance evidence. В `verify.py` добавлен read-only gate через **тот же `KanbanStore`** — несоответствие больше не проходит общий verify. Этот редакторский аудит не закрывает ни один тест в Studio.
- Исторические карточки не перенумеровываются. При следующем редактировании через UI надо сохранять документ и ревизию вместе; правки Markdown отдельно от JSON блокируются договором `KanbanStore`.
