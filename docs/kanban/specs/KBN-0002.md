**Статус:** PROPOSED · **Owner:** Codex · **Домен:** Tooling · **База:** game1 diagnostic dump 2026-11-13.

## Назначение и текущее состояние

Существующий Control Center использует Python Host Agent и локальную web UI, публикации ассетов из разных каталогов. Новый генератор обязан использовать действующие identity и history, не создавать конкурирующих таблиц.

Информация из дампа — исходная гипотеза/обнаруженное состояние. До изменения Roblox runtime сверить с актуальным Git и Studio. Эта карточка сама по себе не утверждает, что задача реализована или протестирована.

## Архитектура и механика

Проверить read_dispatch/write_dispatch, model publication, sqlite audit, registry, Studio plugin. У каждого потока данных указать источник истины, write path, rollback и idempotence.

## Контракт и неизменяемые правила

Запрещены неявный sync Studio и обновление placed geometry по схеме global replace; см. M216 safety contract.
