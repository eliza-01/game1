# KBN-0003 — Базовые замеры на Android

**Статус:** PROPOSED · **Owner:** Owner · **Домен:** Performance · **База:** game1 diagnostic dump 2026-11-13.

## Назначение и текущее состояние

Без исходных измерений нельзя доказать выигрыш от LOD. Определяем одну сцену города и один слабый Android, где выполняем все сравнения до/после.

Информация из дампа — исходная гипотеза/обнаруженное состояние. До изменения Roblox runtime сверить с актуальным Git и Studio. Эта карточка сама по себе не утверждает, что задача реализована или протестирована.

## Архитектура и механика

Измерять одинаковый маршрут, cold/warm loading, performance stats и по возможности память категорий; отдельно смотреть прогрев и падение FPS от нагрева.

## Контракт и неизменяемые правила

Не переносить показатели Studio на мобильный клиент. Не засчитывать тест без реального запуска.

### Зависимости

Независимая задача.
