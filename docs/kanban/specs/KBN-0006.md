# KBN-0006 — Реестр мира и placement records

**Статус:** PROPOSED · **Owner:** Codex · **Домен:** World Streaming · **База:** game1 diagnostic dump 2026-11-13.

## Назначение и текущее состояние

Source of truth — авторские placements и registry, не визуальные Instance в текущем Workspace. Реестр хранит метаданные объектов, сервер отправляет только нужные записи.

Информация из дампа — исходная гипотеза/обнаруженное состояние. До изменения Roblox runtime сверить с актуальным Git и Studio. Эта карточка сама по себе не утверждает, что задача реализована или протестирована.

## Архитектура и механика

Деление 2D по XZ, расчёт bounds, dedup by objectId, snapshot/delta/revision, batch и частота отправки. Мировые координаты рассчитывает сервер.

## Контракт и неизменяемые правила

Не импортировать целый Workspace на каждом Heartbeat. Не выдавать клиенту authority для изменения серверного мира.
