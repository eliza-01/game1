# KBN-0007 — Клиентский World Streaming

**Статус:** PROPOSED · **Owner:** Codex · **Домен:** World Streaming · **База:** game1 diagnostic dump 2026-11-13.

## Назначение и текущее состояние

ClientWorldStreamer создаёт только локальную визуальную оболочку; сервер хранит геймплей, коллизии и авторитетное состояние. Цель: реальные FULL/LOD, а не Transparency=1.

Информация из дампа — исходная гипотеза/обнаруженное состояние. До изменения Roblox runtime сверить с актуальным Git и Studio. Эта карточка сама по себе не утверждает, что задача реализована или протестирована.

## Архитектура и механика

Переходы имеют пороги с гистерезисом. Очередь по приоритету near-first, отмена при телепорте, устойчивость при packet reorder, fallback при недоступных ассетах.

## Контракт и неизменяемые правила

Не делать локальный Destroy серверных коллизий. Не хранить всю библиотеку FULL/LOD постоянно в ReplicatedStorage без отдельного бюджета.

## Этап 1: вычисление дистанций без переключения геометрии

- `LocationLodDistancePolicy.Resolve` — чистая функция без зависимости от Workspace и ассетов. Состояния FULL, LOD1, UNLOADED; стартовые границы 120 и 280 studs, гистерезис 12 studs. Это **отладочные значения**, не утверждённые бюджеты устройства.
- Вычисление идёт по расстоянию от камеры до `Model:GetPivot()` (для дальнего визуального LOD), только на клиенте.
- Для Studio диагностический `LocationLodStudioProbe` отслеживает **только** Models с тегом `Game1LocationLodProbe`. Показывает желаемое состояние над моделью и пишет переходы в Output. Не уничтожает, не скрывает и не клонирует серверные визуалы. Не создаёт ни одной модели LOD1.
- Вне Studio этот диагностический модуль ничего не запускает. CollectionService не обходит весь Workspace покадрово.
- Этап 1 НЕ является полной системой World Streaming: последующие этапы отдельно реализуют каталог placements, адресную доставку FULL/LOD1, создание/освобождение клиентских экземпляров, предзагрузку, бюджет операций и две независимые клиентские сессии.
- Без опубликованного LOD1 **не нужно скрывать FULL** при достижении порога: пока это только вычисленное состояние.

**Приёмка этапа 1 в Studio:** два/три перехода при отдалении и приближении от тестовой модели, отсутствие изменений исходных CFrame/Size/Pivot и коллизии, отсутствие дополнительных объектов после остановки Play. До реальной симуляции отмечено NOT_RUN.
