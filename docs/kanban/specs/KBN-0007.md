# KBN-0007 — Клиентский World Streaming

**Статус:** PROPOSED · **Owner:** Codex · **Домен:** World Streaming · **База:** game1 diagnostic dump 2026-11-13.

## Назначение и текущее состояние

ClientWorldStreamer создаёт только локальную визуальную оболочку; сервер хранит геймплей, коллизии и авторитетное состояние. Цель: реальные FULL/LOD, а не Transparency=1.

Информация из дампа — исходная гипотеза/обнаруженное состояние. До изменения Roblox runtime сверить с актуальным Git и Studio. Эта карточка сама по себе не утверждает, что задача реализована или протестирована.

## Архитектура и механика

Переходы имеют пороги с гистерезисом. Очередь по приоритету near-first, отмена при телепорте, устойчивость при packet reorder, fallback при недоступных ассетах.

## Контракт и неизменяемые правила

Не делать локальный Destroy серверных коллизий. Не хранить всю библиотеку FULL/LOD постоянно в ReplicatedStorage без отдельного бюджета.
