**Статус:** PROPOSED · **Owner:** Codex · **Домен:** Physics · **База:** game1 diagnostic dump 2026-11-13.

## Назначение и текущее состояние

Физический мир не зависит от клиентской детализации. Статичные коллайдеры принадлежат серверу, а их репликацией управляет штатный Roblox Streaming.

Информация из дампа — исходная гипотеза/обнаруженное состояние. До изменения Roblox runtime сверить с актуальным Git и Studio. Эта карточка сама по себе не утверждает, что задача реализована или протестирована.

## Архитектура и механика

Для неподвижных частей: Anchored=true, простые формы по возможности; CanTouch=false, если touch events не используются. Жизненный цикл дверей и триггеров независим.

## Контракт и неизменяемые правила

Нельзя удалять коллизии из серверного Workspace по визуальному профилю одного игрока.
