# KBN-0009 — Автоматизация подготовки ассетов

**Статус:** PROPOSED · **Owner:** Codex · **Домен:** Assets · **База:** game1 diagnostic dump 2026-11-13.

## Назначение и текущее состояние

Используем существующий Asset Manager scanner, Place Registry и History. Автоматизация должна уменьшать ручную работу, но не заменять авторское решение без проверки.

Информация из дампа — исходная гипотеза/обнаруженное состояние. До изменения Roblox runtime сверить с актуальным Git и Studio. Эта карточка сама по себе не утверждает, что задача реализована или протестирована.

## Архитектура и механика

Сканер сверяет manifest, source assets и published IDs; валидатор выдаёт structured report. Действия sync/publish только для выбранного asset type и с backup.

## Контракт и неизменяемые правила

Не менять mesh IDs, placements, texture bindings и авторские материалы массово.
