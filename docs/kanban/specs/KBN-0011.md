# KBN-0011 — Графические пресеты Low / Medium / High

**Статус:** PROPOSED · **Owner:** Codex · **Домен:** Performance · **База:** game1 diagnostic dump 2026-11-13.

## Назначение и текущее состояние

Профиль игрока влияет только на client presentation. Collision, NPC state, loot и interactions остаются серверными.

Информация из дампа — исходная гипотеза/обнаруженное состояние. До изменения Roblox runtime сверить с актуальным Git и Studio. Эта карточка сама по себе не утверждает, что задача реализована или протестирована.

## Архитектура и механика

Настраиваются distance thresholds, decorative density и эффекты. Начать с фиксированного Medium и расширять только после измерений.

## Контракт и неизменяемые правила

Не менять боевую механику по уровню графики и не подменять Roblox Graphics Quality.
