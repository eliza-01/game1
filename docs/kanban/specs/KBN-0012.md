# KBN-0012 — Безопасная публикация Eyesland DEV

**Статус:** PROPOSED · **Owner:** Owner + Codex · **Домен:** Tooling · **База:** game1 diagnostic dump 2026-11-13.

## Назначение и текущее состояние

Eyesland DEV — отдельная закрытая тестовая Roblox Experience. Изменения приходят из одного основного проекта, с явной целью публикации.

Информация из дампа — исходная гипотеза/обнаруженное состояние. До изменения Roblox runtime сверить с актуальным Git и Studio. Эта карточка сама по себе не утверждает, что задача реализована или протестирована.

## Архитектура и механика

Перед публикацией: проверки в Git, commit/hash, backup, target Experience ID, запуск staging на реальном клиенте, фиксированная дата и версия.

## Контракт и неизменяемые правила

Не менять Production без явного решения. Не путать локальное Save и Publish.

## Проверка и передача результата

1. Выполнить локальные узкие тесты и общий `python system/verify/verify.py` при изменениях исходного проекта.
2. Если затронут Roblox runtime — реальный Studio Play и Eyesland DEV телефон, отдельно от статических проверок.
3. Зафиксировать результат, точный commit/патч, известные ограничения и rollback.
4. Только после подтверждения обновлять статус DONE. Код написан ≠ проверено.

## Миграции / откат

Пока миграции не назначены. До реализации обязательны проверка источников истины, архив копии затрагиваемых данных и отдельный план отката для изменённых контрактов. Изменение архитектурной политики требует явного решения владельца.
