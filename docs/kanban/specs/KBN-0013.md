## Сохранённые архитектурные требования

`StudioRealEstateHouseFrame` остаётся авторским контрактом house Pivot; старый
`legacy-model-pivot` может требоваться лишь для чтения исторических Plot Bindings.
`PreciseConvexDecomposition` не назначается автоматически. `Rollback` означает
восстановление из резервной копии Place/SQLite, а не возврат COL Mesh.
**Location Assets** продолжают развиваться независимо от этой паузы.


- Для домов используется независимый Part Collision Blueprint; создание из частей, сохранение относительно **авторского Pivot `house`** и восстановление на Plot.
- Статические коллизии остаются серверными и не переключаются с FULL/LOD.
- В Real Estate существуют Plot Bindings, сокеты, двери и `HouseSocketService`; они требуют отдельного анализа перед клиентским Streaming.
- Сначала проверяем один дом, затем несколько поворотов, затем стресс-тест; не переписываем существующие Place/Clear.
