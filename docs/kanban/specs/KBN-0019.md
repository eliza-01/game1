# KBN-0019 — Balance · каноническая база статов и предметов

**Дата:** 25.11.2026 · база Game1 M512, дамп 21:04:35 + M512; reference RobloxLineage 05.10.2026.

**Статус:** PROPOSED. Цифры и архитектурные предложения подлежат согласованию; runtime не меняется.

## Предлагаемый контракт

Единая авторская база данных Balance с независимыми сущностями progression, weapon, armor, jewelry, set, skill, monster, loot table, economy. Предмет имеет стабильный gameplay ID и ссылку на существующий визуальный каталог, но его цена, редкость, бонусы и характеристики не принадлежат модели FBX/Atlas. Выбрать хранилище после аудита текущего Control Center; сервер получает компактный версионированный snapshot, клиент — безопасную проекцию для UI. Не создавать вторую конкурирующую базу значений.

Предлагаемые понятные статы: HP, Attack, при появлении магии Magic Attack/Magic Resistance, attack interval/speed, critical chance/multiplier, move speed, cast speed при необходимости. Не переносить STR/CON/DEX/INT/WIT/MEN, CP, MP, Accuracy/Evasion автоматически. Навыки — типизированный effect (damage, heal, buff и др.), не универсальный power. Согласовать пределы, finite/nonnegative, процентные единицы и порядок применения эффектов. Armor в новой базе можно задавать непосредственно как +HP. Бонусы комплектов, заточка и временные эффекты — отдельные записи. Локализация названий, описаний и единиц по существующей системе Game1, без дублирования чисел в переводах. Не внедрять новые статы/классы до согласования геймплея.

## Приёмка и откат

- Нет дублей идентификаторов, dangling refs и невалидных чисел — NOT_RUN.
- Одни входы дают идентичные выходы и digest — NOT_RUN.
- Смена визуального ассета не меняет боевой баланс; откат snapshot проверен — NOT_RUN.

До интеграции работа ведётся в изолированной лаборатории; версии входов, выходов и миграций сохраняются. Откат — предыдущий утверждённый snapshot; не менять визуальные Asset ID и существующие профили без миграции.
