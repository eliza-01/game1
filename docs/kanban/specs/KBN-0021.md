## Цели для обсуждения, не утверждённые числа

Начальный монстр 2–4 с; обычный 4–8 с; сильный 8–15 с; элита 20–30 с; мини-босс 45–75 с. Считать время от начала взаимодействия до смерти цели, отдельно чистый боевой TTK и полный цикл фарма. Формула для непрерывной оценки: DPS = D × (1 + pCrit × (critMultiplier − 1)) / interval, TTK ≈ HP/DPS. Это не точный дискретный бой: учитывать первый HitEnd, число ударов, overkill, вероятность попадания, headshot, перемещение, multi-target и скорость анимации. Не складывать crit/headshot без проверки действующего DamageService. Сравнивать урон по одной цели и суммарный урон по группе отдельно. Оружие дальнего боя учитывает реальную release/recovery, прицеливание, дистанцию и риск; широкие melee-секторы могут выиграть у кинжала при одинаковом single-target DPS.
