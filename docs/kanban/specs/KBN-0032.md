# KBN-0032 — Monster Navigation & Rescue Routes

**Статус:** IN_PROGRESS. Реализован эксперимент M561–M569; полная Studio-приёмка открыта. Не включать в production до принятия.

## Контракт

[M570 Gameplay infrastructure](../../workflows/M570_GAMEPLAY_INFRASTRUCTURE_RU.md), разделы 3–7. Direct: верхний горизонтальный луч в радиусе атаки, нижний при препятствии; Recovery: луч до пяток, затем основной. Никаких Wall Follow, резервных кастов для щелей и новых таймеров без измерения. Terrain исключён из навигационных проверок. Физический подъём, локальный обход и Rescue Route сравниваются по полной стоимости. Выход графа выбирается по высоте пяток, затем 3D-дистанции, затем полной длине. Вход с допуском 2 studs; до 8 кандидатов. Legacy/NPC сохранены, Studio A/B.

## Наблюдения

MONNAV подтвердил override=false → Legacy; после переключения оба луча обнаруживали стену, но альтернативы были nil. Пользователь сообщил, что из другой точки маршрут сработал до M568/M569. Это частичная проверка; причину недоступности всех входов и нагрузку ещё надо измерить. Не считать PASS.

## Откат

Отключить эксперимент через Options или Workspace override=false; не удалять граф/Place. Для диагностики сначала Output, затем точечные исправления.
