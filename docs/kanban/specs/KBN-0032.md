# KBN-0032 — Monster Navigation & Rescue Routes

**Статус:** IN_PROGRESS. Исходники M592 сверены по свежему дампу; M593 — Runtime opt-in и статическая оптимизация. Полная Studio/Runtime приёмка и профиль нагрузки открыты. Production rollout не принят.

## Контракт M593

[Gameplay infrastructure](../../workflows/M570_GAMEPLAY_INFRASTRUCTURE_RU.md), [аудит M593](../../workflows/M593_MONSTER_RUNTIME_AUDIT_RU.md), [ТЗ](../../spec/CURRENT_PROJECT_SPEC_RU.md). Direct: верхний горизонтальный луч в радиусе атаки; Recovery/выход: луч к пяткам + горизонтальный. Terrain исключён из навигационных лучей; физические коллизии сохраняются. Прыжок не дольше 1 с; StuckTimeout — телепорт домой с эффектом, обычный Return пеший.

- Rescue Route: ранжировать целевые линии по проекции игрока на отрезок; M582 — минимальное расстояние от линии до цели и выбранный выход не дальше исходной 3D-дистанции монстр–цель. Вход — проекция пяток, один луч до точки; при блокировке ±20 по длине линии, уточнение к цели по 4 в пределах одного интервала. Свободная проекция — без сетки. Никакого старого допуска высоты входа и лимита 8 входов.
- Свободные начало/конец целой линии соединяются с произвольной точкой другой линии при перепаде высоты ≤ routeConnectionHeight (default 2), без лимита длины; внутренние вершины не инициируют переходы. Маршруты независимы; переходы проверяются при поиске пути. Входы, пути и переходы кэшируются в рамках поиска. Выход выбирается по высоте, дистанции и стоимости. Приоритет целевой линии; соседние линии проверяются без повторной проверки входа.
- NoAccessiblePlan: отступить до максимальной дальности лука из Database + буфер (40+2 в текущей базе), даже без лука у игрока. Таймеры начинаются после отступления; повторное сближение и Rescue Route ×1,5 Run, настраивается. В ожидании граф не пересчитывается. При невозможности отступления ожидать в достигнутой точке. Home Leash/Death Chase и NPC сохраняют контракт.
- Studio A/B: override Workspace только в Studio. Published Runtime: `enabled` + `runtimeEnabled` (default OFF); GP/Test Hub не запускается в опубликованном Runtime; compiled Draft в Studio без override наследует оба Runtime-флага, GP/AG/Buffer включаются только при Start in Hub. Rojo Sync → сохранённый Place с Game1RescueRoutes → Preflight/Draft. Legacy доступен как откат; публикация только после приёмки.

## Наблюдения и открытые проверки

До M588 пользовательские логи фиксировали блокировки входов, многократный поиск и физические застревания. M588–M592 изменили контракт; факт выбора плана не доказывает обход. Статическая проверка M593 не доказывает FPS/CPU, проходимость переходов и Runtime Streaming. Проверить 50/100/200 активных монстров, обычный мир и GP в Studio, две клиентские сессии Runtime Draft, отсутствие debug-ремотов и сессии Hub при выключенном режиме. Старые acceptance не закрывать без доказательств.

## Откат

В Studio отключить Experimental или Workspace override=false. В опубликованной игре снять Enable in published Runtime, Save Options → Rojo Sync → новый Runtime Draft. Не удалять граф и Place.
