# KBN-0035 — Performance Profiler · baseline и диагностика

**База:** M605 · 27.11.2026. **Статус:** READY. План согласован на уровне очереди работ; точные реализации и бюджеты уточняются измерениями.

## Цель, исходные замечания и границы

Создать единую диагностическую инфраструктуру до оптимизаций. Ревью M605 — статический анализ, не измерение миллисекунд, FPS или долей CPU. Существующие карточки KBN-0003 (Android baseline) и KBN-0010 (сравнение на устройствах) сохраняют свои задачи и приёмку; результаты этого этапа использовать в них, не дублировать измерения.

Единый диагностический контракт для client/server: время работы и число вызовов подсистем, счётчики Raycast, активных sampler, AI-агентов, запросов навигации, кандидатов хитбоксов, LOD-операций и сетевых событий. Метки MicroProfiler, агрегирование без вывода каждого события; по умолчанию OFF. Не добавлять постоянные дорогостоящие обходы ради диагностики. В опубликованном DEV доступ только в рамках действующего контракта Debug; никакой диагностики для обычного релиза. CPU, GPU, RAM и сетевые показатели измерять раздельно, не выдавать длительность скрипта за полный GPU/frame time.

Зафиксировать воспроизводимый маршрут, версии, число игроков/сущностей, настройки графики, устройство, cold/warm запуск, FPS и p95 времени кадра, RAM, сетевую статистику и 15 минут прохода. Сравнивать одинаковые условия. Эмуляция мобильного в Studio не заменяет физический телефон.

## Проверка и откат

Каждое изменение — отдельный проверяемый патч поверх актуальной ревизии, с профильными тестами, verify.py и сравнением до/после. Для runtime обязательна Studio/DEV-приёмка на реальных устройствах. Не считать статические проверки замером производительности. Откат отдельно для каждого патча; миграции только с резервной копией и проверкой совместимости. Не оставлять дублирующие рабочие реализации. Статусы и evidence находятся в JSON карточки; все проверки пока NOT_RUN.
