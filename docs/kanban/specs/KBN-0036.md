# KBN-0036 — Spatial Index · общая инфраструктура

**База:** M605 · 27.11.2026. **Статус:** IN_PROGRESS. План согласован на уровне очереди работ; точные реализации и бюджеты уточняются измерениями.

## Цель, исходные замечания и границы

Ревью M605: EntityHitboxService.luau (256–373) перебирает глобальные bindings при melee, bow и Headshot. HouseSocketPromptController.luau перебирает загруженные prompts; LocationWorldStreamer.luau перебирает все записи. MonsterTargetPolicy.luau перебирает игроков при поиске цели. Цель — единый переиспользуемый алгоритм пространственного индекса (Spatial Grid), отдельные экземпляры и владельцы данных на client/server; не создавать общий монолит или дублирующие индексы для каждого запроса.

Предусмотреть статические и подвижные записи, запросы радиуса и пересечения объёма/луча с консервативными bounds, dedup, регистрацию/перемещение/удаление, respawn и streaming lifecycle. Индекс — только broad phase, точные проверки и авторитет сервера сохраняются. Не ограничивать Headshot радиусом melee: сохранить существующий контракт прицельного луча. Учитывать большие хитбоксы, вертикальные границы, телепорт и пересечение ячеек. Не заменять обход мира другим глобальным сканированием каждый кадр. Включение потребителей по отдельным патчам KBN-0037/0038.
