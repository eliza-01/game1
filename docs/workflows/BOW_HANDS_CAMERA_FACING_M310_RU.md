# M310 · Лук использует camera / facing Hands

## Область изменений

Только клиентская презентация: `MovementController`, `AttackController`,
`AimPoseController`. Камера, анимационный композитор, серверный `Release`,
баллистика, зарегистрированные ассеты и таймлайны не меняются.

## Поведение

- **ПКМ**: `CameraController` обрабатывает дельту мыши одинаково для hands и bow.
- **Ходьба**: bow больше не включает особый разворот к камере при движении
  или при простом экипировании. Используется обычная hands-политика:
  поворот по направлению движения, S без ПКМ — backpedal, ПКМ+S — steering.
- **Атака на месте**: для bow вызываются `BeginAimFacingCompensation`
  и `UpdateAimFacingCompensation`, как для hands. Пока натягивается лук,
  обновление компенсации получает актуальное направление камеры.
- **Торс**: `AimPoseController` накладывает yaw/pitch после композиции
  анимации на общий верхний bridge; без атаки поза постепенно снимается.
  Во время bow атаки торс продолжает следить за живым направлением камеры.
- **Лук на ходу**: движение ног остаётся у обычного `MovementController`,
  а верх тела — у `AttackUpperBodyComposer`. При начале движения
  стационарная компенсация разворота снимается, как для hands.

## Проверки в Studio (требуются)

1. Hands, без движения, ПКМ и поворот: камера вращается, персонаж не
   разворачивается сам по себе. При атаке на месте — плавный поворот корня
   при превышении допустимого yaw торса.
2. Bow, без атаки — камера и движение как с hands.
3. Bow, удерживая ПКМ, начать атаку на месте: во время натяжения торс
   отслеживает ПКМ по горизонтали и вертикали; при большом yaw корень
   компенсирует остаток; `Release` стреляет по текущему прицелу.
4. Bow, движение W/A/D/S и ПКМ+S во время атаки: ноги продолжают движение,
   корпус ограничен по yaw, корень не блокируется и не телепортируется.
5. Отменить атаку, умереть/респавниться: восстановление нормальной позы.
6. Проверить настоящий bow в Registry: у `EquippedWeaponType` должно быть
   `bow`. Если в Weapon Registry зарегистрирован `dagger`, новая логика лука
   не включится; тип менять явно в Asset Manager, не автоматически.

Автотесты проверяют контракт исходников; точную геометрию Bone.Transform
и отклик ПКМ без запуска Roblox Studio подтвердить нельзя.
