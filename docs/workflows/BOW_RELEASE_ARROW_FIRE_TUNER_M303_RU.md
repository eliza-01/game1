# M303 · Bow Release / Arrow assets / Fire Tuner

## Боевая система

- `bow` — событие **Release**, строго одно на клип; `HitStart` и `HitEnd` остаются **только ближнему бою**. Точное время Release задаётся в уже существующем редакторе таймлайнов, не выдумывается контроллером.
- Время выстрела и частота атак проверяются на сервере `AttackService`. Во время натяжения сервер получает обновлённое направление прицела (не позицию попадания).
- `BowProjectileService` продолжает проверять swept-ray, расстояние, препятствия, урон и headshot на сервере. Визуальная стрела (`ArrowVisualFactory`) **не является источником попаданий**. При ударе о поверхность модель временно остаётся в точке контакта и удаляется через 2.5 с.
- Для фонарей `LandscapeSwayService` уведомляет игроков по `RootCollider`, а не по отсутствующему у Game1 `HumanoidRootPart`. Событие отправляется лишь при фактическом контакте луча со sway-proxy/объектом.

## Asset Manager → Weapons → Arrow assets

1. Зарегистрировать FBX и опциональный PNG/JPEG; ввести имя, скорость в studs/s и локальную ось **носа** стрелы (по умолчанию -Z). Скорость разрешена 20–500 studs/s.
2. `Save` → `Publish` (Open Cloud) → `Sync Studio` (в `ServerStorage.arrows.<slug>.model.<slug>`) → выбрать `Active Arrow` → `Use` → дождаться синхронизации через Rojo.
3. Если ничего не опубликовано и не выбрано, система создаёт **процедурную деревянную стрелу** со скоростью 145 studs/s. Подмена на несуществующий Asset ID не используется.
4. При изменении только скорости FBX публиковать снова не нужно. Поскольку общий `ArrowRegistry` экспортируется в Luau, необходимо синхронизировать проект через Rojo.
5. Сейчас один глобальный активный вариант стрелы для тестирования луков (не инвентарь и не боеприпасы). Стрела — видимая серверная модель с баллистикой и hit detection, **не физическое тело с Roblox NetworkOwnership**.

## Fire Tuner — исправление M304

- **M303 ошибочно установил архивную копию `Plugins.rar/fire_bone.lua` поверх пользовательского `%LOCALAPPDATA%\Roblox\Plugins\fire_bone.lua`.** В архивной копии нет системы пресетов, которая была в рабочем локальном плагине. Поэтому ранее написанное утверждение о сохранении пресетов и совместимости было неверным.
- **M304 удаляет автозамену** из `system/studio-plugin/install.ps1` и исключает архивную копию Fire Tuner из проекта. Установка Game1Bridge больше не редактирует Fire Tuner, направление его огня или пресеты.
- M304 **не может сам восстановить прежний локальный код**, если M303 уже перезаписал файл. Для восстановления предусмотрен безопасный помощник `system/studio-plugin/recover-fire-tuner.ps1`: по умолчанию он только ищет возможные копии; с явным `-RestoreFrom` сохраняет резервную копию текущего файла и восстанавливает *выбранный пользователем* исходник. Никакая архивная версия не назначается автоматически.
- Клиентский `BoneOrbController` (новая независимая runtime-возможность M303) сохранён. Но возможность настраивать светящийся шар в **исходном** Fire Tuner зависит от локальной версии плагина и **не может считаться реализованной без её исходника**. Модифицировать живой пользовательский Fire Tuner нужно только после получения настоящего исходника.
- Никакая логика оружия, стрел, `Release` или публикации стрел в M304 не меняется.

## Проверка в Roblox Studio (не выполняется автоматическими тестами)

1. Play: bow attack с authored Release; проверь полёт/ориентацию/скорость/попадание в голову и отсутствие повторного урона. Вариант без опубликованной стрелы должен показывать процедурную геометрию.
2. Стреляй в коллизию/`LandscapeSwayTarget` фонаря — камера должна видеть полёт и качание. При стрельбе мимо sway-proxy эффекта **не будет**: событие выдаётся только от реального пересечения.
3. Fire Tuner: выбери кость с произвольным названием, включи Orb, настрой параметры в Studio Edit, затем Play рядом с ригом.

**Ограничения:** Roblox Studio, реальная публикация FBX/Open Cloud и сетевые условия в этой среде не запускались; статические тесты не подтверждают визуальную корректность в Play. Из старого Lineage взят принцип, не копированы его боевые сервисы.
