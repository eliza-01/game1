# M316 — Bow: combat hitbox != arrow visual surface

## Контракт

- **Урон и Head/Body:** только `EntityHitboxService.RaycastAimRegions`, один
  подтверждённый контакт с серверным bone-local hitbox. Захваченная камерой
  зона не гарантирует headshot, если фактически попали в другой hitbox.
- **Визуальная стрела:** после подтверждённого контакта искать отдельно
  геометрию того же актора. Приоритет `COL_*`, `col_mesh` и другие имена,
  распознаваемые `MeshPhysicsCore.IsCollider`; иначе MeshPart видимого рига.
- `CanQuery=false` у NPC, монстров и персонажей не изменять. Для геометрии
  использовать один *impact-time* `Workspace:Raycast` с Include-фильтром;
  `BruteForceAllSlow` разрешён только внутри этого запроса для конкретной цели
  (когда физические коллизионные части недоступны для обычного Raycast).
- Landscape Painter использует тот же запрос поверхности; прежний OBB-fallback
  удалён. При отсутствии геометрического пересечения не прикреплять стрелу к
  прямоугольному proxy или пивоту.
- При удачном мировом попадании по COL/Mesh того же актора повторный запрос
  поверхности не выполняется.
- Контакт поверхности не может сам по себе выдать урон или headshot.
- Не искать поверхность у всех акторов каждый кадр. Если поверхность дальше
  1,25 studs от подтверждённого hitbox-контакта (или не найдена), урон остаётся,
  но косметическая стрела исчезает — нет "притягивания" к центру/пивоту.
- `ArrowImpactAttachment` использует реальный ударенный BasePart для rigid-weld
  либо существующее кратковременное следование за Bone у skinned-ригов.
- До применения смертельного урона определить геометрию и закрепить стрелу:
  Death может менять состав рига прямо во время вызова DamageService.

## Ограничения

Roblox Raycast пересекает **физическую collision-геометрию MeshPart**, а не
обязательно точные треугольники деформированной skinned-поверхности. Для
анимированных NPC отсутствие COL и `CanQuery=false` требует единичного
brute-force запроса по известным MeshPart — не в цикле полёта, а только после
зарегистрированного попадания. Если геометрия не совпадает со скелетом,
система сознательно не рисует зависшую стрелу.

## Проверка в Studio Play

1. NPC: голова/корпус с фронта и со спины; проверить Head/Body и геометрию.
2. NPC во время смерти: стрела следит за костью до истечения 2,5 с.
3. Static MeshPart без COL: стрела на collision-поверхности меша.
4. С объектом `col_mesh`: визуализация на COL, урон (если это актор) только
   при пересечении его боевого hitbox.
5. Подвесной фонарь с LandscapeSwayTarget: нет прыжка к пивоту, есть покачивание
   со стрелой.
6. При отсутствии поверхности — лог `visual_surface_missing`, но урон нанесён.
7. 20 выстрелов в одну точку; отдельно проверить стабильность захвата M315.

`verify.py` и статические тесты не заменяют Studio Play для скелетных моделей.
