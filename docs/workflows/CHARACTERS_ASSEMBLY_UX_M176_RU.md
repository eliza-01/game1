# M176 · Characters: список, редактор и пустой рецепт

**База:** M175. Это интерфейсный этап, не миграция Character Assembly и не изменение схемы SQLite.

- Список зарегистрированных сборок расположен **над** редактором. `New character` находится над таблицей; отдельная дублирующая кнопка в боковой панели убрана. `Edit recipe` переносит фокус в редактор выбранной строки.
- Редактор группирует слоты в две колонки: слева голова, верх, низ, перчатки, ботинки; справа волосы, брови, глаза. Узкие экраны получают одну колонку. Порядок полей в JSON/API **не изменён**.
- Новый рецепт не выбирает одежду, сет, голову, волосы, брови или глаза автоматически. Риг остаётся стартовым параметром, а характеристики заполняются значениями по умолчанию. Нажатие кнопки не сохраняет запись, не публикует FBX и не меняет Startup.
- Смешанный, но полностью выбранный комплект — **нормальное** состояние. Только отсутствие частей и другие зависимости дают оранжевое предупреждение. Проверка серверной готовности и права на Startup по-прежнему выполняется сервером.
- Стартовый персонаж обозначается зелёной **неинтерактивной** меткой `✓ startup`; для остальных отображается действие `Set as Startup`.
- Подсказки `?` в Characters переведены на краткий русский. Справка по именам атласов сохраняет примеры и формат M175.
- Для `Starting stats` добавлены отдельные внутренние отступы и адаптивная сетка полей.

## Ручные проверки в браузере

1. Открыть Characters: таблица **Зарегистрированные персонажи** над редактором, `New character` над таблицей.
2. Нажать `New character`: ни один из восьми слотов не выбран, Starter set пустой, Startup прежний. Выбрать сет и проверить подстановку только четырёх частей одежды.
3. Нажать `Edit recipe` у существующей сборки: все сохранённые части подставлены, выбранная строка подсвечена и поле имени получает фокус. `Reset edits` восстанавливает сохранённую конфигурацию.
4. Выбрать неполный комплект: видны хорошо читаемые оранжевые причины отсутствующих зависимостей. Смешанный **полный** комплект не должен подсвечиваться как неполный.
5. Развернуть `Starting stats`: элементы не прилипают к краям и не переполняют окно. На узком окне колонки слотов складываются в одну.
6. Проверить `?` возле сборки, сохранения, атласа и legacy-кнопок: текст на русском; `✓ startup` не выглядит кнопкой и не реагирует на нажатие.

После применения перезапустить Control Center/Host Agent и обновить браузер. Roblox Studio и Rojo перезапускать не требуется.
