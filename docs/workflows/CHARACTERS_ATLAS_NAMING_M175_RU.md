# M175 — Стандарт имён атласов Characters

> Действует для **новой регистрации** атласов Characters. Общий Atlas Registry для Location Assets / Real Estate не меняется. Существующие опубликованные атласы, привязки и Roblox Image Asset ID не мигрируют и не переименовываются.

## Шаблон

`<atlas_key>_<width>x<height>_atlas.png` — предпочтительный формат. Принимаются также `.jpg` и `.jpeg`. Файл изображения должен иметь заявленные в имени размеры в пикселях. Примеры `2048x2048` и `512x512` ниже **не обязательные размеры**, а иллюстрации.

`atlas_key` — строчные ASCII-буквы, цифры и `_`, начинается с буквы, без пробелов, дефисов и `.001`. Это соглашение соответствует названиям частей из `character_core/part_names.py`. Парсер атласа выделяет размеры и суффикс справа, поэтому подчёркивания **внутри имени сета поддерживаются**.

Сет **Fullplate Imperial** регистрируется как `fullplate_imperial`, а его FBX-меши — `fullplate_imperial_upper`, `fullplate_imperial_lower`, `fullplate_imperial_gloves`, `fullplate_imperial_boots`. Не стоит использовать буквальный пробел в имени атласа.

## Примеры по слотам

| Слот или назначение | Пример имени атласа |
|---|---|
| Upper | `fullplate_imperial_upper_2048x2048_atlas.png` |
| Lower | `fullplate_imperial_lower_2048x2048_atlas.png` |
| Gloves | `fullplate_imperial_gloves_2048x2048_atlas.png` |
| Boots | `fullplate_imperial_boots_2048x2048_atlas.png` |
| Shared atlas для всего сета | `fullplate_imperial_2048x2048_atlas.png` |
| Head male | `head_01_male_1024x1024_atlas.png` |
| Head female | `head_01_female_1024x1024_atlas.png` |
| Hair male | `hair_01_male_1024x1024_atlas.png` |
| Hair female | `hair_01_female_1024x1024_atlas.png` |
| Hair common | `hair_01_common_1024x1024_atlas.png` |
| Eyes | `eyes_01_512x512_atlas.png` |
| Eyebrows | `eyebrows_01_512x512_atlas.png` |
| Eyes spiral (эффект) | `eyes_01_spiral_512x512_atlas.png` |

Это **варианты организации**, а не обязательный отдельный атлас под каждую часть. Один опубликованный атлас можно назначить сразу нескольким компонентам — например, всему `fullplate_imperial` или всем прическам. Слоты `eyes` и `eyebrows` с однотонным материалом могут вообще не использовать атлас. Существующие FBX имена/сеты от переименования файла атласа не меняются.

## Регистрация и замена

1. Нажать `?` **слева от Register Atlas**: памятка с примерами доступна при наведении или фокусе с клавиатуры.
2. Выбрать изображение: Host Agent показывает фактические размеры, превью и проверку имени **до регистрации**.
3. При неверном имени показывается ожидаемое имя и `Show in folder`; переименование вручную, затем повторный выбор.
4. Совпадающее имя + разрешение в Character scope означает **существующую ревизию атласа**: модалка сравнивает изображения и требует подтверждения. Сначала публикуется новый Roblox Image Asset ID, затем переключается реестр. При неудаче прежний опубликованный ID сохраняется.
5. Атласы других разделов не попадают в список Characters; сервер не разрешает захватить их имя/разрешение без явного переименования.

Новые ограничения применяются **только** в `CharacterAtlasAuthoring.inspect` / `publish`: глобальный `parse_filename`, старые записи SQLite и права других разделов не изменяются. Конвертации или миграции существующих опубликованных атласов нет.
