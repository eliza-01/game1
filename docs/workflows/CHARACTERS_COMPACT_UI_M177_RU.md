# M177 · Characters: компактная статистика и очередь публикации

**База:** M176. Изменения касаются только интерфейса Characters; схема SQLite, API регистрации компонентов, версия ассетов, механизмы Roblox Open Cloud и Studio Sync не меняются.

- Удалены вводный англоязычный текст и дублирующая навигация из четырёх ссылок. Разделы и их ID сохранены.
- Статистика ригов, частей, сетов и публикаций показывается в отдельных компактных карточках. Числа рассчитываются из текущего каталога компонентов, а не из статических строк HTML.
- Совет короткий: проверить FBX, зарегистрировать части и публиковать только изменения. Если есть неопубликованные или незавершённые ревизии — рядом появляется янтарное предупреждение с количеством. При повторной публикации прежний Model ID остаётся действующим до успешной замены.
- `Mesh naming standard` и `Starting stats` раскрыты при первом открытии страницы. Пользователь может свернуть каждый блок самостоятельно.
- `Queue` видима всегда. Без выбранных компонентов открывает пустую очередь; с выбранными — предварительный список без запуска публикации. Кнопка постоянно имеет бирюзовую рамку; красная пульсация означает выбранные либо выполняющиеся задания. После завершения и очистки выбора пульсация прекращается. При `prefers-reduced-motion` мигание отключено, красная рамка остаётся.
- Визуализация статистики находится в отдельном `character-component-summary.js`. Владельцем состояния очереди остаётся `character-publications.js`; новой серверной очереди, скрытой загрузки и автоматической публикации нет.

## Проверки после установки

1. Открыть Characters: вводного текста и четырёх карточек навигации нет. Видны пять числовых метрик, короткие совет и состояние публикаций.
2. Убедиться, что `Mesh naming standard` и `Starting stats` раскрыты без кликов. После сворачивания они должны оставаться закрытыми до следующего открытия страницы.
3. Открыть `Queue`, ничего не выбирая. Ожидается сообщение о пустой очереди, никакая публикация не запускается.
4. Отметить неопубликованную часть в таблице. `Queue` получает красную пульсацию и число. Открыть: выбранная часть перечислена, но публикация ещё не началась. Снять отметку: пульсация исчезает.
5. При реальной публикации **тестовой** части проверить: диалог открывается и показывает статус загрузки; после завершения (и обновления каталога) красная пульсация исчезает. Не перепубликовывать неизменённые части ради теста.
6. В PowerShell: `python system/verify/verify.py` (код завершения 0), затем `python -W error::ResourceWarning -m unittest discover -s system/verify -p "test_*.py" -q`.

Для отображения изменений перезапустить Control Center/Host Agent и выполнить hard reload браузера. Roblox Studio/Rojo перезапускать не нужно.
