# M465 · Common bind compatibility / поиск анимаций

## Проблема

`human_common_m001_eye_l` и `human_common_m001_eye_r` опубликованы на
`human_female`, но предназначены обоим полам. Ранее проверка требовала
совпадения **всех** костей между женским и мужским ригами. Несвязанные с
глазами `face_mouth`, `face_mustache`, `weapon_grip_l` отличались и скрывали
глаза в редакторе сборки, хотя их `face_eye_l/r` и цепочки родителей совпадали.

## Контракт

- Только `gender=common` допускает повторное использование между ригами
  одного семейства. Фильтр `allowedGenders` остаётся обязательным.
- Используются только **опубликованные** метаданные MeshPart и двух ригов.
- Для skinned MeshPart сравниваются bind-матрицы его реально используемых
  `used_bones` и **всех предков** в трёх источниках: опубликованный MeshPart,
  исходный rig, целевой rig. Различия в любых этих костях запрещают reuse.
- Для присоединённых через сокет деталей проверяется сокет и его предки.
  Если нет ни bone influences, ни явной привязки, cross-rig reuse запрещён.
- Runtime `CharacterAssemblyBuilder` проверяет импортированные используемые
  кости и родителей, но не посторонние кости из скелета исходного FBX.
  Несовпадение любого проверяемого bind остаётся жёсткой ошибкой.
- Никаких автоматических изменений весов, геометрии, Asset ID, рецептов и
  Armor Set. Несовместимая общая деталь продолжает требовать исправления
  исходного rig/FBX или отдельного варианта.

## Наблюдение на базе 24 ноября

Для `human_male` обе common-пары глаз и бровей совместимы; common boots
также совместимы. `human_common_m001_gloves` **несовместим** с одним из
используемых костных bind (`ring_03_l`). Сет `peasant_clothes` пока требует
назначения male upper/lower. Эти данные не исправляются автоматически.

## Поиск в Animations

Клиентский фильтр зарегистрированных/отсутствующих анимаций ищет по
имени клипа, каноническому имени файла, слоту и контексту, без учёта регистра.
Он применяется поверх фильтра раздела, сортировки и Show missing; не
записывает состояние в каталог, не меняет Animation ID и не запускает
публикацию. Escape очищает запрос, переход по filename rule тоже очищает
его, чтобы открыть правильную строку.
