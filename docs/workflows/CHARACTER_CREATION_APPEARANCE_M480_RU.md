# M480 · Character Creation — сцена, превью, редактор внешности

## Контракт

- На сцене одновременно представлены два **локальных** визуальных Human (Male/Female).
- Позиции: `Workspace.Places.Character Creation/Game1CharacterCreationSpawnPoints/MalePreviewPoint`, `FemalePreviewPoint` (Part или Model). Альтернатива без Studio Lua — `Options → Character Creation → Два места персонажей` (`position XYZ`, `rotationDegrees XYZ`). Если редакторских меток нет, используются значения Options. Координаты в исходном наборе — приблизительные, их следует сверить в Studio.
- Наличие двух точек не изменяет игровые SpawnLocation и не создаёт физические коллайдеры.
- Сборка превью: серверный `CharacterAssemblyBuilder`, затем клиентское локальное клонирование из общего набора шаблонов ReplicatedStorage (лимит 32 геометрических комбинации на сервер).
- Разрешённая внешность: опубликованные совместимые прически, пары глаз, пары бровей, готовые головы и цветовые каналы. Верх/низ тела, обувь и перчатки берутся исключительно из выбранной стартовой сборки, не редактируются.
- Кандидаты выпускаются из `CharacterComponents` на `CharacterStore.export`; общие части проверяются через существующий bind-pose resolver. Несовместимые или неопубликованные части не предлагаются.
- Клиент передаёт идентификаторы из каталога и цвета `#RRGGBB`; сервер проверяет каждый ключ, вариант, канал и допустимое значение, строит игровой образ той же системой. Клиент не задаёт URL, Asset ID, экипировку или управляющие структуры.
- Preview модели не создают персонажей Roblox Player, не регистрируются в бою, не запускают физические контроллеры. Цвета изменяются в локальных клонах, не создавая серверные template на каждый оттенок.
- Выбранная внешность сохраняется в памяти текущей игровой сессии и используется при Respawn/Return to Town. Постоянное сохранение слотов/имён требует отдельной DataStore-модели и в M480 не включено.
- Анимация презентации — существующий `weapon.hands.idle`; никаких специальных `creation` клипов.

## Проверка Studio Play / Runtime

1. В Options включить Character Creation. Проверить точки Male/Female и 5 Camera Anchors; сохранить Place и синхронизировать Rojo.
2. Войти: два персонажа на сцене, панель справа, обзорная камера, выбор пола → полная фигура → лицо.
3. Сменить каждую из 3 причёсок, переключить брови Female (Common/Female), цвета волос по основному и дополнительному каналам, глаза и брови. В неподдерживаемых категориях UI отсутствует.
4. Нажать «Войти в мир» и подтвердить ту же внешность на игровом персонаже. Убедиться, что шмотки/броня и тело не менялись.
5. Проверить вторым игроком: сцена и цвета приватны, серверные шаблоны общие. Попробовать отправить неизвестный hair/slot/invalid hex — сервер должен отклонить запрос без спавна.
6. Проверить mobile, повторное появление персонажа и закрытие сцены (локальные модели уничтожаются).

## Ограничения

Нет подтверждённого Studio Play из среды патча. Если пользователь прислал координаты только изображением, координаты не следует объявлять точно извлечёнными автоматически. Авторские точки в Workspace имеют приоритет, запасные координаты Options редактируемы. Сохранение внешности между игровыми сеансами пока отсутствует.
