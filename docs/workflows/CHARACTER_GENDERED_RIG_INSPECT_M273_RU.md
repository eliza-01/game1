# M273 · Rig family vs gendered Armature (Character Inspect)

В FBX разрешены два варианта **основного Armature**:

- `human_armature` — общий bind profile `human`;
- `human_male_armature` / `human_female_armature` — отдельные bind profiles `human_male` и `human_female`.

Имя MeshPart по-прежнему `<family>_<male|female|common>_mNNN_<slot>`.
Семейство `human` в `human_female_m001_head` **не обязано буквально
равняться** полному ID `human_female` рига. В FBX женского рига допустимы
`human_female_*` и `human_common_*`. `human_male_*` в нём отклоняются.
Общий `human_armature` может содержать любой половой вариант своего семейства.

`common` не означает совместимость произвольных скелетов. При регистрации
MeshPart сохраняет фактический риг, под которым был экспортирован. При
сборке с другим ригом такой skinned MeshPart разрешён только если оба
зарегистрированных опубликованных скелета совпадают по костям, родителям
и bind matrices; иначе сборка отклоняет ресурс. `allowedGenders` — отдельный
игровой фильтр и сам по себе не доказывает совместимость скелета.

Для standalone rigid hair без Armature используется половой риг из имени,
если он зарегистрирован; иначе существующий общий риг семейства. Если
`common` hair не имеет Armature и подходит сразу под два различных
зарегистрированных рига, нужно явно выбрать риг через FBX с Armature,
а не полагаться на произвольный выбор импорта.

## Skin weights

У skinned MeshPart каждая вершина должна иметь от 1 до 4 положительных
весов на **реальные deform Bones основного Armature**, сумма ~1.0.
Inspect теперь сообщает тип нарушения и индекс вершины:

- нет весов на кости рига — необходимо исправить Skin/Vertex Groups в Blender;
- более четырёх влияний — Limit Total(4), затем Normalize All;
- сумма весов не равна 1 — Normalize All.

Для диагностики можно открыть Blender → Weight Paint → Weights; также
проверь Armature modifier и что Vertex Groups названы как Bones.
**Автоматический перенос весов на ближайшую кость не выполняется:**
для головы он может незаметно повредить мимику. Исходный FBX и `.blend`
не изменяются при Inspect.

Обязательный тест: FBX с `human_female_armature`, женской головой и общими
частями успешно проходит проверку имён; ошибочные веса блокируют только
проблемные меши, а зарегистрированный риг не заменяется скрыто.
