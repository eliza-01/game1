# M461 · Материал персонажа по умолчанию — Plastic

- В редакторе **Characters → Assemblies** в каждом из 10 слотов материала
  (броня, голова, глаза, брови, волосы) доступен `Plastic`, выбранный по умолчанию.
- В v2-рецепте `part_materials` остаётся разреженной картой явных назначений.
  В отсутствие записи для слота `CharacterAssemblies.resolve` выдаёт `Plastic`.
  Явно сохранённые материалы (`Metal`, `SmoothPlastic` и другие) не перезаписываются.
- Разрешённый рецепт экспортируется в `CharacterRegistry` через существующий
  `CharacterStore.export`. Сервис Builder применяет `part.material` ко всем
  выбранным MeshPart, в том числе дополнительным элементам составных волос.
- Схема SQLite, имена слотов, ID ассетов, FBX и атласы не меняются; миграция не нужна.
- Старые опубликованные v2-рецепты получают Plastic при очередном экспорте
  Registry, который выполняется при запуске Host Agent после инициализации
  CharacterAssemblies. Уже собранный персонаж меняется при следующей сборке,
  а не за счёт изменения существующих экземпляров на Place.
- `rig_carrier` и невидимый `RootPart` — служебные объекты, а не визуальные
  части; изменение материала на них не требуется.
