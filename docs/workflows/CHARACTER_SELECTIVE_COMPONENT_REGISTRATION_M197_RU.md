# M197 · Characters — выборочная регистрация новых и замена существующих частей

## Причина

Inspect FBX, содержащего `hair_03_common` и пять опубликованных частей,
показывал новый компонент, но модальное окно требовало подтверждения **всех**
пяти замен. Отмена оставляла `hair_03_common` незарегистрированной. Более того,
ранее зарегистрированные, но ещё не опубликованные части могли переписываться
при повторной регистрации без отдельного разрешения.

## Поведение после M197

1. **Inspect** по-прежнему анализирует полный FBX и не загружает Roblox assets.
2. **Review** разделён на *Add new components* (по умолчанию выбраны только
   новые записи) и *Replace registered components* (все флажки сняты).
   Можно снять отметки с отдельных новых частей или явно выбрать некоторые
   замены. Ничего не выбрано — подтверждение недоступно.
3. **Register** принимает `newParts` (подмножество идентификаторов, отсутствовавших
   в реестре при Inspect) и `replacements` (подмножество ранее существовавших).
   Backend повторно проверяет выбранные идентификаторы и snapshot ревизий.
   Пересечение новых и зарегистрированных запрещено; неподтверждённая замена
   невозможна. Для старых клиентов отсутствие `newParts` означает все новые
   компоненты, а **не** разрешение заменить существующие.
4. **Existing rows not selected:** у них остаются те же ревизии, Model Asset ID,
   `published_revision`, метаданные и пути FBX. Записи истории не добавляются.
   Никакой републикации не происходит.
5. **02 · Публикация компонентов** получает новые строки из обычного snapshot
   после регистрации. Для их публикации используется прежняя очередь.

Поведение M190 Replace Rig сохранено: несовместимый риг требует отдельное
одобрение; режим Rig only не регистрирует ни один меш. M196 partial inspection
по-прежнему требует `allowPartial=true`, если некоторые FBX-компоненты ошибочны.

## Проверка сценария

- В FBX есть `human_armature`, `hair_03_common` без Armature Modifier и
  `head_01_male`, `newborn_boots/gloves/lower/upper`, уже опубликованные ранее.
- Inspect → Review: галочка `Add NEW hair_03_common` включена;
  пять `Replace` выключены; Confirm активен.
- Register: добавлена только `hair_03_common` со статусом `registered`.
  Пять прежних записей и их IDs побайтно идентичны до/после.
- В таблице публикации новая причёска доступна для отдельной публикации.
- Альтернативный сценарий: выбор одного Replace затрагивает только его;
  все другие части не меняются. В том числе защищены ещё не опубликованные.

## Границы

SQLite-схема, Blender FBX-экстрактор, Open Cloud, общий Atlas Registry,
CharacterAssemblyBuilder, анимации и Roblox Studio не изменялись.
Извлечение всех корректных частей FBX перед коммитом сохранено как проверка
неизменности авторского источника; **регистрация** происходит выборочно.
