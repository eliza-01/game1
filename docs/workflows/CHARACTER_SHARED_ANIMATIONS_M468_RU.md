# M468 · Общие анимации персонажей

Публикации сохраняются на исходном клипе. Таблица `animation_shared_bindings` связывает
семантический слот семейства (например `human`) с опубликованным `animation_bindings.id`.
Поиск на клиенте: локальная анимация персонажа → общая → отсутствует. Не происходит
копирования Asset ID, редактирования исходного клипа или перепубликации.

Безопасность: для общего назначения требуется опубликованный исходник и совместимая
иерархия и bind pose. Для `jump_start` и `jump_loop` допускаются только различия
`face_mouth`, `face_mustache`, `weapon_grip_l`; все остальные кости проверяются.
**Это проверка скелетов, а не анимационных кривых**: исходные `.rbxm` недоступны в дампе,
поэтому визуальную работу обоих клипов на мужском риге необходимо проверить в Studio Play.
Остальные кросс-риг анимации разрешаются только при полном совпадении всех bind-костей.

Миграция `m468_share_human_jump.py` создаёт резерв SQLite, добавляет ссылки,
сохраняет женские публикации и повторно генерирует оба реестра.
Выбор Male/Female виден над списком, раздел Common содержит назначения, кнопка
`common` разрешает явную публикацию общего назначения в другие слоты.

Используется всеми потребителями: клиентский AnimationResolver, прогрев, Studio Test Stand,
серверная проверка боевых клипов и FaceEmotionService. Для лицевых анимаций
действуют дополнительные правила рига в документах клипа; они не обходятся.
