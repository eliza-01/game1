# M330 · Классическая камера и мобильные жесты

## Область изменения

- `CameraController`: непосредственный поворот по пиксельным смещениям мыши / пальца без угловой интерполяции. `GetRenderCFrame()` остаётся для визуального сопровождения персонажа. На ПК RMB + движение мыши; колесо — зум. Уменьшена чувствительность до `0.0024` радиан/пиксель.
- `MobileInputController`: правый круг полностью удалён. Левый аналоговый стик уменьшен вдвое; сохранены `RequestAttack`, `RequestJump` и независимое движение при атаке. Одно свободное касание двигает камеру, два свободных касания изменяют расстояние камеры щипком. Касание стика движения не считается пальцем жеста. GUI-перехват проверяется через существующий `UiInputGuard`.
- `CharacterConfig`: `CameraTouchRotationSpeed` и `CameraRotationResponse` удалены (больше не используются); `CameraTouchSensitivity = 0.0024`.

## Поведение

- Камера не догоняет целевой угол через lerp. При отпускании мыши или пальца вращение сразу прекращается.
- Разведение пальцев приближает камеру, сведение — отдаляет, в прежних пределах 4–18 studs. При переходе между drag и pinch отсутствует скачок угла, потому что отслеживаются отдельные позиции каждого свободного пальца.
- Отладочный Camera Draft продолжает управлять исходными параметрами положения камеры; pinch не сохраняет расстояние в Options. При смене персонажа камера сохраняет существующую схему инициализации.

## Проверить в Roblox Studio Device Emulator / опубликованном месте

1. ПК: RMB+движение, зум колесом, камера без задержки и умеренная чувствительность.
2. Телефон: левая рука — маленький стик; свайп по свободной части экрана — поворот; два пальца — pinch. Нет правого круга.
3. Телефон: левый стик + отдельный палец для камеры; одновременно атака/прыжок не поворачивают камеру.
4. Свайп/щипок поверх UI не двигает камеру; при отпускании одного пальца после pinch оставшийся продолжает управлять камерой без рывка.
5. Ближний бой / лук: серверная проверка попадания и направление aim ray не затронуты изменением контроллеров.

Тесты в Python являются контрактными, а не заменой реального Device Emulator.
