# M305 · Fire Tuner, застрявшая стрела и единый Atlas Registry для оружия

## Назначение и границы

M305 накладывается **поверх M304**. Стрельба, урон, headshot, серверная баллистика и LandscapeSwayController не переписываются. Отработанный M303 `Fire Tuner` не устанавливается общим Studio Plugin installer: установка остаётся **отдельным явным действием** с копированием старого локального файла в `%LOCALAPPDATA%\Game1\FireTunerBackups` перед заменой.

### Fire Tuner

* Базовый архив, доступный ассистенту, содержал устаревший Fire Tuner, без первоначальной системы пресетов пользователя. Их уникальные значения **не восстановлены** из архива; новый механизм сохранения/применения пользовательских пресетов добавлен в исходник. Установщик отдельно делает резервную копию предыдущего локального файла.
* Любая выделенная `Bone` независимо от имени. Текущие настройки Fire, PointLight и Orb не обнуляются при выборе кости; встроенные пресеты применяются только при щелчке.
* Огонь направляется Tail → Head через один `Game1FireDirection` Attachment с локальным поворотом на 180° вокруг X. Авторские `Bone.CFrame`, `PivotOffset`, имя кости и скелет не меняются.
* Пользовательские пресеты Fire/Light/Orb сохраняются через `plugin:GetSetting`/`plugin:SetSetting` под `Game1_FireTuner_UserPresets_v1`. Ранее не полученные значения пользовательских пресетов невозможно обещать восстановить.
* `system/studio-plugin/recover-fire-tuner.ps1` (ошибочная M304 recovery-утилита) удалён, и никакой фоновый recovery не выполняется.

### Застрявшая стрела

* Серверный `BowProjectileService` сохраняет расчёт попаданий, определение headshot и логику `LandscapeSwayService.Impact`.
* При пересечении доступного для запроса элемента `LandscapeSwayTarget` дочерняя косметическая модель стрелы помещается в родительский ландшафтный Model. `LandscapeSwayController:PivotTo()` двигает фонарь и его стрелу как одну визуальную иерархию; **нет** нового контроллера, физической сварки или отслеживания каждый кадр.
* Пробитие `penetrationStuds` (0–3 studs, по умолчанию 0.12) задаётся для Arrow Asset. Место останова вычисляется по переднему краю фактической 3D-геометрии стрелы с учётом выбранной оси модели. В уже выпущенные стрелы изменение настройки не вносится.
* Попавшая стрела — косметический объект на 2.5 секунды, не постоянное состояние мира и не новая сохранённая сущность.

### Shared atlas для оружия и стрел

* Централизованный `AtlasRegistry` — единственный источник опубликованных Image Asset ID. Тот же выбор семейства/варианта/ревизии, что уже используется Location Assets. Никаких новых текстурных публикаций при выборе уже опубликованного атласа.
* `WeaponStore` / `ArrowStore` отвечают за слуги, статусы, экспорт игровых реестров; `AtlasRegistry` — за варианты, их ревизии, историю и синхронизацию потребителей. Композиция зависимостей остаётся в `host_agent.py`. Существующие локальные текстуры остаются, но не считаются активными при выбранном общем варианте.
* UI отображает выбор опубликованного варианта и статус `pending_studio_sync`. **Select/Unbind не публикуют и не синхронизируют автоматически.** Publish и Sync Studio — отдельные пользовательские действия с состояниями выполнения.
* Существующая `StudioAssetSyncService` передаёт выбранный опубликованный Image ID в штатный Studio Bridge; статус `synced` выставляется лишь после подтверждения применения к MeshPart. Регистры генерируются из сохранённого состояния.
* У стрел есть необязательная аддитивная SQLite-миграция `penetration_studs`; при повторной регистрации сохраняются опубликованные ID и старые файлы.

## Установка и проверка

1. Применить M305 поверх M304 обычным `git apply --check` / `git apply`.
2. **Явно** выполнить `system/studio-plugin/install-fire-tuner.ps1`; проверить показанный путь резервной копии. После этого выполнить стандартный `system/studio-plugin/install.ps1` и `control-center.ps1`.
3. Перезапустить Roblox Studio, синхронизировать Rojo и обновить Control Center (`Ctrl+F5`).
4. Выбрать произвольно названную Bone, убедиться в Tail → Head, сохранить и применить пользовательский пресет, затем переключить кость и повторить.
5. Выпустить стрелу в качающийся фонарь: 2.5 секунды визуальная стрела должна двигаться с фонарём. Проверить `penetrationStuds=0` и `0.3` при разных `forwardAxis`.
6. Выбрать уже опубликованный атлас у оружия и у стрелы — **не должен** начинаться upload или Studio Sync. Явно нажать Sync Studio и проверить изменение текстуры.

Не протестировано в живом Roblox Studio Play/Open Cloud: динамика потомков PivotTo, внешний вид огня на конкретном авторском FBX, применение MeshPart текстур. Автоматические проверки покрывают контракты и вызовы; окончательный тест обязателен на сохранённой копии Place.
