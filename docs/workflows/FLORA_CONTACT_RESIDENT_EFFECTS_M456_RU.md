# M456 · Flora contact VFX / resident assets

## Домен и владение

- **OptionsStore → GameOptionsRegistry.flora** — единый типизированный контракт для настройки эффекта. `Options → Flora` редактирует только эти параметры; обратная совместимость старых options.json обеспечивается добавлением отсутствующего блока. `residentAssets` — строгий список из 1–8 опубликованных одно-визуальных Location моделей. `leafAssetSlug` должен быть опубликованным `leaf` и находиться в resident list.
- **LocationResidentTemplateService** — серверное единократное размещение разрешённых прототипов в ReplicatedStorage через **уже существующий** `LocationLodTemplateService.loadPrototype`. Не создаёт визуальных экземпляров в Workspace. Работает и для Studio Play, и для compiled Runtime.
- **FloraContactIndex** — клиентский индекс геометрии деревьев/кустов. В **Studio Play** используется один первоначальный Scan реальных моделей по `Game1DecoAssetSlug`/`LandscapeAssetSlug` с последующими Workspace events; в **compiled Runtime** для потоковых размещений используются проверенные расположения/размеры из `LocationRuntimeManifestContract` (исходные визуальные MeshPart там удалены компилятором), а Flora с выключенным LOD продолжает индексироваться из неизменённых Workspace моделей. Обе ветви имеют единый spatial query API. Пространственная сетка 32 studs; модели с аномально большими bounds пропускаются с warning.
- **FloraLeafPool** — один экземпляр поддерживаемого опубликованного MeshPart, визуальная настройка из `LocationAssetRegistry.meshOptions`, best-effort предварительная загрузка MeshId/атласа через ContentProvider, затем фиксированный пул (по умолчанию 32). При недоступности прототипа или ошибке загрузки эффект **не** запускается вместо появления бесцветного листа. Не создаёт MeshPart во время столкновения.
- **FloraLeafBurstController** — только локальный presentation: до 8 листьев по умолчанию, направление с рандомизацией и движением персонажа, локальный радиус старта/разлёта, движение при 30 Гц и плавное исчезновение. Глобальный cooldown 1,5 s, не вызывает RemoteEvents. Не используются физические объекты, Touched или CanCollide.

## LOD и жизненный цикл

`Game1ResidentEffectTemplates` и пул хранятся вне Workspace/визуального LOD Manager. Выгрузка конкретного дерева, куста или размещения `leaf_01` **не уничтожает шаблон эффекта**. Ресурсы могут быть выселены движком из GPU/HTTP cache при давлении на память: `ContentProvider:PreloadAsync` и постоянные ссылки снижают риск, но не дают платформенной гарантии 100% residency. Мы не закрепляем *все экземпляры* `leaf_01` в Workspace — это потребовало бы неограниченного числа объектов и нарушило бы назначение LOD.

Эффект не является серверной механикой столкновения, не наносит урон, не даёт ресурсы, не реплицируется другим игрокам. В спокойном состоянии пул не обновляется и не рендерится. Ранний выход при нулевом движении, телепорте или cooldown. В отличие от реальных контактов, вход в авторский bounding box даёт приближённый визуальный сигнал — без дорогостоящих физических проверок. Изменение геометрии при Studio Sync требует рескана/Play; лёгкий LandscapeSway покрывается допуском контакта.

## Проверка в Studio Play (ещё не выполнена удалённо)

1. Убедиться в Output: `[game1][flora] local leaf pool ready: leaf_01`. На клиенте проверить Mesh ID и Image ID оригинального `leaf_01`, наличие атласа на всех восьми эффектах.
2. Пройти через `thuja_02`, `christmas_tree_01`, `bush_02` (DecoManager и LandscapePainter), убедиться в эффектах даже при `CanCollide=false`, в отсутствии листьев при стоянии и повторении не чаще сохранённого cooldown.
3. Удалиться от размещённых растений/листа за порог LOD, затем быстро вернуться и снова пройти: лист появляется с атласом без задержки.
4. Быстро пробежать через узкий куст, сменить персонажа, выполнить respawn, проверить StreamingEnabled на ПК и телефоне. Пул не превышает `maxActiveLeaves`; нет физических или сетевых листьев.
5. Выключить `enabled` в Options, Save, Rojo Sync и Play; не должно создаваться активных листьев. Неподходящий/не опубликованный resident slug отклоняется серверной валидацией Options.
