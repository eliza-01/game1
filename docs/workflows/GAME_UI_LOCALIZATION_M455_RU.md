# M455 · Локализация игрового UI Game1

## Границы и источник данных

- Только Roblox Runtime. Административный Control Center и Studio Debug **не локализуются**; раздел `Options → Languages` предназначен для просмотра игровых переводов.
- Единственный редактируемый источник: `assets/manifests/game-localization.json` (schemaVersion 1). Группы `language`, `action`, `hud`, `weapon`, `feedback`, `actors`, `items` содержат ключ, исходную строку и все 10 переводов.
- `system/control-center/localization/catalog.py` валидирует схему, дубликаты, ключи, полноту языков и генерирует `src/shared/localization/GameTextCatalog.luau` для Rojo. Контроль синхронности: `python system/control-center/localization/catalog.py --check`.
- Options `GET /api/options/languages` — **только чтение**. Переводы не входят в `options.json` и не записываются через `POST /api/options`.

## Язык и владелец состояния

- Клиент выбирает язык: `LanguageState` владеет текущим локальным locale ID, переводом по ключу, просмотром оригинальной серверной строки и уведомлением UI об изменении. Ничто в Combat/SocketService не зависит от выбора.
- `LanguageMenuController` отвечает только за представление выбора. При первом посещении показывает окно; для возврата есть кнопка «🌐 Язык». При уже сохранённом выборе меню можно открыть вручную.
- `PlayerLanguageService` — серверный *необязательный* сервис, проверяет коды из `LanguageContract` и записывает предпочтение в DataStore `Game1PlayerLanguage_v1` по UserId. RemoteFunction `Game1Remotes.SetPlayerLanguage` принимает только string из списка; возвращает `{ok, locale? ,error?}`. `error`: `unsupported_locale`, `rate_limited`, `save_unavailable`. Других персональных данных не сохраняет.
- Если DataStore недоступен (Studio/API disabled), текущая локальная сессия работает в выбранном языке, а меню предупреждает, что выбор не был сохранён. Повторная попытка/продолжение не блокирует игровой Runtime.
- До загрузки предпочтения временно используется `Player.LocaleId`, нормализованный через `LanguageContract.Normalize`; неизвестные языки — `en-us`. Загрузка сохранения не блокирует CharacterService.

## Перевод игровых данных

- Серверные ProximityPrompt.ActionText сохраняют исходные строки для валидации доменной логики. Их переводит `HouseSocketPromptController` только в презентации, сохраняя E/F, условия и лимиты.
- Игровые уведомления, ресурсы, камин, боевые метки, экран смерти и Debug Weapon Selection переводятся по тем же исходным ключам. Динамический номер этажа заполняется именованным параметром `{floor}`.
- Имена зарегистрированных NPC/монстра и оружия получают стабильные ключи `actors.<slug>` и `items.<slug>`; неизвестные будущие slugs остаются с текущим authoring-именем до добавления перевода. Имена *пользователей* не переводятся.
- Статические TextLabel/TextButton в PlayerGui переводятся через один контроллер с наблюдением за появлением и изменением Text; AutoLocalize отключается на контролируемых виджетах для предотвращения конкуренции с языком аккаунта Roblox. Внутренние имена, Asset IDs и пользовательский ввод не трогаются.
- Новые UI-компоненты должны использовать `LanguageState.Translate("group.key", params)` для динамики или известную `source`-строку для автоматического наблюдения. Нельзя добавлять новую жёстко зашитую надпись без ключа и переводов всех языков.

## Локали

`ru-ru`, `en-us`, `de-de`, `zh-cn` (упрощённый китайский), `it-it`, `es-es`, `fr-fr`, `pt-br`, `ja-jp`, `ko-kr`.

## Минимальный Studio Play / опубликованный Runtime smoke (вручную)

1. Войти новым игроком, проверить модальное окно, все 10 языков, выбор и сохранение; перезайти и убедиться, что сохранённое предпочтение восстановлено. В Studio без API DataStore проверить предупреждение и игровой fallback.
2. Переключить язык во время открытого диалога двери/костра; проверить E/F, русскую и немецкую надпись, отсутствие влияния на действие.
3. Проверить локализацию камина (горение, готовка, ресурсы), уведомлений лифта/замка/двери, экрана смерти и имени монстра/NPC.
4. На ПК и мобильном проверить длинные немецкие/французские строки и китайские/японские/корейские шрифты, прокрутку выбора и перерисовку окон.
5. В опубликованной игре проверить сохранение PlayerLanguage после повторного подключения, в том числе смену языка без DataStore/API Errors.

Запуск в Studio Play и опубликованной Roblox Experience из этой среды **не выполнен**. Luau guard + Python/JS + verify.py не заменяют этот шаг.
