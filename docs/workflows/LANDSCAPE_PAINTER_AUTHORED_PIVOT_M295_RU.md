# M295 · Landscape Painter — сохраняем исходный pivot FBX/рига

## Причина регрессии M294

`LandscapeSurface.Pivot` ставил `Model:GetPivot()` ровно на поверхность (или на
конец подвеса), не учитывая реальное расстояние от опубликованного FBX pivot до
опорной геометрии и оригинальную ориентацию FBX. В результате при обычном
размещении pivot оказывался на уровне земли/дна меша. `DecoManager` использует
`DecoTransform.supportOffset` и `DecoTransform.authoredPivotRotation`, поэтому
его результаты отличались, хотя оба инструмента загружают один опубликованный
риг через `DecoAssetLoader`.

## Исправление

- `DecoTransform` подключён в Landscape Painter прямо из Studio Plugin, без
  копирования алгоритма и изменения `DecoAssetLoader`.
- Для поверхности без подвеса `supportOffset` поднимает исходный pivot так, чтобы
  **геометрия**, а не pivot, касалась поверхности. Оригинальные
  `rig_carrier.PivotOffset`, `PrimaryPart`, `Bone.CFrame`, `Motor6D` не изменяются.
- Для стебля без подвеса точка выбора остаётся точкой размещения исходного pivot.
- Для подвеса верхняя точка — выбранная поверхность/стебель, нижняя —
  **исходный** pivot на расстоянии `length` по мировой вертикали. Для декоративной
  нити и `RopeConstraint` используется одна и та же позиция нижнего конца.
- В обоих режимах используется авторская FBX ориентация, сохранённая на
  отдельном шаблоне до создания предпросмотра. `Surface.Pivot` перемещает
  Model целиком, а не меняет внутренние координаты меша/скелета.
- Предпросмотр, `Click` и повторное `Apply` работают с общим расчётом, а не с
  пересчитываемым при каждом клонировании bounding-box pivot.

## Модели, размещённые до M295

Существующие объекты не изменяются автоматически. Новый объект сохраняет
`LandscapeSchemaVersion=3` и `LandscapeAuthoredPivotRotation`,
`LandscapeAuthoredSupportOffset`, `LandscapeFacingDirection` для
воспроизводимого `Apply` независимо от текущего положения камеры.

У моделей до M295 исходную ориентацию нельзя надёжно восстановить из их
**уже изменённого** world pivot. Для их исправления:

1. В Landscape Painter выбери исходный опубликованный ассет (тот же Model Asset ID).
2. В Explorer выдели ранее размещённую модель.
3. Нажми `Apply` с нужными настройками: процедура получит исходную ориентацию
   и геометрию из выбранного опубликованного шаблона, исправит размещение и
   сохранит метаданные схемы 3.

Если соответствующий опубликованный ассет не выбран, `Apply` отменяется с
понятным сообщением **до** начала Undo-записи: нельзя угадывать FBX pivot.

## Проверка в Roblox Studio Edit / Play

1. Выбери скелетный Location с очевидным pivot внутри объекта; сравни то же
   опубликованное изделие в DecoManager и Landscape Painter.
2. Поставь без подвеса на Terrain: геометрия касается поверхности, pivot рига
   остаётся на своём исходном месте **относительно меша/костей**.
3. Поставь на тонкий стебель; проверь совпадение исходного pivot с точкой выбора.
4. Включи декоративный подвес: линия начинается в точке выбора и заканчивается
   на исходном pivot ниже неё (но не на нижней границе меша).
5. Включи физику и Play: `RopeConstraint.Attachment1` совпадает с исходным pivot,
   фонарь висит и раскачивается средствами Roblox.
6. Проверь `Apply` для новой модели и для старой модели при выбранном её
   исходном asset ID, затем Undo/Redo и отсутствие дублей Attachments.

Автотесты не заменяют реальную проверку Bones, импортированного MeshPart
и физической симуляции внутри Roblox Studio.
