# M294 · Landscape Painter · Pivot, тонкие стебли, физический подвес

## Размещение

- Без подвеса `Model:GetPivot()` совпадает с точкой крепления на стебле или поверхности.
- С подвесом точка крепления остаётся в месте наведения, а Pivot ассета находится
  **ниже по мировой оси Y** на заданную длину. Отрезок соединяет ровно эти точки.
  Направление не зависит от нормали стены/потолка: фонарь подчиняется гравитации.
- Стебли с толщиной 0.05 studs (и меньше) по-прежнему могут иметь `CanQuery=false`.
  Их ищет только аналитический геометрический прицел `LandscapeStemTarget` по
  оси конечного сегмента. Допуск увеличен для удобного наведения на тонкий стебель,
  проверка перекрывающей поверхности остаётся; обычные цилиндры не распознаются.
  Режим «Только поверхность» преднамеренно игнорирует стебли.

## Чекбокс «Физика подвеса»

- Не отмечен: части модели сохраняют `Anchored=true`. Если включён декоративный
  «Подвес», видимая нить создаётся прежним `BranchGeometry.Apply`.
- Отмечен: автоматически включает подвес. `LandscapeTetherPhysics` создаёт
  один невидимый **anchored Part** с верхней `Attachment` в точке крепления,
  нижнюю `Attachment` непосредственно в Pivot ассета, а между ними
  **штатный `RopeConstraint`** (длина, толщина, приблизительный BrickColor).
  Его `Visible=true`, поэтому дополнительный декоративный Part не создаётся.
- Сам ассет становится `Anchored=false`: Roblox сама моделирует гравитацию,
  натяжение, раскачивание, столкновения. Для многочастной статической Location
  модели подключаются только отсутствующие связи `WeldConstraint`; уже
  существующие Weld/Motor6D/кость `rig_carrier` не переписываются. Нет Heartbeat,
  физической эмуляции скриптами и серверных RemoteEvent.
- Невидимый anchored Part принадлежит **только размещённой Model**, а не
  стороннему Terrain/Part или опубликованному шаблону. Это стационарный верхний
  конец: автоматического крепления к динамически движущимся поверхностям нет.
  Удаление модели удаляет верхнюю точку и Rope; никаких объектов снаружи не остаётся.
- Физика проявляется в Play / физическом режиме Studio. В Edit до симуляции
  модель сохраняет предварительно выбранное висячее положение.

## Совместимость и границы

- `physicsEnabled` — необязательное поле профиля. Старые профили без него
  интерпретируются как `false`; старые объекты не пересоздаются автоматически.
- У новых размещений `LandscapeSchemaVersion=2` и новый атрибут
  `LandscapeTetherPhysicsEnabled` (остальные имена и опубликованные ID сохранены).
- `Use` использует весь сохранённый профиль; `Apply` пересоздаёт только управляемый
  подвес выбранной модели, сохраняет её источник, ID и точку крепления. Все
  действия остаются в Studio Undo/Redo; старый Anchor можно вернуть через Apply.
- При изменении профиля legacy-объекта с декоративным подвесом его Pivot
  будет перепозиционирован по новому правилу вниз, только после явного `Apply`.
- Инструмент не создаёт физические ограничения для уже размещённых моделей
  автоматически. Другие плагины, DecoManager и игровая логика не изменены.

## Ручной Roblox Studio smoke-test (автоматика его не заменяет)

1. В Edit без подвеса поставить ассет на Terrain, стену и стебель 0.05:
   курсор выбирает точку, Pivot совпадает с ней, ЛКМ создаёт объект.
2. Включить «Подвес» без физики: Pivot расположен на `length` ниже крепления,
   линия от крепления до Pivot, все части `Anchored=true`.
3. Включить «Физика подвеса», поставить фонарь на потолок и стебель:
   внутри модели видны `LandscapePhysicsAnchor` и `LandscapePhysicsRope`, в
   обеих физических точках — Attachments; авторские MeshParts не заменены.
4. Начать Play: фонарь висит и качается под силой тяжести, не падает на землю;
   проверить rigid assembly на многочастном / skinned опубликованном ассете.
5. Сохранить Use профиль, применить Apply, снять физику через Apply,
   проверить Undo/Redo, отсутствие дублированных Attachments/Constraint,
   и повторное открытие Place.
