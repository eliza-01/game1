# M254 · Location Asset Studio Sync доступен для любой записи

Кнопка `Sync Studio` справа от `Edit` больше не зависит от агрегированного
статуса Location Asset. `UPDATE_AVAILABLE`, `LOCAL_ONLY` и `INCOMPLETE` не
скрывают действие: пользователь может открыть workflow и запустить `Find`.

Сервер не принимает локальные файлы как опубликованные ресурсы. Перед командой
Studio он отдельно проверяет опубликованный Model Asset ID, прямую atlas-привязку,
опубликованный Image ID и revision привязки. Поэтому новая ревизия с сохранёнными
опубликованными ID синхронизируется, а действительно неопубликованный ресурс
получает точную ошибку о Model или Atlas вместо общей блокировки по статусу.

Контракт M216 сохраняется: команда scoped одним slug и не создаёт размещение;
`Find` остаётся read-only, а `Sync` изменяет только явно найденные управляемые
экземпляры.
