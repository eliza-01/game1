# M411 · Повторное использование опубликованной LOD1-модели

Один Roblox Model Asset ID может использоваться как LOD1 несколькими зарегистрированными Location Assets и Real Estate. Публикация модели не повторяется. Это **привязка к неизменяемому опубликованному ID**, а не ссылка на изменяемую настройку другого ассета.

## Редактор

Вкладка Location Assets → LOD1 и секция Real Estate → Runtime предлагают `Choose LOD1 FBX` и `Use published LOD1`. Библиотека содержит только собственные **прямые опубликованные** LOD1 из Location Assets / Real Estate. Показаны источник, ревизия и Roblox Model ID. Можно искать по имени и ID. Кнопка выбора применяет привязку без Open Cloud, нового FBX или изменения Studio.

После выбора в карточке видно происхождение LOD1. Сохраняются Model ID исходника, его SHA, домен, slug и ревизия. Если источник позже получает новую публикацию или удаляется из реестра, целевой ассет **не переключается автоматически**. Целевая запись сохраняет закреплённый Model ID.

Регистрировать собственную FBX-ревизию по-прежнему можно. В этом случае происхождение повторно используемого LOD сбрасывается; до новой публикации готовность определяется обычными проверками.

## Общий контракт

- `GET /api/lod1-library` — каталог прямых опубликованных LOD1.
- `POST /api/location-assets/{slug}/lod1-reuse` и `POST /api/real-estate/{slug}/lod1-reuse` принимают точные `sourceDomain`, `sourceSlug`, `sourceRevision`, `sourceModelAssetId`, `expectedRevision`; любой устаревший выбор отклоняется.
- Миграции SQLite аддитивны; перед изменением сохраняют полные копии БД. Истории публикаций и исходники не изменяются.
- Общий Runtime Builder и LocationWorldStreamer получают существующий `ModelAssetId` через действующие структуры. FULL-модели, Plot, коллизии и сокеты не затрагиваются.
- Исторические прямые публикации в базах остаются без изменений. Повторная привязка не добавляется в историю **Open Cloud публикаций**, поскольку никакой публикации не было.

## Границы и проверки

Выбирать следует LOD со схожими пропорциями, центром и масштабом. Совпадение pivot/габаритов разных FBX не может быть доказано только по Model ID; необходим визуальный тест переключения FULL ↔ LOD1 в Studio/DEV. Общий Model ID может дать повторное использование загруженного геометрического ресурса, но **не устраняет расходы на экземпляры и не гарантирует снижение памяти без измерений**.

Roblox Studio Play и мобильный DEV нельзя считать проверенными только на основании Python/JS тестов.
