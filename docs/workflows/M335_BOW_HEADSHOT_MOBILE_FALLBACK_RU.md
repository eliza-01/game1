# M335 · Bow headshot in permission-safe hitbox fallback

## Где находилась ошибка

M333 создал геометрию `root_bounds_fallback` при запрещённом `EditableMesh`,
а M334 расширил Body до **всего** `RootCollider`, чтобы стрелы не пролетали
мимо. Из-за этого серверный `HitboxSpatialQueries.AimContact` сравнивал
ближайшее расстояние до Head и Body. Луч через голову сначала встречает
наружную грань большого Body-бокса, затем вложенный Head; поэтому `head`
перезаписывался на `body`. Особенно заметно на мобильном с точным прицелом.

## Контракт после M335

- Луч на любом устройстве: `CameraController.GetAimRay` (точка ретикла)
  → `AttackController` → однократный `BowAimUpdate`
  → `BowHitscanService.Capture` → `EntityHitboxService.RaycastAimRegions`.
- В режиме `root_bounds_fallback` при реальном пересечении Head-бокса
  результат остаётся `head`, даже если полный RootCollider дал более близкий
  `body`-контакт. Луч только через Body остаётся `body`; вне обеих зон — промах.
- В режиме `precomputed_bone_boxes` всё по-прежнему: точная геометрия,
  эллипсоид головы и ближайший контакт без изменения приоритета.
- Автонаведение на `neck`/`spine.003` **не изменено**. M335 не переносит
  точку прицела, не добавляет автоheadshot и не меняет дальность или урон.
- `DamageService` получает существующий флаг `headshot`, отображение
  `Headshot` исходит из серверного `CombatFeedback`.

## Почему Test Loadout не показывает хитбоксы в опубликованной игре

`EntityHitboxService.publishDebugData` создаёт `CombatHitboxDebugData`
**только в Studio**. Клиентский Test Loadout читает именно эти записи.
Отсутствие визуальных боксов на телефоне не означает отсутствия боевых
хитбоксов на сервере. Этот инструмент M335 не расширяет.

## Проверка на Android и ПК после публикации

1. На Gremlin посмотри `CombatHitboxMode`: при отсутствии EditableMesh ожидается
   `root_bounds_fallback`, а `CombatHitboxCount` должен быть > 0.
2. Стреляй вручную в центр головы и отдельно в грудь (5, 20, 39 studs).
   По голове ожидается `Headshot`, `LastHitZone = head`, `LastHeadshot = true`;
   по телу `LastHitZone = body`, `LastHeadshot = false`.
3. Отдельно попробуй мобильное автонаведение, не меняя его поведение:
   для Gremlin это точка `spine.003`; headshot происходит **только** если
   фактический серверный луч пересёк Head, а не из-за включённого auto-aim.
4. Убедись, что стены блокируют попадание; одиночный выстрел не наносит
   двойной урон и не создаёт лишних проверок за время полёта стрелы.

Проверки Python охватывают детерминированные пограничные случаи,
но не заменяют фактический двухклиентный Play на устройствах.
