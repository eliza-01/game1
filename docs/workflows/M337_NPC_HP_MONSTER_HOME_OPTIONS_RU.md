# M337 · NPC UI, возврат монстров, home radius и компактные Options

## NPC над головой

- `NPCs` обрабатываются отдельным `NpcOverheadController`, который использует общий `HealthBarView`, а не новую разметку HP.
- Имя NPC видно на расстоянии до `npcOverhead[device].nameRadiusStuds` (по умолчанию 70).
- HP видно, только если NPC ранен (`HP < MaxHP`) **или** его текущая `NpcTargetUserId` совпадает с локальным игроком; независимо ограничено `healthRadiusStuds` (по умолчанию 70).
- Оба радиуса меряются от персонажа, не от камеры; в момент смерти не показываются. Профили PC/Mobile независимы.
- При StreamingEnabled отсутствующий `RootCollider` ожидается событийно; прежний UI уничтожается при выгрузке collider и создаётся вновь, без множества BillboardGui.

## Monster: Return

Серверный `MonsterAIService` использует существующие `MonsterChaseNavigation` и `ActorDamageSignals`.

1. С момента выбора цели начинается таймер. После **реально нанесённого** монстром урона игроку он сбрасывается.
2. Если за `monsterAi.noDamageReturnSeconds` (по умолчанию 30) нет успешного нанесения урона, прекращаются погоня и текущая атака, очищаются target и combat feedback; состояние переходит в `Return`.
3. Пересечение `homeRadiusStuds` (проверка от *центра авторской точки спавна*) со стороны цели или самого монстра также запускает `Return`.
4. Возврат осуществляется существующей навигацией к запомненной **наземной** исходной позиции экземпляра. Точка хранится до анимации появления из-под земли.
5. После достижения дома монстр снова может искать цель согласно `MonsterAggressive`. Если он получает урон на обратном пути, немедленно переходит в агрессию, без ожидания очередного сканирования.

Внимание: `spawnRadius` — область рождения/блуждания нескольких экземпляров; **не** радиус прекращения погони. `homeRadiusStuds` — отдельное значение для конкретного spawn record. Для NPC используется уже существующий `NpcCombatAIService` с индивидуальным leash по `NpcHomeRadiusStuds` (если поле отсутствует — 16 studs).

## Asset Manager

Options теперь состоят из раскрывающихся разделов с пиктограммами: Combat & AI, Movement, Camera, Health UI, World, Debug/TestPlace. Прежние HTML ID сохранены. Профили NPC отображения также разделены по устройствам. В `Monsters → Spawn` и `NPC → Spawn` добавлен `home leash` от авторского центра.

## Применение и тестирование

После `git apply` выполнить `python system/verify/m337_refresh_registries.py`, затем Rojo Sync, Studio Plugin и Control Center. Миграция не перезаписывает сохранённые значения Options, а регенерирует только отсутствующие ключи и runtime-реестры spawn.

Проверить в Studio/опубликованном Place: NPC без урона только с именем; раненого NPC с HP; NPC при атаке игрока; уход NPC из радиуса; монстра, который 30 секунд не может нанести урон, и повторное нападение во время `Return`; выход за границу spawn radius; подъём из-под земли без возврата под Terrain.
