# M338 · Monster pursuit radius from spawn · исправление M337

**Раздельные радиусы:**

- `Monsters → Behavior → Aggro radius`: когда монстр самостоятельно обнаруживает игрока (из позиции монстра).
- `Monsters → Behavior → Pursuit radius from spawn`: граница преследования по горизонтали **от центра авторской точки спавна**. Индивидуальная настройка каждого вида монстра, по умолчанию **150 studs**. Никакой связи с `Spawn radius`.
- `Monsters → Spawn → Spawn radius`: только область случайного появления и обычного патрулирования группы.
- `Options → Combat & AI → Monster return`: возврат после **30 секунд без нанесённого монстром урона**, если радиус преследования ещё не пересечён.

**Состояния:** `Aggro → Chase → Attack`, затем `Return` при достижении границы преследования или истечении таймера. При возврате монстр идёт к исходной точке конкретного экземпляра, а не к случайному месту в зоне. Если игрок наносит ему урон во время возврата, монстр немедленно снова агрится; граница преследования продолжает действовать.

**Исправленная регрессия M337:** поле `Monsters → Spawn → Home leash` удалено. Старое `homeRadiusStuds` у монстров удаляется из манифеста и runtime-реестра при миграции. Поле NPC `homeRadiusStuds` не меняется. Старые маркеры Studio остаются привязаны к тем же spawn ID; изменение per-species behavior не делает их устаревшими.

**Безопасная миграция:** `python system/verify/m338_migrate_monster_pursuit.py`. Перед изменением выполняется SQLite backup через `sqlite3.backup()` и сохраняются манифесты и оба генерируемых реестра в `.m338_backup_<timestamp>`. Сервис `MonsterStore` добавляет колонку `monster_behavior.pursuit_radius_studs` через `ALTER TABLE`, а затем регенерирует `MonsterRegistry.luau` из реальной базы. У всех существующих видов по умолчанию появляется 150 studs без потери опубликованных ID; далее радиус можно сохранить отдельно для любого вида через Monsters. Повторный запуск миграции сохраняет индивидуально настроенные радиусы.

**Проверка Roblox Studio Play:** начальный Gremlin с `spawnRadius=15` может преследовать игрока дальше 15 и 40 studs (например, до 100 studs), но вернётся, когда игрок либо монстр превысит 150 studs от центра spawn-point; без урона в течение 30 секунд также вернётся. Удар по возвращающемуся Gremlin снова вызывает агрессию. Второй вид монстров с другим `Pursuit radius` должен вести себя независимо. Физическую навигацию проверить на реальном Terrain.
