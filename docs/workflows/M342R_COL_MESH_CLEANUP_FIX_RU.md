# M342R — корректировка удаления COL-мешей

## Что произошло

M342 успешно изменил реестр ассетов, однако профильный тест на Windows
оставил SQLite соединение открытым и завершился `WinError 32`. PowerShell
не дошёл до установки нового Studio Plugin, поэтому Workspace физически не
очищался. В Place Registry оставалась устаревшая проверка обязательного COL.

## Что исправлено

- Тестовая SQLite закрывается явно.
- Place Registry и Location Assets UI больше не требуют `col_mesh`.
- Studio Bridge при запуске в Edit Mode очищает COL внутри управляемых домов,
  **а также старые безатрибутные размещения** внутри `Workspace.Places`,
  `Workspace.Plots` и шаблоны ServerStorage.
- Старые ссылки на COL в опубликованных моделях не являются обязательной
  частью нового рига. Загруженные в Studio экземпляры очищаются.
- Исторический Roblox Model Asset ID не изменяется: ранее опубликованную
  модель невозможно редактировать по тому же ID.

## Проверка

После установки нового плагина **полностью закрой и заново открой Studio**.
В Edit Mode дождись `[game1 plugin] M342R COL cleanup` в Output, проверь
Explorer и сохрани Place (Ctrl+S / Publish при необходимости).
Затем повтори Place Registry Scan: «Нет обязательного COL-меша» исчезнет.
«Нет отдельной Model» и «Нет Placement ID» — отдельная проблема
старой привязки, они остаются до Repair/Sync.
