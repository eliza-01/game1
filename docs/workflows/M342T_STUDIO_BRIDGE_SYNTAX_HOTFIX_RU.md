# M342T — восстановление запуска Game1Bridge после M342R

## Причина

В `StudioPlaceRegistryInventory.luau` при удалении требования `COL` исчезла завершающая запятая поля `needsStructure` таблицы `row` перед `duplicateId`. Roblox Studio выдавал `Expected "," after table constructor element` (строка 375), после чего `require(StudioPlaceRegistryCommands)` и `require(Main)` переставали работать. Поэтому одновременно пропали Plots и Place Registry.

## Изменения

1. Восстановлен разделитель полей Luau таблицы. Логика регистратора и миграция `COL` не изменяются.
2. В `validate_luau.py`, который установщик выполняет **до замены установленного плагина**, добавлена прицельная проверка этого шаблона ошибки.
3. В `test_studio_luau_preflight_m139.py` добавлен регрессионный тест с заведомо испорченным примером; два устаревших утверждения тестов актуализированы после удаления legacy sync и перехода установщика на `$RojoExe`.

## Порядок установки

- Применить M342T поверх M342S (M342R и M342 уже установлены).
- Запустить профильный unittest, `verify.py`, затем `validate_luau.py`.
- Закрыть Studio, установить Game1Bridge командой `./system/studio-plugin/install.ps1`, вновь открыть Studio в Edit Mode.
- Проверить появление кнопки `Plots` и успешное завершение Place Registry Scan; в Output не должно быть ошибки `Expected "," ... StudioPlaceRegistryInventory`.

## Область изменения

Никакой повторной миграции SQLite, перепубликации ассетов или перезапуска Rojo не требуется. Исправление касается только исходника Studio-плагина, его установочного preflight и теста.

## Ограничение

Текущий `validate_luau.py` — не полноценный парсер Luau. Новая проверка предотвращает именно обнаруженную регрессию. Общую синтаксическую корректность нужно подтверждать настоящим Luau-компилятором/парсером или запуском в Studio.
