# M346 · Источник Pivot в Instance Manager

База: M345 поверх M344, **без M344A**. Никаких изменений регистрации, публикации, FBX, Pivot ассетов или коллизий.

## Исправление смысла выбора

В M345 список опор был ошибочно сформирован по **новой** опубликованной Model. Теперь `Preview` читает реальные **старые размещённые экземпляры** (Source), и предлагает:

- `Pivot старой Model` — по умолчанию, сохраняет корректную замену после размещения DecoManager;
- `Pivot MeshPart N · путь` — точка и поворот выбранного MeshPart **старой** Model.

У новой опубликованной Model всегда берётся её **Model Pivot**; он совмещается с выбранным старым Pivot. Ни модель, ни отдельные MeshParts не перенастраиваются. Копируются и позиция, и поворот (`CFrame`), масштаб Model (`GetScale()` → `ScaleTo()`). Положение и масштаб физических коллизий нового Blueprint обновляются после позиционирования.

При `Replace All`, если старые экземпляры имеют разные структуры, предлагаются только MeshParts с одинаковым порядковым номером, вложенным путём и Mesh ID у всех затрагиваемых экземпляров. `Pivot старой Model` доступен всегда. Это предотвращает случайную привязку к разным частям при массовой замене.

## Важное ограничение масштаба

Масштабирование *самой Model* (`Model:GetScale()`) сохраняется. Индивидуальные ручные правки `Size`/`CFrame` внутренних MeshParts **не являются масштабом Model** и не могут автоматически воспроизводиться при полной замене всех внутренних частей. В таком случае опорный Pivot MeshPart может восстановить позицию/поворот, но для восстановления особого размера потребовалось бы отдельное правило масштабирования, которое здесь не добавляется (нельзя угадывать его по габаритам).

## Проверка

1. В Location Assets открой Instance Manager. Выбери Source и Target, область `Selected`.
2. В Studio выдели один старый экземпляр. `Preview replacements` → выбери **Pivot старой Model** или **Pivot MeshPart** нужной старой части.
3. `Replace Models`; убедись в положении, повороте и физических коллизиях. Повтори на экземпляре, поставленном DecoManager: стандартный Model Pivot должен совпасть с M345.
4. Для массовой замены сначала сохрани Place и проверь Preview: список опор может быть ограничен общими MeshParts.

Только Studio Edit Mode, требуется обновление Game1Bridge и перезапуск Control Center. Проверка в реальном Studio — отдельная приёмка, не заменяется статическими тестами.
