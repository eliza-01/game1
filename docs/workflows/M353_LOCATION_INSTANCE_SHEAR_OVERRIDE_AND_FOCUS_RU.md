# M353 · Instance Manager: Shear override and collision focus

В `04 · Workspace instances` для замены Location Asset доступны:

1. **Preview replacements** — чтение исходных размещений, формирование `scanToken`.
2. **Show collision preview · Studio** — временные визуалы будущей модели и примитивы коллизий, без изменений исходных Model. Возвращается уникальный `inspectionToken` и список превышений с путём, ID Collision Part и приращениями по X/Y/Z.
3. **Показать в Studio** в списке превышений — перемещение только камеры к оранжевому блоку. Selection не меняется; это важно для `scope=selected`.
4. Необязательный чекбокс **Игнорировать ограничения увеличения коллизий (shear)** — разрешает нестандартно увеличенные *Block*-коллизии при Replace только после Preview и явного подтверждения. Без него предупреждения блокируют Replace.

Чекбокс **не** отменяет проверку опубликованных Model ID, идентификаторов Placement, стабильности CFrame/Size, геометрического fingerprint, валидности Collision Blueprint, предельных размеров Roblox, типа допустимого примитива, требований Undo или атомарности замены. Non-Block shear нельзя достоверно представить стандартным Part; этот случай остаётся ошибкой. Подтверждение не применяется к Studio Sync или Place Registry Repair.

Неполученный / просроченный токен останавливает Replace без изменения источников. `clear` применяется только к переданному `inspectionToken` и не может уничтожить более новый осмотр. `inspect` не удаляет предыдущий проверенный осмотр до успешного создания следующего. Preview автоматически исчезает через пять минут. Перед сохранением Place его следует очистить.

Для проверки: выделить один проблемный Source Model, Preview → Show → «Показать в Studio» → оценить оранжевый блок, включить чекбокс при согласии → Replace; затем Ctrl+Z, проверить исходную Model, повторить на нескольких моделях. Не заменять сразу все размещения без проверки первого экземпляра.
