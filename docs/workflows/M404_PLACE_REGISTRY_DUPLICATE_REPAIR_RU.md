# M404 · Дубликаты Placement ID и безопасный порядок Repair → Sync

Домен: только распознанные опубликованные Location Assets с доказанным текущим
ригом. Никаких новых правил для Real Estate, LandscapePainter, NPC и Monster.

## Проблема

Snapshot #215: 475 размещений, `ground_torch_01` — две пары с одинаковыми
`Game1DecoInstanceId` и одинаковыми именами/путями внутри пары; их физические
позиции отличаются. Старый алгоритм оставлял первый обнаруженный экземпляр
без изменений даже при одиночном Repair именно его. Это давало `changed=0` и
сохраняло конфликт. `Scan` также ошибочно показывал `status=current` у
некоторых дубликатов, несмотря на `duplicateId=true`.

## Контракт

- Read-only Scan помечает все члены дубликатной группы `pending`, запрещает Sync.
- Одиночный Repair **выбранного** дубликата меняет его GUID, независимо от
  порядка сканирования; другие размещения не меняются.
- Repair полной группы сохраняет один исходный GUID, всем остальным членам
  назначает новые уникальные GUID. При частичном выборе все выбранные члены
  дубликатной группы получают новые GUID. Новые GUID проверяются против
  всех ID предыдущего Scan.
- Repair не меняет геометрию, Pivot/CFrame/Scale, части рига, огонь, свет,
  физику, публикации и Atlas. Изменяются только метаданные и имя Model.
- Требуются явный Scan, Backup confirmation, Undo, однозначная принадлежность
  Mesh ID, актуальный опубликованный состав и неповреждённый `rig_carrier`.
- Операция сбрасывает токен Scan. После неё выполнить Scan снова, и только
  затем Sync, если остаются Material/Atlas/Physics/Collision-несоответствия.
- Неоднозначные, внешние, устаревшие или повреждённые риги Repair не затрагивает.

M404 включает также M403 (кнопка NPC Spawns и DEV cleanup) из-за неуспешной
первой установки: патч строится поверх диагностического дампа 21.11.2026 12:19.
