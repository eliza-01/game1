# M407 · Studio Sync: текущий опубликованный риг и устаревшие метки

## Причина

`DecoPlacedAssetSync.RefreshIds` пытался восстановить *предыдущую* публикацию
при `needsMesh=true` даже тогда, когда в Studio уже находится полный текущий
риг, а устарели только `Game1DecoPublishedModelAssetId` / SHA. При пустом или
равном новому Model ID код искал **только старые** инвентари и завершался
`old published Model ID unknown; no Place geometry modified`.

## Исправленный контракт

- Если модель действительно совпадает с загруженной **текущей** публикацией:
  проверяются полный мультимножество Mesh ID, иерархия управляемых дочерних
  объектов, канонический rig, CFrame/Size и авторские Bone-трансформации.
  Проверки геометрии выполняются на отделённых временных копиях. Тогда Sync
  исправляет метки публикации, при необходимости Texture/Alpha/Physics, **без**
  уничтожения и пересоздания дочерних ригов; событие `model` не записывается.
- Если текущая публикация не доказана: требуется однозначная предыдущая
  опубликованная версия и полный исторический риг. Общая транзакция
  `StudioManagedRigSwap` и откат остаются обязательными.
- При отсутствии доказательств (в том числе для модели с неизвестной
  историей) операция останавливается с объяснением и не трогает Place.
- Studio Sync не изменяет Asset Registry / Image ID, другие слуги, LandscapePainter,
  Real Estate, место/масштаб модели или серверный Runtime.

## Приёмка в Roblox Studio на копии Place

1. Уже обновлённый полный риг, устаревший stamp: Find → Sync → повторный Find.
   Метки становятся актуальными, `geometryUpdated=0`, дочерние объекты не
   заменяются, свет и Bone остаются на месте.
2. Старый полный опубликованный риг: `geometryUpdated=1`, новый риг из
   публикации, та же корневая Model, Instance ID и CFrame; Undo работает.
3. Несовпадающий/добавленный вручную MeshPart или Bone: отказ до записи,
   сообщение о неподтверждённой публикации. Чужой slug не затрагивается.
4. Повторный Find/Sync на актуальном объекте не выполняет действий.

Проверки Python/Luau guard являются статическими: работа AssetService и
реального `StudioManagedRigSwap` должна быть подтверждена в Studio.
