# M486 · Character Creation / Padlock

База: M485. Схема профиля, модельные и atlas ID не изменены. Удалены ToggleFace и его строки локализации. Вкладки доступны только при наличии двух и более совместимых опубликованных вариантов; повторный клик закрывает настройки и возвращает полный рост. Цвет/материал остаются в доступных вкладках.

Превью: новый rig скрыт до загрузки idle и оценки кадра Animator, время переносится в нормализованной фазе прежнего idle. Старый rig сохраняется до готовности нового, rigid hair обновляется перед показом. Ошибка загрузки не заменяет исправный rig на restpose.

Создание: overlay блокирует ввод до смены этапа; одна пользовательская операция, максимум четыре последовательные попытки при временных ошибках (2/4/5 секунд между попытками). Не повторяются ошибки валидации. Gateway признаёт уже выполненное создание; UpdateAsync create-only никогда не перезаписывает занятый слот, возвращает фактический профиль для повторной валидации. Кандидат не виден другим потребителям до завершения записи. Без изменения schemaVersion. При недоступности Studio сохраняет существующую session-only политику.

Замок: в дампе опубликован `padlock_02` (92574610508351), а не `padlock_01`; authored grip — `padlock_01_hole_socket`. Оба доступных сокета монтируются одним визуальным набором, без коллизий. Состояние `Game1PadlockAttached` остаётся единым. `Game1PadlockVisualStatus`: loading / ready:2 (ready:1 для одного сокета) / detached / asset_unavailable. Ошибка загрузки не заменяется stub; сундук по-прежнему отдельная заглушка. Инвентарь/ключи не изменены.

## Studio Play — обязательная приемка

- Male/Female: полный рост после выбора, лицо при открытии вкладки, закрытие вкладки и возврат камеры; при 0/1 варианте вкладка отсутствует, при 2 появляется. Desktop / touch.
- На движущемся idle быстро менять голову, волосы, глаза: старый rig виден до готовности нового, фаза не сбрасывается, волосы следуют за головой. Проверить медленную репликацию/отсутствующую анимацию.
- Одно нажатие Create: overlay, блокировка повторного клика, принудительная временная ошибка и автоматический повтор; после успеха один профиль и переход в выбор; сетевой сбой после commit не создаёт дубликат. Исчерпание попыток показывает причину. Проверить Studio session-only и published DataStore отдельно.
- Дом с двумя сокетами: ready:2, замки в отверстиях с обеих сторон, E снимает оба, F на закрытой двери возвращает оба. Проверить удаление/повторную регистрацию дома, быструю смену состояния во время загрузки, два клиента. Камин и сундук продолжают работать, лифт M485 без регрессии.
