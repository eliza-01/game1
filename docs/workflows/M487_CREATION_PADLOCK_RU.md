# M487 · Цвет глаз / вход в мир / authored grip замка

База: диагностический дамп 2026-11-25 15:04:15, M486. ID моделей и атласов, внешняя версия профиля (1), схема каталога вариантов и правила владения домом не меняются.

- Вкладки волос, глаз и бровей доступны даже с одним вариантом; вкладка головы остаётся скрытой, если нет выбора. Сетка вариантов показывается только при двух и более вариантах. Цвета и материалы не зависят от числа вариантов.
- Контракт `appearance.colors.eyes = {l = "#RRGGBB", r = "#RRGGBB"}`: стороны анатомические, соответствуют `eye_l`/`eye_r`. Старый scalar преобразуется на сервере в пару одинаковых цветов; при отсутствии стороны используется цвет соответствующей части базовой сборки. Неизвестные ключи и неправильный HEX отклоняются. Сервер возвращает каноническую пару; существующий профиль нормализуется в сессии после проверки, сохраняется обычной записью позиции. Новый профиль хранится уже в новом формате. Откат runtime на M486 после сохранения новых профилей требует совместимого преобразования/восстановления данных (двухцветность в M486 не представима). Не запускать смешанные M486/M487 серверы при использовании общего DataStore.
- `CreationSubmittingOverlay` работает при Create и Enter, остаётся до передачи камеры корневому коллайдеру, снимается при ошибке RPC или после готовности камеры. Ввод остаётся заблокированным на время fade.
- `AuthoredPropSocketMount` ищет точное имя grip во всём клоне опубликованной модели, предпочитает уникальный authored carrier; при отсутствии на carrier допустим grip визуального меша. Несогласованные альтернативы отклоняются; проверяется позиция и полный поворот после `BoneModelMount.Place`. Нет stub, подмены ID или выдуманных смещений. Если кость отсутствует во всём опубликованном Roblox Model, потребуется проверить/переопубликовать FBX, а не генерировать ложный grip.
