# M489 · Character Creation / Selection UI

База: M488 final. Изменения presentation-only, кроме уточнения ответа SetPlayerLanguage.

- `FullScreenLayer` создаёт независимый ScreenGui с ScreenInsets.None для полноэкранного затемнения. Панели и кнопки остаются в safe area. Системный Roblox CoreGui не отключается.
- Continue применяет локальный язык, сразу закрывает окно и сохраняет выбор асинхронно. Сервер отличает применённую настройку (`ok`) от постоянной записи (`persisted`). При недоступном DataStore выбор действует в текущей сессии. Ошибка/недоступность RemoteFunction не отменяет локальный выбор. Валидация допустимых языков и rate limit не изменены.
- Флаги — Unicode emoji без внешних Asset ID. Проверить их отображение на целевых устройствах.
- При выборе пола открывается первая видимая категория в порядке CharacterCreationPanel.Categories. Квадраты вариантов обозначаются порядковым числом, внутренние ID неизменны.
- EyeEdit: закрытие замочка копирует цвет нажатой строки на оба глаза, сохраняет пару до закрытия; открытие восстанавливает её. Связанные изменения пресетов и HSV не меняют сохранённую пару. Apply записывает цвет, Cancel восстанавливает текущую подтверждённую пару. Режим и резервная пара локальны для черновика каждого пола, не входят в DataStore.
- Экран выбора: Select character / 1/5 / Human Male (или Human Female) / Level 0 / Enter the world. 1/5 и 0 — заданная презентация, не изменение фактической вместимости профиля или боевых статов. Загрузка и ошибки остаются различимы.
- GothamBold — шрифт существующего Overhead HealthBarView для NPC/Monster.

## Studio Play acceptance

1. В неопубликованном Place без API Services выбрать язык и нажать Continue один раз. Окно сразу закрывается, выбранный язык остаётся активным. В Output допустимо уведомление о session-only.
2. В опубликованном тестовом Place с разрешённым DataStore проверить сохранение языка после повторного подключения.
3. При создании и входе в мир проверить сплошное затемнение от верхней до нижней границы viewport. CoreGui Roblox остаётся системным. Проверить desktop и mobile, в том числе поворот экрана.
4. Выбрать Male и Female: сразу открывается Hair (если доступен). Варианты имеют вид 1, 2, 3. Проверить переход камеры и независимость черновиков полов.
5. С открытым замком выбрать два цвета. Закрыть замок правого глаза: оба глаза получают правый цвет. Изменить общий цвет пресетом и палитрой. Открыть замок: исходная раздельная пара возвращается. Повторить с левой строки и с одинаковыми цветами. Проверить Apply/Cancel и сохранение текущей пары после создания.
6. Проверить минимальную карточку выбора и Enter the world. M488 padlock и игровой Runtime не меняются.

Автоматические проверки: test_m489_character_ui.py (включает CLI-сценарий при наличии luau), M480–M488, M455, catalog.py --check, validate_luau.py, verify.py. Полноценная визуальная проверка требует Roblox Studio.
