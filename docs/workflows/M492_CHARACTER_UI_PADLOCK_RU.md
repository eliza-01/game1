# M492 — интерфейс загрузки и Bone Socket

- Editor: SyncLock находится в той же группе UIListLayout, что CustomColor, сразу справа; пресеты переносятся по ширине. Состояние EyeEdit не изменено.
- Panel: убраны GameBrand и GoldAccent; один полноэкранный loader для создания и входа в мир, без меча. Бег анимирован по времени, RenderStepped отключается при закрытии. Пока сервер создаёт игрока и камера ждёт RootCollider, полоса неопределённая (без процентов). После передачи камеры существующий MeshPreloader обрабатывает ресурсы реплицированного персонажа; процент относится к завершённым запросам предзагрузки, а не загрузке всего Workspace. При исключении сохраняется прежний выход в мир с диагностикой. Bootstrap учитывает оба одновременно загружаемых preview и не сбрасывается обычным refresh.
- Padlock (обновлено M496): аналог Blender Bone Socket v1.4 COPY_LOCATION (head_tail=0) + COPY_ROTATION REPLACE (все оси), без масштаба. Оба импортированных трансформа уже в Roblox. Дополнительный поворот +90° вокруг X, введённый M492, удалён после визуальной проверки пользователем. Runtime двигает весь Model на `bone.TransformedWorldCFrame * visual:GetPivot():Inverse()`, оставляя carrier PrimaryPart, PivotOffset и взаимное положение мешей неизменными. Не используется внутренний hole_socket, горизонтальная проекция или центр bounds. Экспорт/публикация/FBX/asset IDs не изменены. Реальное расположение геометрии относительно PivotOffset требует Studio Play.

Studio Play:
1. Открыть создание персонажа на узком и широком экране, проверить CustomColor + SyncLock, состояние обоих глаз, загрузчик и отсутствие брендовой полоски.
2. Enter the world: бег без меча, движущаяся полоса до серверного spawn, процент при обработке ресурсов; overlay закрывается после предзагрузки и camera handoff. Проверить повторный вход и отказ RPC.
3. Server Command Bar: содержимое `system/verify/studio_padlock_pivot_m491.luau` проверяет полное вращение, pivot визуала, относительные трансформы, обычный Attachment; затем `system/verify/studio_padlock_live_m492.luau` проверяет фактические замки на обеих петлях. Если визуально не совпало даже при head_error≈0 и forward/up dot≈1, приложить вывод этой проверки и скриншот Blender/Studio: требуется уточнение локального базиса опубликованного меша, а не очередной подбор углов.
