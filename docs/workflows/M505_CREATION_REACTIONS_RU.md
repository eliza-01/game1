# M505 · Character Creation reactions

В Options → Character Creation все шесть подразделов закрыты по умолчанию.
Animations: `chancePercent` — вероятность реакции на изменение внешности (0–100),
`weights` — относительные веса одиннадцати групп (0 выключает группу). Внутри группы
все опубликованные numbered variants равновероятны; используется текущий
CharacterAnimationRegistry и CharacterAnimationVariantMerge (personal/common).
`bow` только human_female; отсутствующие у пола группы исключаются. По умолчанию
35% и равные веса 100. При старте OptionsStore делает резервную копию старого
options.json и дополняет только новый блок; генерирует GameOptionsRegistry.

Механизм локальный: idle продолжает играть, одна Action one-shot реакция на модель,
без очереди повторных жестов. Материалы, цвета (только подтверждение, не drag палитры),
замок глаз и смена варианта вызывают реакцию; смена геометрии — после атомарной
замены preview, несколько изменений в процессе загрузки объединяются. При удалении
модели/выходе track очищается. Переключение вкладки не считается изменением внешности.

Drag мышью/пальцем вне UI в Creation вращает выбранного персонажа, в общем ракурсе —
под курсором или ближайший по проекции подиум. Selection сохраняет прежнее поведение.
Плавность и сохранение угла M494 не изменены.

Studio acceptance: Rojo Sync после перезапуска Control Center, 100% шанс и один
вес 100 (остальные 0), проверить каждый пол и несколько вариантов, смену hair/material,
цвет/отмену палитры, UI-scroll, вращение и отсутствие жестов в игровом мире. На телефоне
проверить начало drag в свободном месте, второй палец, палитру и скролл. Smoke
`system/verify/studio_creation_reactions_m505.luau` проверяет политику, не заменяет Play.
