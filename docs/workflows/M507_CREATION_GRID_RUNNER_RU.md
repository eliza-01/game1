# M507 — сетка материалов и загрузочный бегунок

- MaterialOptions: четыре колонки, восемь значений в двух рядах; высота зависит от количества значений, ширина ячейки ограничена 46 px и уменьшается на узкой панели. Порядок, стрелки и обработчики выбора сохранены.
- CharacterLoadingRunner: 2D-фигура с общей точкой плеча/таза и непрерывными сегментами локтя/колена. Центр каждого сегмента вычисляется из двух суставов, угол — из направления между ними. Противофаза рук/ног, 1.65 циклов/сек. Без ассетов и новых кадровых подписок.
- CharacterCreationPanel сохраняет прежний режим загрузки, прогресс, восстановление и управление RenderStepped. При скрытии overlay анимация отключается.
- Studio: проверить 1–8 в два ряда на телефоне и ПК; оба режима загрузочного экрана, плавный цикл, отсутствие отрыва конечностей, скрытие после загрузки. `system/verify/studio_creation_runner_m507.luau` проверяет суставы в 121 точке цикла (Client Command Bar).
