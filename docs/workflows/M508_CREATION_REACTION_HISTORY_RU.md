# M508 · История эмоций в редакторе персонажа

- Последние две запущенные группы эмоций исключаются из взвешенного выбора.
  Номер варианта не меняет группу (`laugh_01` и `laugh_02` — одна эмоция).
- История общая для обоих archetype в текущей сцене создания. Замена preview
  её не сбрасывает; закрытие сцены сбрасывает.
- Если все доступные группы исключены (например, включено всего две),
  реакция пропускается. Шанс и веса M505 не изменены.
- Смена пола, открытие, закрытие и переключение категории вызывают тот же
  механизм реакции. Повторное нажатие уже выбранного пола без смены категории
  не запускает реакцию. Геометрия ожидает готовности preview.
- Активная эмоция не прерывается и новые реакции не накапливаются в очереди.

Проверки: `test_m508_creation_reaction_history.py`,
`studio_creation_reaction_history_m508.luau` (Client Command Bar, Play).
