# M509 · Бегун загрузки

Бегун перемещается над всей полосой загрузки по времени, а не по проценту.
Одна секунда в каждом направлении, с зеркальным отражением всей позы на развороте.
Шаг, суставы и вертикальная амплитуда M507 сохранены. Прогресс и неопределённая
индикация заполнения работают независимо. Используется существующий RenderStepped,
отключаемый при закрытии загрузчика или показе восстановления.

Studio smoke: `system/verify/studio_loading_runner_m509.luau` (client Command Bar).
