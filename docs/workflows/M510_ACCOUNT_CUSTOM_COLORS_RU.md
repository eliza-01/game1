# M510 · Общая палитра аккаунта

Палитра Custom Color показывает локализованное имя текущего канала. Дискета сохраняет оттенок независимо от Apply/Cancel. Один список для обоих полов, волос (все каналы), бровей, правого/левого глаза. Выбор свотча меняет только текущий канал с учётом замочка глаз. Сохранённые цвета отображаются в горизонтальной строке палитры и рядом с пресетами.

Хранилище `game1_account_colors_v1` по UserId, не связано со слотом героя. Сервер валидирует HEX, удаляет дубликаты, ограничивает список 24 цветами (новые первыми, при переполнении удаляется старейший), использует UpdateAsync, не перезаписывает неизвестную схему. Studio без DataStore — только сессия; в опубликованной игре ошибка сохранения явно отображается. RPC ограничен по частоте, без очереди. Загрузка не блокирует редактор.

Проверка в Studio: сохранить оттенок, отменить редактирование, открыть брови/глаза и другой пол, выбрать оттенок; проверить, что меняется только текущий канал. Проверить мобильную прокрутку строк. В опубликованном тестовом Experience с API-доступом сохранить и переподключиться до создания героя; проверить сохранённый оттенок. Скрипт studio_saved_colors_m510.luau проверяет чистые правила.
