# M516 · Debug Dock

- GP в общем ряду TL / MV / MO / CS / HS / CAM / HP / UI / GP. На узком экране ряд переносится.
- Все 9 кнопок используют один стиль `StudioDebugDock.Bind`; выбранный цвет зависит от фактической видимости панели и ScreenGui. `Game1DebugPanelOpen` оставляет открытой одну панель.
- Gameplay создаёт UI независимо от готовности RPC; запрос разрешён только в Studio через существующий серверный авторизатор. Если сервер ещё не готов, сообщение предлагает повторить действие. MO больше не ждёт remote бесконечно, ищет его при открытом меню.
- В M515 сообщение о delayed GetMonsterDebugCatalog не доказывает, что MO блокирует GP (MO создаётся в отдельной задаче). Проверить реальную причину отсутствия GP можно только в Studio; добавлена явная отметка GP launcher ready.
- Проверка: Play → создание/вход в мир → GP → Enter test. Поочерёдно открыть TL/MV/MO/CS/HS/CAM/HP/UI/GP, закрыть по кнопке и ×, проверить цвет и мобильный перенос. Дополнительный клиентский smoke: system/verify/studio_debug_dock_m516.luau.
