# M519 · Gameplay Test — HP recovery

Заменяет правило M320 о 5 HP/сек: обычная пассивная регенерация теперь 0. В GP два независимых параметра, по умолчанию 0: Regeneration (0–10000 HP/сек) и Vampiric (0–100% фактически снятого HP). Дробные числа допустимы. Apply recovery меняет только эти параметры без полного лечения/пересборки и остановки боя; Enter / Apply loadout / Start group также передают их. Настройки живут в сессии Test, переживают тестовое возрождение и исчезают при Exit. Обычное возрождение, level-up и подготовка боя не изменены.

Сервер проверяет Studio, владельца и активную тестовую сессию. CharacterHealing ограничивает восстановление MaxHP, не лечит мёртвых/возрождающихся. Vampiric применяется в DamageService после вычитания защиты/крита по фактической разнице HP цели; overkill не учитывается, отдельные цели лечат отдельно. Не влияет на награды или обычные сохранения. В опубликованной игре регенерационный scheduler не запускается при нулевом глобальном значении.

Studio acceptance: получить урон при 0/0, убедиться в отсутствии восстановления; установить 10 HP/сек, Apply recovery, измерить +10 за секунду; 0 HP/sec + 25% Vampiric, ударить цель с 20 HP уроном 100, получить +5 HP; проверить лук и массовый удар, MaxHP, смерть/возрождение, Exit и обычный мир. Проверить отказ для отрицательных/NaN/бесконечных значений и 101%.
