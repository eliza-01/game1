# M521 · Database → Logs

`config/balance/patch-logs.json` — отдельный версионируемый журнал изменений баланса с патчей, не часть gameplay.json или Luau registry. Начинается с M520 по запросу пользователя; прежние записи не восстанавливаются задним числом.

Каждый следующий патч, изменяющий баланс, добавляет в `entries` одну запись `{ "patch": 522, "message": "Краткое описание изменений" }` (номер в примере условный). Порядок — по возрастанию номера патча, существующие записи не переписываются. Не записывать несвязанные исправления UI и ручные сохранения редактора. Автоматического определения установленных патчей нет.

`GET /api/balance/logs` возвращает `{schemaVersion: 1, entries: [...]}`; ошибки чтения/валидации возвращают 500. Отдельный read-only endpoint не зависит от состояния основной базы и не изменяет её. POST для журнала не предусмотрен.

Приёмка: Database → Logs показывает нумерованный список, одну строку на патч. Refresh перечитывает источник. Balance и Asset History остаются независимыми, несохранённые изменения Balance сохраняются при смене вкладки. Runtime не затронут. Перезапустить только Control Center.
