# M524 · Critical Balance

## Источник и решение

Пропорции Interlude из старого RobloxLineage: критический рейтинг кинжала и лука 120, меча и двуручника 80 (в пересчёте без DEX — 12% и 8%). Это базовые значения оружия, не полный шанс оригинальной L2. В Eyesland без оружия 1%, крит ×2, потолок 50%. Все 35 существующих записей — обычные монстры, 5% крит. Для будущих усиленных/элитных/боссов ориентиры 10/15/20%, не отдельные категории в текущей базе. Записи редактируемы независимо. M523 AS и ATK, XP, HP, цены, заточка, геометрия и тайминги не меняются.

## Контракт

`config/balance/gameplay.json` → `BalanceRegistry` (генерируется через game_balance.py). `rules.critChance` теперь шанс рук; `rules.maxCritChance` ограничен 1..50; `rules.critMultiplier` 1..5. `weapons[].critChance` и `monsters[].critChance` — абсолютный процент, 0..50, не бонус. WeaponEquipService заменяет модификатор оружия на разницу с базой (снятие возвращает шанс рук). MonsterInitialAttributes использует игровую запись, непривязанные модели сохраняют свой авторский шанс; NPC не мигрируют в баланс монстров. DamageService ограничивает шанс любого атакующего, в том числе NPC, и применяет множитель из серверных статов или глобальный. Независимый серверный roll для каждой цели. Headshot умножается до крита, как в M523 (при базовых значениях ×1.5 и ×2 => ×3 до защиты и округления).

`CriticalStats.Chance(base, percent, flat)` = clamp(base × (1 + percent / 100) + flat, 0, maxCritChance). В CharacterStatsService абсолютные базовые модификаторы, затем сумма процентных бонусов, затем сумма плоских бонусов. `CritMultiplier` — отдельный стат, ограничен 1..5. Заточка/уровни не меняют крит. Баффы будущих навыков могут использовать именованный источник модификаторов; никаких навыков пока не создано.

## GP · Studio only

Crit buff (0..200% относительных), Crit bonus (0..20 процентных пунктов), Crit damage (1..5 абсолютный множитель), Effective crit — предварительный расчёт выбранного loadout. Вступают в силу после Enter / Apply loadout / Start, не после изменения поля; recovery по-прежнему живой. Поля необязательны для старого payload (0, 0, глобальный множитель). Сервер проверяет тип/диапазоны, запросы разрешены только владельцу тестовой сессии в Studio. Настройки в transient selection повторно применяются при respawn, выход создаёт штатного персонажа без источника gameplay-test-critical. Обычные профили не меняются.

## Проверка

При мече 8%, +50% и +3 п.п. => 15%; кинжал 12% => 21%; при +200% и +20 п.п. кинжал ограничен 50%. Снятие оружия должно вернуть 1% (без тестовых бонусов). При обычном уроне 80 и без Defense, крит 160, headshot 120, critical headshot 240. Проверить melee и bow, групповое поражение, смерть/возврат, выход и новую игровую сессию в Studio. Патч мигрирует JSON и сгенерированную проекцию вместе; rollback через git apply --reverse до ручной правки данных. Редактор — перезапуск CC, runtime — Rojo Sync и Play restart.
