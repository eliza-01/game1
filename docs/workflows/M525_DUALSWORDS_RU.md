# M525 · Dualswords

- B: weapon_033, item LVL 30, required LVL 30, суммарный ATK 141 = 70+71, AS 180, крит 8%, сектор 108°, дистанция 8 studs. Два weapon_013 по 3000 + 1500 = 7500 Gold.
- B+: weapon_034, item LVL 35, required LVL 30, суммарный ATK 165 = 82+83, AS 180, крит 8%, сектор 108°, дистанция 8 studs. Два weapon_029 по 3500 + 1750 = 8750 Gold.
- ATK = round(ATK меча × 1.125); бонус оружия = ATK − baseDamage. Это бюджет обычной атаки, не удвоение. Прежняя формула заточки применяется к одной записи; стоимость одной попытки пока как у меча того же уровня. Независимые крит/Headshot и проверки геометрии; вампиризм от фактического урона. Если цель имеет flat Defense, она применяется к каждому попаданию существующим DamageService; у текущих сбалансированных монстров Defense 0. Дробный остаток при обычном целочисленном ATK отдан второму удару. При критах/Headshot и округлении отдельных попаданий возможны небольшие отличия DPS.
- Database: recipe.swordId, quantity=2, fee. Цена — расчётная стоимость ингредиентов, не магазинная продажа. Рецепт допускает только меч того же уровня; нижняя граница B. Кузнец, квест, инвентарь, расходование предметов и наследование заточки НЕ реализованы. В будущем они должны атомарно потреблять два экземпляра меча и валюту, а не доверять клиенту. Никаких новых идентификаторов опубликованных моделей не придумано.
- Weapons: dualswords означает шаблон ОДНОГО клинка с каноническим grip. Сервер копирует в обе руки, существующий BoneMountedAttachmentController уже обслуживает оба сокета. При снятии удаляются оба клинка. В GP допускается опубликованная модель обычного меча, витрина показывает пару. Вне GP нужна явная Database-привязка к опубликованной модели dualswords и уровень 30+. Никакого бесплатного получения в обычной игре (действующий debug selector остаётся только для разрешённых пользователей).
- Animations: набор `dualswords`; например `human_male_dualswords_attack_01.rbxm`. В Timelines у каждого опубликованного attack обязательны `HitFirst` и `HitEnd` строго по порядку. Сервер вычисляет время из текущей скорости; одна сессия, не более одного исполнения на каждый checkpoint. Смена экипировки, смерть, bounce и старая сессия не должны позволять второй отложенный удар. Обычное оружие по-прежнему имеет ровно один HitEnd, лук Release. При отсутствии готовых dualswords-клипов GP использует 1hs и условную точку первого удара на половине времени до HitEnd. Это только механический тест, а не настоящая двухударная анимация. Вне GP эта подмена запрещена. Для полного визуального теста опубликовать нужные idle/run/walk/attack и задать оба маркера.
- Приёмка: GP LVL 30, Оружие_033 и Оружие_034, по два числа урона за цикл, промах каждого удара независимо, два клинка на обеих руках, после снятия оба удалены; проверить смерть/падение/смену цели между ударами. Отдельно сверить один удар меча/кинжала/2H и один выстрел лука. В Studio в Server Command Bar можно запустить `system/verify/studio_dualswords_m525.luau`.
