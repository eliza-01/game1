# M529 · Skills / Skilled Monsters / Sky Test

## Данные и владельцы

`config/balance/gameplay.json` schema 4 — единственный редактируемый источник. `skills` содержит ID, имя, owner, effect, длительность, cooldown, power и tick. `skilledMonsters` — тестовые конфигурации (уровень, melee/ranged, список ссылок на skillId, флаг downgrade, trigger и HP threshold). `test.skilledEnabled` управляет созданием секции. 70 обычных записей M527, предметы и уровни не изменены. Каталог доступен через Database → Skills (Monsters / Characters, Debuff / Buff); Characters пока пуст. Options → Debug / TestPlace → Skilled Monsters редактирует конфигурации того же API с optimistic revision. До 24 профилей по 8 разных эффектов, до 64 навыков. Сохранение через существующую пару source/registry с backup/rollback. Никаких прав на игровые мутации через каталог из клиента.

`services/skill_balance.py` валидирует ссылки и рассчитывает производные строки; `BalanceRegistry` — неизменяемая проекция. `MonsterSkills` владеет назначениями и cooldown по экземпляру; `SkillEffects` — отдельный серверный исполнитель lifetime/stacking, `DamageService` — единственный авторитет урона. Сейчас назначения работают только у Studio Skilled Monsters (в том числе Group). Обычные production-monsters не получают навыки автоматически. Будущие назначения production и character skills используют те же каталожные ID, но требуют отдельной интеграции и валидации.

## Начальная модель

Все значения — **стартовые настройки Game1**, а не исторические параметры L2. Для сохранения времени убийства HP, AS и награды базовой строки не меняются. Стоимость навыка вычитается только из обычной атаки: `ATK = round(baseATK / product(1 + budget_i))`; только назначения с включённым Auto downgrade входят в произведение. Урон периодики берётся от уже сниженной атаки. Модель средней интенсивности не гарантирует равную реальную сложность CC; контрольные веса — явно заданные гипотезы. Точный cooldown отсчитывается от успешного применения, может быть дополнительно отложен следующей атакой, условием или неприменимостью эффекта. Не рассчитывать из частоты ударов персонажа. Для Gremlin: базовый клип 1.8 s при AS100 + guard .03 s. `cycle = 1.8 * 100/AS + .03`; при других моделях/анимациях нужна калибровка. ДоT budget = (power/100) × floor(duration/tick) × min(1,cycle/cooldown) / (1 + critChance/100 × (critMultiplier−1)). Control budget = uptime × power/100 × weight. Weights: slow .5, root .75, stun 1.5. Buff budget = uptime × power/100. Uptime = duration/cooldown; для HP/attacked условия это верхняя оценка. Сочетания: произведение коэффициентов, overlap контроля может приводить к излишнему штрафу — проверять на стенде.

Silence запрещает касты, не автоатаки; персонажных кастов пока нет, поэтому фактический downgrade 0. При их появлении пересчитать по доле DPS/utility навыков; первоначальный контрольный вес .75 дал бы 13.04% при тех же таймингах, но он не применяется сейчас. DoT не критует, не запускает вампиризм, игнорирует Defense; округление распределяется по ticks, суммарный бюджет округляется один раз. Каждое назначение имеет свой cooldown. Одинаковый effect на цели не складывается и не продлевается, разные эффекты совместимы. Root/Stun перекрывают Slow. Stun инвалидирует уже начатые melee/bow checkpoints по epoch, не делает автоматические атаки Silence. HUD показывает активные эффекты. `Effect expired` допускает первый каст в бою, затем повтор после окончания эффекта и cooldown; `was attacked` — подтверждённый ненулевой урон, `HP below` — строго меньше порога в бою. Haste влияет на следующую атаку, не пересчитывает уже начатую. При уходе/смерти источника тики прекращаются. Яд и bleed различаются длительностью, не имеют пока разных моделей резистов/диспела. Клиентское движение следует серверным атрибутам, production enforcement и полноценные VFX/анимации/иммунитеты — отдельно.

## Sky Test

Origin = существующий тестовый origin +100 studs по Y. Hub/Group, Melee, Ranged и Skilled размещены на отдельных палубах с переходами, надписями над зонами, цветовым кодированием; два обычных трека ×3 и индивидуальные подходы ranged сохранены. Skill-профили имеют отдельные площадки, мосты и ограничение радиуса возврата. Начальные 8 профилей lvl20 melee; флаг в Options скрывает всю секцию. GP переключает Melee → Ranged → Skilled; Go, Start group используют тот же серверный lookup. Явный переход Go очищает дебаффы игрока. При выходе из теста временный стенд удаляется. Внешний мир не изменяется.

## Приёмка и риски

После Rojo Sync + Play: 100-stud elevation относительно ранее настроенного origin, переходы без дыр, восстановление при падении, ranged gate и retreat, Go/Start/Exit, восемь отдельных профилей, multi-skill и checkbox, сохранение/перегенерация при изменении параметров. Проверить длительность, урон DoT без повторного крита, stun до HitEnd / Release и отсутствие возобновления уже отменённого попадания, root без прыжка, slow в обычном движении и во время атаки, buff cooldown и условия, отсутствие статов/XP вне теста. Проверить, что HUD не мешает мобильной панели. `system/verify/studio_skill_effects_m529.luau` — дополнительный ручной smoke. Реальный Studio Play и численный баланс контроля не подтверждены локальными Python тестами.
