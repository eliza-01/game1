# M531 — Combat Analytics / Guided GP и отдельные касты

> Guided остаётся актуальным без наград; дорожки заменены M539, с M541 ×3 только Hub вне Group/Guided. Обычные zone-убийства теперь дают transient XP/Gold. Касты/VFX уточнены M533, headshot и экспорт M532, анимации M534. См. [текущий World GP](M541_HUB_WORLD_PROGRESSION_RU.md).

Канбан: KBN-0025–0030. В GP выбрать Enter test, затем Guided. Next автоматически экипирует участника и запускает одного монстра с полной HP; 36 studs в начале для всех этапов, без регена, vampiric, бонусов крита и заточки. Первые 30 боёв: LVL 30, B, пять типов оружия × два типа монстров × три повторения. Дополнительно по одному бою на каждую включённую запись Skilled Monsters (стартовые 8 — LVL20; меч и броня доступного уровня). Для каждого уникального уровня/типа skilled, отличного от LVL30, добавлены три контрольных боя с обычным монстром того же уровня и типа. По умолчанию 41 бой (30+3+8). Результаты разных уровней не сравнивать напрямую.

Задача: бой без прыжков с платформы и без сторонних debug-модификаторов; атаковать выбранную цель обычными атаками, стремиться к попаданиям, не злоупотреблять ожиданием. Умирать разрешено. При смерти или победе фиксируется результат; 90 секунд — timeout. Прерванные respawn/удалением цели попытки повторяются. Next после отчёта, Done после всех этапов; скопировать серверный Output от GP_REPORT_BEGIN до GP_REPORT_END, включая GP_SUMMARY. Cancel прекращает сценарий; Exit возвращает персонажа. Статистика эфемерна, не даёт XP/gold и не сохраняет результаты в профиле. Отчёт JSON: фактически снятые HP, DPS от старта до исхода, firstHitSeconds, firstInRangeSeconds (приблизительный горизонтальный root distance, не время перемещения), попадания, криты, headshots, начатые циклы, циклы без контакта (не чистое число промахов), DoT, время под эффектами с шагом около 0,1 с, начатые/применённые касты. Смерть, timeout и незавершённая атака не исключаются из средних DPS; TTK только по победам. Три боя — smoke sample, не статистически надёжная оценка критов. Настоящие анимации dualswords и 2hs обязательны для финальных выводов.

RunSpeed: один источник Database (baseRunSpeed, индивидуальный runSpeed монстра). 10 единиц = 1 stud/s. Игрок 160 (16), melee 130 (13), ranged 120 (12). Предварительные тестовые значения; обычная ходьба ×0.5, GP track ×3 и существующий melee attack pursuit ×1.65 оставлены. Непривязанные монстры сохраняют authoring RunSpeed. Старый RunSpeed рецепта персонажа больше не базовый runtime источник.

Навыки: debuff trigger `cast` вместо `hit`; self-buff сохраняет условия. Общий отдельный action `atk_special` (0.7 s в Rules), резервирует cooldown при начале, не наносит обычный удар, эффект в середине при повторной проверке цели. У skilled монстров визуальный Weld вместо WeldConstraint соединяет те же детали, C0 меняется только на время каста и восстанавливается при смерти/возврате. Дебафф: подъём и flip по X; buff: подъём и spin по Y. Клиентские эффекты только у локального игрока: Poison облако каждые 3s; Bleed капли; Root декоративный коричневый блок без столкновений; Slow пульсация цвета boots с восстановлением; Silence глаза/X; Stun звёзды. Отдельный полноценный visual replication для наблюдателей и авторитетная серверная проверка перемещения — KBN-0026.

Downgrade: netBudget = max(0, rawBudget - castSeconds/cooldown), ATK factor = произведение 1/(1+netBudget) для активных downgrade. rawBudget прежний M529 (DoT от базового удара / ожидаемый цикл, контроль — эвристика, баффы — power × uptime). Модель приближённая, касты конкурируют и могут промахнуться; проверять фактическую частоту в GP. No downgrade при отрицательном netBudget; Silence пока не запрещает базовые атаки. Не менять HP, цены и награды. Прямая миграция JSON/registry одним патчем, проверка применения обязательна; пользовательские изменения не перезаписывать при конфликте.
