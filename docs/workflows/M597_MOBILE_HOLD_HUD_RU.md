Перед публикацией применить требования M596 к резервной копии DataStore и остановке старых серверов. Настроить DEV Place ID по M595; четыре категории оружия не обходят серверную авторизацию.

## Приёмка (Studio, PC, реальный телефон, Published DEV)

- ЛКМ/Attack: короткий tap = один запрос; удержание на melee и bow повторяет полные timeline, release перестаёт создавать новые атаки. Проверить bounce, смерть, stun, respawn, переключение оружия, лаг и быстрые нажатия.
- Jump: tap = один прыжок, hold = новый импульс после приземления; отсутствие дополнительных импульсов в воздухе; release/cancel/menu/scene/focus/death прекращают серию.
- Два/три пальца: джойстик + Attack/Jump + свободный drag; drag тем же пальцем на Attack/Jump/Skill/Weapon/Settings, свободный drag имеет приоритет; pinch только двумя свободными пальцами. Tap toggle auto, drag не toggle. Ручная камера снимает AutoAim, но сохраняет автоатаку до выключения.
- HUD: Attack белый/чёрный/red slash, Jump синий, Auto зелёный, 4 пустых оранжевых skill slots. Оружейные категории 2×2 в правом верхнем углу, переключают оружие напрямую через существующий DEV каталог (M599); не выдавать предметы в production. Settings слева под Core UI, Gold меняет ширину вместе с числом. Проверить пересечения с debug toolbar, prompt/info dock, safe area, portrait/landscape и маленькими экранами.
- Серверные боевые контракты неизменны. Нет нового Heartbeat/RenderStepped или новых боевых RemoteEvents. Не считать физическую приёмку завершённой по статическим тестам.

## M598 · Геометрия HUD

Attack — базовый диаметр (25% короткой стороны safe viewport, с ограничением по ширине и максимумом 120 px). Jump, Auto и 4 Skill — 46% диаметра, joystick — 106%, DEV оружие — 37%. Skill-ячейки на общей дуге вокруг центра Attack: 15°, 50°, 85°, 117° (от левого направления к верхнему и правому). Весь кластер закреплён снизу справа, joystick снизу слева, оружие сверху справа. Settings сохраняет 44 px, Debug Dock сдвинут вправо на 44 px и оставляет место оружию на touch. Context/Info используют фактические границы кластера. Приёмка на реальном телефоне с Core UI и вырезом экрана остаётся открытой.

## M599 · Mobile debug & quick switch

На touch DebugDockProfile оставляет GP (только при разрешённом Studio Gameplay Test), UI presentation, HP (линейка), CD (камера). TL/CS/HS/AG не запускаются на touch; desktop без изменений. Слоты оружия не создают окно каталога: один tap выбирает последний известный slug типа или первый доступный по сортировке slug из серверного каталога. Загрузка каталога лениво, один успешный результат кэшируется на клиенте. Equip RPC и DEV-авторизация прежние; не является production inventory. Проверить на телефоне смену всех четырёх типов, отсутствие окна, отказ во время атаки, respawn и отсутствие каталога/прав.
