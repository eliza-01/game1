# M611 · Network Motion Owner

M610: наблюдатель 57 Hz, Position/Render 16.1 [13.0–19.0], Velocity 16.0 [16.0–16.0]; сервер 60 Hz, Position 16.0 [14.5–17.7], Velocity 16.0 [16.0–16.0]. Пульсация позиционной скорости измерена, но её источник ещё не установлен.

Camera Debug → Network motion → Record 8s. Другой игрок бежит по прямой с постоянной скоростью. Автоматически снимается третий отчёт OWNER на локальном клиенте цели (панель открывать не надо). Оба клиента должны иметь Debug access; при его отсутствии или таймауте явно OWNER unavailable. OWNER — обозначение локального клиента цели, не отдельная проверка network ownership.

Server clock задаёт только общий интервал; локальный os.clock измеряет elapsed dt. Одна запись на цель, максимум две серверных сессии, ограничение 2048 samples и cooldown сохранены. Дополнительные сообщения используют существующий диагностический RemoteEvent; координаты не реплицируются. Сервер проверяет отправителя, ID, временное окно и копирует только конечные числовые агрегаты. Результаты не используются в игровой логике.

Сравнить диапазоны p05–p95 Position/Render/Velocity во всех трёх точках; одинаковое среднее не доказывает линейности. Если пульсация уже у цели, изучить локальную физику и порядок семплирования; если цель ровная, а сервер и наблюдатель нет — изучить путь репликации. Не менять скорость, ownership или вводить компенсацию на основании одного снимка. Фактическая проверка M611 ещё открыта.
