# M613 · Общий пул анимационных sampler NPC/Monster

Решение владельца: пока без новых измерений; сначала рефактор критических модулей. Исходная база M612a. KBN-0035 (Profiler) остаётся открытой.

- `SamplerPool` — независимый от Roblox ограниченный пул с эксклюзивной выдачей, учётом резерва до потенциально yielding factory, повторным использованием по ключу, уничтожением старейшего idle при необходимости и TTL 8 с.
- `ActorSamplerPool` — единственный экземпляр для обоих композиторов, лимит 32 resident, включая активные, idle и pending. Два независимых кэша и счётчики удалены. Ключи разных доменов не смешиваются. При исчерпании занятых слотов не создаётся новый proxy, существующий серверный клип продолжает играть.
- Сохранены текущие дистанция 140 studs, entry/exit blend, скорость, фаза и раздельная композиция ног; при смерти lease освобождается. Выход монстра из боя не выкидывает активную запись до release. Удаление рига из Workspace освобождает lease; завершившаяся после удаления загрузка проверяет актуальность записи. RigidConstraint исключён из клона скрытого sampler.
- Нет новых циклов, RPC, настроек или измерений. Player attack sampler пока вне этого лимита (чтобы не потерять видимость недавно восстановленных атак); приоритет ближайших и отдельный мобильный бюджет остаются в KBN-0037-T01/T07. Лимит 32 сохранён из прежнего общего Config, не результат профилирования.

Проверка: автономный Lua тест пула (cap, idle eviction, повторное использование, TTL, ошибка factory/resume, конкурентное резервирование); исходные контракты. Studio/DEV: несколько NPC/монстров в pursuit, смерть, выход из боя, повторный вход, streaming/despawn, проверка отсутствия rest pose. Полная приёмка открыта.

Следующий критический этап: Spatial Index, затем потребители по одному. Общий Profiler и итоговые сравнительные замеры отложены, не отменены.
