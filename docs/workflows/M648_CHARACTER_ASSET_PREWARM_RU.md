# M648 · Character Creation Asset Prewarm

База M645 + M646 + M647. Владелец функционально принял Overhead; полный A05 открыт. KBN-0039-T05 — CODE_COMPLETE, native A03/A04 NOT_RUN.

## Контракт

- До M648 до 24 собранных шаблонов с общим дедлайном 75 с блокировали стартовый экран до двух реальных preview. Теперь `CharacterCreationController` сразу запрашивает две реальные default сборки; progress относится только к ним. `CharacterCreationVariantPrewarm` удалён. Реальное preview по-прежнему валидирует геометрию через `AssetMeshPreloader.PreloadModel` до помещения в сцену; профили, цвет, материалы, roster, анимации и gameplay не изменены.
- `CharacterCreationWarmPlan` строит allowlist из готовых human archetypes и каталога, исключает стандартные ресурсы и группирует по опубликованному Model asset ID; в текущем каталоге четыре дополнительные публикации. `CharacterCreationAssetWarmService` читает через существующий серверный component cache, не вызывает Builder. `CharacterService` сериализует загрузки одного cache key (15 с ожидания; не блокирует другие ключи). Нативный InsertService не прерывается после локального timeout.
- Новый read-only RemoteFunction `CharacterCreationWarmComponent(index)` доступен только при pending/creation. Целочисленный индекс из allowlist, `ok/done` либо `ok/meshes/images/count` либо `ok=false/error`; произвольные ID от клиента не принимаются. Один server-wide warm in-flight, 15 s cooldown после ошибки, результаты кэшируются. До 24 публикаций, 16 MeshPart на компонент, 96 общих источников. `Game1CharacterWarmSources` содержит только отдельные stripped MeshPart, без костей, TextureID, Animator и физики в Workspace; dedup фактического MeshId. Источники сохраняются до конца сервера, реплицируются всем клиентам: это ограниченный дополнительный расход RAM/сети вместо репликации полных ригов. Не считать выигрыш измеренным. Текстуры берутся из фактических опубликованных частей и atlas override; необязательный raw texture может быть лишним при override. PBR texture packs по прежнему контракту не прогреваются отдельно.
- `CharacterCreationAssetPrewarm` стартует только после готовности двух default preview, не входит в curtain. 20 s общий клиентский бюджет, 10 s RPC, 5 s replica wait. Остановка при первом реальном geometry edit, уходе из creation, смене epoch или submitting; нет возобновления в той же сцене. Foreground может ждать совпадающую raw asset загрузку, но не optional RPC/очередь. Typed cache общий, один background слот из четырёх, остальные для foreground; нет raw Model ID как image, нет новых Animator. Отменённый PreloadAsync завершается самостоятельно и освобождает owned request. Ошибка optional не препятствует on-demand preview. Новых Options, схем, публикаций или изменений игрового баланса нет.
- M337: явный UTF-8 при чтении тестовых файлов, независимо от Windows codepage.

## Приёмка

Обычная игра: дождаться двух default preview; сменить пол, волосы (включая compound hair), лицо/глаза/брови, цвет; создать или выбрать персонажа и войти в мир, вернуться в roster. При необходимости повторить на телефоне. Не требовать стресс-тестов. Измерения startup/FPS/RAM, настоящая репликация, ContentProvider и Studio/DEV/Mobile не проверены исполнителем. Следующий этап после functional smoke — Hitbox Precompute.
