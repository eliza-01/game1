# M364 · Выравнивание Melee Arc при атаке

- **Источник данных:** атрибут `MeleeArcAngle` на персонаже, который публикует `WeaponEquipService` при экипировке/снятии оружия. Контакт по-прежнему вычисляет серверный `MeleeTargetQuery` по `RootCollider.CFrame.LookVector` строго на `HitEnd`.
- **Правило:** `MeleeFacingPolicy.MaxResidualYaw(arc)` разрешает камере оставаться внутри 85% половины сектора, но не дальше `TorsoYawLimit`. Если сектор полный (360°), поворот корня не требуется. Для дуги 108° допустимый остаточный yaw составляет 45,9°, а не прежние 70°.
- **Кэш:** `MovementController` пересчитывает предел только при смене `MeleeArcAngle` и создании персонажа. Подписка удаляется при CharacterRemoving; никаких Raycast, обходов Workspace, remotes или пересчётов размера сектора в каждом кадре нет.
- **Во время атаки:** цель направления фиксируется один раз. Довод корня завершается не позднее запланированного `HitEnd` (ограничение по авторскому времени события); при движении сохраняется `MovingDirection`, но на период удара физический yaw управляется компенсацией. Нет лишней записи CFrame, когда направление уже совпадает.
- **Границы:** гарантия относится к *горизонтальному положению луча прицеливания внутри сектора* после завершения поворота, а не к обязательному попаданию по перемещающейся цели. Препятствия, расстояние, высота, лаг репликации и реальные анимации остаются отдельными факторами.
- **Ручная проверка в Studio:** стойка и ходьба, углы ±90/±150/180°, оружие с дугами 20/60/108/180/360°, смена оружия во время Play, ускоренная атака (HitEnd раньше 0,28 с), лук и возврат к обычному развороту после завершения атаки. Проверять фактическую серверную зону в Test Loadout и один серверный урон на HitEnd.
