# M213 · Real Estate / Atlas Registry: проверка реального формата изображения

## Симптом и граница диагностики

`Register / Save: house: texture must be a real PNG or JPEG file` при выборе
`house_level2_01_2048x2048_atlas.png`.

В диагностическом архиве от 2026-11-03 бинарные изображения исключены, поэтому
невозможно установить фактическую сигнатуру именно пользовательского файла.
Воспроизводимый дефект в `AtlasRegistry.adopt_file`: проверка расширения допускала
`.png`, а конвертация WebP происходила только для расширения `.webp`.
В результате WebP-изображение под `.png` копировалось в Registry с ложным расширением,
после чего строгая проверка `register_file` его отвергала.

## Контракт

- Atlas Registry по-прежнему единый владелец регистрации и публикации изображений.
- В `adopt_file` Pillow определяет настоящий формат источника. Разрешены PNG, JPEG, WebP;
  другие форматы, в том числе GIF с именем `.png`, отклоняются.
- WebP, в том числе с ошибочным расширением `.png`, декодируется во временный
  настоящий PNG, и только он сохраняется в canonical Registry. Оригинал не изменяется.
- Настоящие PNG/JPEG копируются без рекодирования. Если расширение не соответствует
  содержимому (например, JPEG под `.png`), canonical filename приводится к формату.
- Повреждённые изображения возвращают читаемую ошибку валидации, а не исключение
  Pillow, выпадающее из API.
- Правила имени атласа, размеры, контрольные суммы, уникальность вариантов,
  опубликованные Image Asset IDs, связи домов и политика M212 не изменяются.

## Проверка

Новые тесты `test_real_estate_atlas_source_format_m213.py`: WebP внутри PNG,
обычный PNG, JPEG внутри PNG, запрещённый GIF, повреждённый файл.

После применения перезапустить только Host Agent (с процессом Control Center,
если он запущен в том же Python-процессе), обновить страницу и повторить
`Register / Save` с тем же файлом.

Если файл не PNG, JPEG или WebP, либо повреждён, он и дальше должен отвергаться;
в этом случае нужно экспортировать настоящий PNG. Для проверки сигнатуры
PowerShell: `Format-Hex -Path 'E:\RobloxProjects\Blender Export\game1\houses\house_level2_01\house_level2_01_2048x2048_atlas.png' | Select-Object -First 2`.

Без SQL-миграций, Studio-плагина, повторной публикации существующих Image Assets.
