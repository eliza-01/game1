# M227 · Real Estate — Place all / Clear all

**База:** M225 (совместим с M226, который менял только установщик плагина).
**Область:** `04 · Placement` в Asset Manager и Studio Edit Mode.

## Семантика

- **Place all** требует выбора зарегистрированного дома в поле House. Из сохранённого `RealEstatePlacementStore` берутся **все бинды этого дома** (максимум 50, по одному на участок). Каждый создаётся в `Workspace.Plots/NN/Houses` по сохранённому `localCFrame`, `scale` и `anchored`. Если на участке уже есть авторская помеченная копия любого дома, она заменяется. Несовпадающий/неуправляемый объект с именем целевого дома блокирует **всю** операцию.
- **Clear all** удаляет **все** корректно помеченные авторские preview-модели из `Workspace.Plots/01..50/Houses` независимо от выбора House и от того, сохранился ли старый Binding. Не удаляются шаблоны `ServerStorage`, неуправляемые модели, `plot_XX_volume` или чужие дома. Пустые участки пропускаются. Кнопка не требует подтверждения (как и одиночный Clear).
- Оба действия — **один вызов** аутентифицированного Studio Bridge и **одна Studio Undo-запись**, а не 50 последовательных HTTP-вызовов. Одиночные Place/Clear используют те же функции подготовки и выполнения операции.

## Архитектура

`real-estate-placement.js` (только UI) → `POST /api/real-estate/placements/bulk` → `api/real_estate.py` (выбор и валидация домена) → `studio_house_placement_bridge.py` (верифицированная команда) → `StudioHousePlacementPreview.luau` (проверка, подготовка, транзакция, Undo).

Запрос браузера для Place all содержит только `{ "action": "place_all", "houseSlug": "..." }`; присланные из браузера координаты/список целей игнорируются. Сервер отправляет сохранённые Binding. Для Clear all браузер отправляет только `{ "action": "clear_all" }`.

Существующая команда `house-placement-preview-v2`, schema 2, расширена **новыми action** `place_all` / `clear_all`; старый Studio-плагин не может выполнить их и должен вернуть ошибку, не изменяя Workspace. `plotIndex=0` указывает на пакетную операцию. После выполнения сервер проверяет тип статуса, число изменённых домов и для Place all количество проверенных `BasePart`.

## Безопасность

До начала любой мутации Place all выполняет preflight **всех** требуемых участков, папок, шаблонов, соответствия имён, сохранённых CFrame/scale/anchored и строит временные клоны. Любая ошибка в предварительной проверке означает **ноль изменений Workspace**. Только после успешного preflight начинается одна Undo-операция. Новые клоны сначала вставляются и повторно проверяются; только после успеха удаляются прежние помеченные копии.

При ошибке вставки клоны удаляются, новые каталоги `Houses` удаляются и Undo-запись отменяется; существующие объекты не тронуты. Отдельная гарантия физического результата в Studio не может быть доказана статическими Python/Luau тестами. Для первого массового Place/Clear обязательна копия Place.

Бинды SQLite, публикации, Atlas Registry, экономическая/игровая недвижимость и остальная геометрия не изменяются.

## Тест в Roblox Studio

1. Сохранить копию Place; установить Game1Bridge, перезапустить Studio.
2. Создать/проверить 2–3 Binding **одного** дома на разных Plot (один Anchored, другой Free); на третьем Plot оставить чужую неуправляемую Model.
3. Нажать **Place all**. Проверить, что появляются только выбранный дом на его связанных Plot, CFrame/Scale/Anchored сохранены и соседняя модель не затронута.
4. Повторить Place all и проверить отсутствие дубликатов авторских preview; выполнить Undo и убедиться, что прошлые копии вернулись.
5. Нажать **Clear all**; убедиться, что удалились все помеченные авторские preview, включая дома другого slug, но не удалились чужие модели и `plot_XX_volume`. Выполнить один Undo.
6. Проверить отказ Place all при отсутствии одного из `ServerStorage/real_estate/<slug>/model/<slug>` и при конфликте с неуправляемым объектом. В обоих случаях существующие preview должны остаться без изменений.

## Применение

Применить Git patch M227 поверх M225/M226 из корня `game1`, затем установить плагин командой `system/studio-plugin/install.ps1`, перезапустить Host Agent и Roblox Studio. Миграций базы нет. При отказе системы проверять Studio Output, команду и редакторскую копию Place; для массовой операции доступен один Studio Undo.
