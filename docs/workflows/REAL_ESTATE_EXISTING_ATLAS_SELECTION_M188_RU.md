# M188 · Выбор другого опубликованного атласа

## Причина и поведение

В диалоге `mesh → Texture · atlas → Use an existing published atlas`
можно выбрать любую опубликованную серию. Раньше этот выбор попадал в
`select_atlas` под ограничение переключателя разрешения/версии и ошибочно
отклонялся сообщением `select an atlas resolution or version from the same
mesh series`.

В существующий PUT `/api/real-estate/{slug}/atlas-binding` добавлено
необязательное поле `mode`:

- `variant` — прежнее поведение и значение по умолчанию: разрешение/версия
  внутри текущей серии;
- `existing` — явная привязка к другой уже опубликованной серии из диалога.

Другие значения отклоняются. В обоих режимах сохраняются проверки наличия
меша, запрет текстур у коллизии, актуальность публикации выбранного атласа
и optimistic revision привязки. Новое изображение не загружается, модель
не публикуется. Сохранённая привязка не откатывается при недоступности Studio;
ответ остаётся `pending_studio_sync` с диагностикой.

Кнопка диалога передаёт `existing`. Цветовые кнопки разрешений и список
версий используют прежний `variant`. Остальные привязки дома и Model Asset
IDs сохраняются. В API и БД схема не менялась; миграция не требуется.

## Проверка и применение

Добавлены поведенческие тесты выбора другой серии только для одного меша,
отсутствия вызовов публикации, запрета неопубликованного атласа/устаревшей
ревизии, прежнего ограничения разрешения и сохранения выбора при offline
Studio. Host Agent и веб-интерфейс обновлены.

В рабочей записи `structures_01` ранее использовался атлас через
`estate:house_level4_01:restoration`. Эта привязка автоматически не менялась:
нужно обновить страницу и повторить выбор желаемого опубликованного атласа.
