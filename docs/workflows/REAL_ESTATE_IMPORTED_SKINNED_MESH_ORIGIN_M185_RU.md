# M185 · Real Estate · Imported skinned mesh origin

M184 не восстанавливал положение `door` в `house_level5_01`: в ранней
версии перепутаны знаки осей X и Z, а перемещение всего дверного рига
одновременно сдвигало корректно расположенный шарнир.

## Доказательство из Blender и Studio

- Исходный центр двери (Blender): `(2.492348, 7.506341, 10.132211)`.
- Корректный центр Roblox: `(-2.492348, 10.132211, 7.506341)`.
- Импортированный в ServerStorage центр: `(-2.492348, 10.132211, -4.599523)`.
- Искажение: `-12.105864` по Roblox Z, при этом мировой шарнир
  `(0.404723, 9.476135, 7.522702)` уже корректен.

## Контракт

1. Inspect сохраняет общую геометрическую систему дома в `authoredPlacement`
   версии 2: Blender `(x,y,z)` -> Roblox `(-x,z,y)`.
2. При Studio Sync размеры должны соответствовать исходному FBX.
3. Для скелетных MeshPart **нельзя** перемещать весь риг: MeshPart ставится в
   авторский центр, а прямые root Attachment/Bone перенормируются с сохранением
   мировых `WorldCFrame`, включая все дочерние сокеты.
4. Для статических мешей остаётся обычная установка `rig:PivotTo`.
5. Существующий v1 из M184 поддерживается без изменения SQLite: координаты
   приводятся к v2 в момент Studio Sync.
6. Шаблон заменяется только после успешной проверки всех частей, иначе
   новое состояние не публикуется в ServerStorage.

## Проверка

После установки Studio-плагина запустить Full Studio Sync. Если база не
содержит `authoredPlacement`, повторить Inspect/Register FBX без изменения
моделей и Model Asset IDs. В ServerStorage центр двери должен стать
`(-2.492348, 10.132211, 7.506341)` относительно исходного шаблона, а
`door_01_hinge_socket` остаться `(0.404723, 9.476135, 7.522702)`.

Реальную анимацию и результат MeshPart skinning следует проверить в Roblox
Studio отдельно. Повторная публикация FBX не требуется для исправления
размещения в шаблоне.

Для диагностики `DoorRig` получает `Game1AuthoredPlacementMode`,
`Game1AuthoredPlacementDelta`, `Game1AuthoredPlacementVersion`. Отсутствие
этих атрибутов после Full Sync означает, что данные авторского размещения не
поступили или не использовались.
