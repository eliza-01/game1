# M247 · Real Estate — оформление редактора

Изменения касаются только разметки и презентации Asset Manager: `index.html`, `real-estate.css`, `real-estate.js`.

- Убран дублирующий блок **Central Atlas Registry / Uploaded Atlases** из Real Estate. Общий каталог Atlas и выбор/переиспользование атласов внутри редактора MeshPart остались без изменений.
- У **Registered Library** максимальная высота прокручиваемой таблицы увеличена с 520 px до 1300 px (×2,5). Фактическая высота коротких списков остаётся по содержимому.
- Колонка **economy** убрана. Под именем дома и `level / variant` отображаются две строки: `buy / sell`, `level required`.
- В **01 · House Identity → Register House** все шесть полей расположены в одну вертикальную колонку.
- В Real Estate выпадающие списки имеют ширину содержимого с ограничением шириной доступного контейнера. Сохранены выпадающие списки публикации и размещения.
- Отступы: единый шаг 11 px между полями, 14 px вокруг блоков полей, 12 px между заголовком библиотеки и таблицей, 12 px после таблицы, без глобальных переопределений.

Операции регистрации, публикации, Studio Sync, Atlas Registry и исходные файлы не затронуты. После применения достаточно перезапустить Host Agent (если изменившиеся статики кэшируются) и обновить Asset Manager через Ctrl+F5; Studio-плагин не менялся.
