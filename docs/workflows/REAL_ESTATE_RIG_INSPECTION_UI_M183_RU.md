# M183 · Real Estate: риги при Inspect и порядок каталогов

## Что отображается

`Inspect` хранит **исходный** общий `house_armature` для каждого связанного меша.
Это не означает, что все эти кости попадут в Roblox. Начиная с M182,
отдельный Model Asset статичного меша без влияний (`influencedBones=[]`),
использующего `house_armature`, не содержит копий его костей.

Сводка и раскрываемый список в Control Center теперь показывают **кости,
ожидаемые при публикации**. Для статичной части указывается число общих
костей в исходном FBX, но их имена повторно не выводятся. Для `house`,
`door`, отдельных скелетов и реально взвешенных мешей кости остаются видны.

Это только представление данных на клиенте; контракт `publish_bones_for_mesh`
остаётся на стороне Python, а фактическое сохранение костей проверяет Studio Sync.
Ранее опубликованные Model Asset ID и их содержимое UI не изменяет.

## Расположение

В Real Estate `Registered Library → Houses` находится выше
`Central Atlas Registry → Uploaded Atlases`. Фильтры и обработчики остаются прежними.

## Проверка

После обновления страницы выбрать или загрузить FBX `house_level5_01`:
`house` показывает свои сокеты, `door` — свои, статичные `col_mesh`,
`restoration`, `structures_01`, `window_frames_glass` — 0 костей при
публикации. На этапе Inspect это прогноз текущего контракта, не
подтверждение того, что конкретный Asset ID уже перепубликован.
