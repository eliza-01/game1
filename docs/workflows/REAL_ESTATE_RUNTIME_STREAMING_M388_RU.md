# M388 · Real Estate в общем Runtime Streaming

## Зона ответственности

- Авторский `place/game1.rbxl` и сохранённые Plot-привязки **не изменяются**.
- Исходный `place/game1_runtime_source.rbxlx` используется только для проверки и создания отдельной резервной копии.
- В Runtime Draft каждый визуальный MeshPart выбранного дома заменяется невидимым Part с **тем же Referent, CFrame, Size, именем, Bone/Attachment/Weld и коллизионными свойствами**. `rig_carrier`, серверные сокеты, модели двери и Collision Blueprint сохраняются.
- Источники Client FULL — авторитетные Mesh Asset ID из проверенного Studio Place. Они не публикуются и не подбираются клиентом.
- Общий `LocationWorldStreamer` рассчитывает FULL / House LOD1 / UNLOADED и отдельные расстояния MeshPart. Шаг дистанций — 1 секунда; операции разделяют один общий лимит. Полная геометрия FULL создаётся локально по запросу через `InsertService:CreateMeshPartAsync` и уничтожается за пределами заданного диапазона. В случае ошибки загрузки клиент не создаёт ложный fallback.
- House LOD1 — **один опубликованный Model Asset на тип дома**, клонируемый клиентом из общего сервера-шаблона LOD Manager. В зоне LOD1 FULL отсутствует.
- Для типовых 39 Plot идентичные описания 16 MeshPart хранятся в манифесте **один раз на тип**. Каждое размещение передаёт только путь, Plot, pivot и scale. Нестандартная авторская геометрия отдельного Plot вызывает ошибку Preflight.

## Активация

1. В **Real Estate → House LOD1** зарегистрировать/опубликовать LOD1 при режиме `lod1`, либо выбрать `full` без LOD1.
2. Настроить дистанции отдельных частей в спойлерах MeshPart и сохранить профиль дома.
3. В **LOD Manager / Runtime Preparation** убедиться, что Real Estate отображается в таблице; выполнить новый Scan Place в этой сессии.
4. В Studio сохранить текущее авторское содержимое Place как **XML** `place/game1_runtime_source.rbxlx`.
5. Выполнить Preflight, проверить число скомпилированных домов и частей, затем нажать **Backup + Build Runtime draft**. Рядом отображается красное напоминание сохранить копию Place; ввод защитной фразы не нужен. Verified Backup выполняется автоматически.

## Ограничения и проверки перед DEV

- `publishAllowed=false` сохранён: он является явным ограничением существующего Runtime Builder. **Компиляция не равна разрешению DEV-публикации.** Публичная загрузка требует теста в Studio Play, включая клиентскую загрузку исходных Mesh Asset ID и ресурсные разрешения.
- При первом тесте проверить: воспроизведение всех материалов/ForceField, стекло 50/60 studs, перемещение и открытие двери, сокеты, Collider Parts, телепортацию, переходы FULL ↔ LOD1 ↔ UNLOADED, повторное приближение и мобильную память.
- Клиентские визуальные экземпляры физически удаляются, но Roblox может оставлять mesh/texture **данные в движковом кеше**. Полное освобождение GPU/RAM нельзя гарантировать программно.
- Любое неоднозначное размещение, неполный профиль, неподдерживаемый коллизионный MeshPart, несовпадение авторского pivot или неверная геометрия между Plot блокируют Preflight вместо повреждения Runtime.
