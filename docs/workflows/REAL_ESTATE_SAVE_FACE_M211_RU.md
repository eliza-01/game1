# M211 · Real Estate Register / Save и глаза во время атаки

## Исправления

1. **New house**: `realEstateRender` не обращается к `publicationJob.status`, когда нет выбранного дома и задания публикации. Раньше optional chaining на двух отсутствующих `slug` приводил к ложному совпадению `undefined === undefined`.
2. **Register / Save**: сообщение серверной валидации HTTP 400 остаётся под кнопкой сохранения (`role=alert`), а при открытии другой формы сбрасывается. Это не скрывает настоящие ошибки выбора файлов, идентичности и миграции.
3. **Старые незаполненные части**: изменение цены/настроек существующего дома не обязано регистрировать отсутствующий исторический atlas-binding у неизменённой визуальной части. При создании нового дома и добавлении новой части атлас по-прежнему обязателен. Никаких `estate:`/`mesh:house` ссылок не возвращается.
4. **Глаза в бою**: Presenter обновляет мировые anchored MeshPart глаза **после** `AttackUpperBodyComposer` (`PostSimulation`, а не оба модуля в `PreSimulation`). Существующие лицевые клипы и настройки не изменяются.

## Ограничения и проверка

Сервер отвечает HTTP 400 и при иных ошибках (не найден оригинальный FBX, недопустимый atlas variant, смена идентичности дома). М211 не маскирует такие ошибки: точный текст теперь виден в форме. Если ошибка повторится, приложить **текст блока Register / Save**, а не только статус 400 из консоли.

Проверить в Roblox Studio Play на human_male/female: стоя, бег с атакой, поворот головы во время атаки, эмоции и мигание, смена персонажа. Статические тесты не заменяют Play-проверку.

`bounce` и `destructible` не изменены.
