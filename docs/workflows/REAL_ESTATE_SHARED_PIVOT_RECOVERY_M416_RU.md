# M416 · Real Estate: общий pivot и восстановление одной публикации

- `rig_carrier` определяет единственный канонический pivot дома.
- Визуальный MeshPart и его опубликованная Model должны использовать этот же pivot.
  Геометрический центр отдельной части не является её pivot.
- Отдельный статический FBX без `house_armature` допускается только если
  импортированная геометрия **уже** находится в авторской системе координат
  дома. `StudioRealEstatePartPlacement.AlignOrigin` проверяет структурный
  контракт и устанавливает общий pivot без переноса геометрии. Сравнивать
  `MeshPart.Position` с сохранённым `centerInPivot` нельзя: последний является
  центром авторского bounding box, а не доказательством положения pivot.
  Поэтому разница в десятки studs между этими величинами сама по себе не
  является ошибкой. Автоматический перенос по AABB запрещён.
- `MeshPart.PivotOffset` устанавливает канонический pivot, не изменяя `CFrame`
  или вершинную геометрию. Кости, сокеты и двери не переносим.
- `restore_house_part.py` восстанавливает одну опубликованную версию из
  указанной проектной SQLite-копии. Требуются ожидаемый текущий и целевой
  исторический Model Asset ID. Перед изменением создаётся отдельный SQLite
  backup; история публикаций и другие части дома не изменяются.
- Восстановление авторского реестра **не меняет** Roblox Studio Workspace.
  После успешного восстановления требуется `Sync entire house` на копии Place.
  Прежде чем сохранять Place, проверить положение стен на двух проблемных
  участках и сохранить авторский `.rbxlx`.
- Если исходный FBX или предыдущая SQLite-копия отсутствуют либо хэш
  отличается, автоматическое восстановление запрещается.

## M417 · Устранение ложного отказа по центру статического MeshPart

- Ошибка `imported mesh centre is ... studs` устранена: Roblox `MeshPart.Position`
  больше не сравнивается с Blender `centerInPivot` как с одинаковыми величинами.
- Публикация без скелета по-прежнему требует подтверждённого authoredPlacement v3,
  ровно один BasePart и отсутствие Bone. Все три pivot (house / MeshPart / Model)
  совпадают через PivotOffset, без изменения CFrame и без переноса геометрии.
- Изменение размеров FBX допустимо: размеры старой авторской части не должны
  запрещать публикацию изменённой геометрии. Некорректные размеры запрещены.
- Проверить реальное расположение геометрии после Sync можно только в Studio;
  наличие одинаковых pivot не доказывает совпадения вершин с прежней формой.
