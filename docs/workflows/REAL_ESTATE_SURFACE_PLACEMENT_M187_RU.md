# M187 · Габариты публикуемой поверхности при Sync House

## Причина

После публикации level5 с общим скелетом Sync останавливался на `col_mesh`
с ошибкой `published mesh dimensions differ from authored FBX`.
Это не ошибка разделения скелета. Inspect сохранял `mesh.bound_box`, который
в Blender включает свободные вершины и концы рёбер без граней. Эти элементы
не входят в поверхность опубликованного Roblox MeshPart.

Проверены реально опубликованные ассеты через `AssetService:LoadAssetAsync`:

| Часть | Ширина в прежних метаданных | Ширина Roblox / поверхности FBX |
|---|---:|---:|
| col_mesh | 67.738102 | 37.827457 |
| restoration | 67.313309 | 37.013084 |

У structures_01 также расходился размер по глубине: 15.805943 против
11.300152. Расчёт по вершинам граней воспроизводит фактические размеры
и центры опубликованных частей.

## Изменение

`real_estate_part_placement.inspect_placements` использует только вершины,
на которые ссылаются полигоны. Геометрия, веса, FBX и масштабы не меняются.
Меш без поверхностных граней отклоняется с явной ошибкой. Контракт
`authoredPlacement` v2 и проверка размеров в Studio сохраняются.

У текущей записи `house_level5_01` повторно измерен зарегистрированный FBX.
Перед обновлением проверены хеш файла, состав частей, кости, связи и веса.
Изменено только `skeleton_json.authoredPlacement`; остальные поля строки,
включая revision, исходные хеши, текстуры и опубликованные ID, сохранены.
Обновление сначала проверено на копии SQLite, включая повторный запуск без
изменений. Перед применением создана резервная копия в
`.control-center/backups/real_estate_before_surface_bounds_<UTC>.db`.
Манифест Real Estate пересоздан из БД.

Новые импорты сразу получают исправленные размеры. Другие существующие
записи автоматически не переписывались. Для старой записи с таким же
расхождением нужно заново измерить её зарегистрированный источник с учётом
независимых ревизий мешей; ослаблять допуск проверки размеров не следует.

## Подтверждение в Studio

Повторный Full Sync level5 завершился успешно:

- 6 Model Assets проверены;
- 11 костей, отсутствующих сокетов нет;
- 5 текстур применены;
- проверены/восстановлены размещения 5 частей;
- шаблон обновлён в `ServerStorage.real_estate.house_level5_01.model.house_level5_01`.

Публикация в Roblox повторно не выполнялась. Существующий
`Workspace.Houses.house_level5_01` не содержит MeshPart, поэтому плагин
пропустил обновление этой пустой копии с предупреждением об отсутствии
основного меша house. Она не удалялась и не заменялась автоматически.

Добавлены поведенческие тесты на свободные вершины/рёбра, отсутствие граней
и измеренные габариты level5. Проверки раздела домов: 202 теста, успешно.

## Восстановление метаданных

При необходимости вернуть только прежний `skeleton_json` строки
`house_level5_01` из резервной SQLite-копии в транзакции, предварительно
проверив текущую ревизию и source hash, затем пересоздать манифест. Не
заменять всю рабочую БД, если после копии появились другие изменения.
