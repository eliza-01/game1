# M200 · Уточнение модального окна удаления общих ассетов

Основа: M199. Область изменения: только интерфейс подтверждения удаления для Real Estate и Location Assets. Backend, режимы `preserve`/`all`, токен проверки зависимостей, физические файлы и Roblox Asset ID не меняются.

## Название действия

- Режим `preserve`, когда есть зависимости: **Delete house · keep shared assets** / **Delete location asset · keep shared assets**. Если зависимостей нет, просто **Delete house** / **Delete location asset**.
- Режим `all`, когда есть зависимости: **Delete all (N registrations)**, где N — число удаляемых регистраций из серверного плана. Ручное подтверждение slug обязательно, как в M199.

## Группировка зависимостей

`plan.relations` группируется по составному идентификатору **owner + ownerPart** (оригинальный владелец и часть, откуда взята общая текстура). Для Location Assets без `ownerPart` используется поле `texture`. Один источник показывается одной секцией; внутри — список всех зависимых моделей и частей, число частей и число уникальных регистраций. Если `plan.nodes` содержит опубликованный Image Asset ID источника, он отображается под его названием; отсутствующие ID не подменяются придуманными значениями.

Группировка исключительно визуальная: исходный план, SHA-256 token и набор удаляемых объектов сохраняются без изменений. Имена помещаются в DOM через `textContent`.

## Проверки

`system/verify/shared_asset_retirement_ui_m199.js`: несколько частей переиспользуют один источник, отдельное отображение другого источника, атрибут Image Asset ID, обе категории, отсутствие зависимостей, обновление названия при выборе режима, защита подтверждения каскада и сохранение token. Версии JS/CSS подняты до `v=2` для обновления кеша браузера.
