# M308 — Weapons: модель и атласы по общему контракту Location Assets

## Область изменений
Только Control Center → Weapons / Arrow assets и общие Atlas Registry / Source Review, которые уже используются Location Assets и Real Estate. Боевые Luau-контроллеры, физика, Fire Tuner, геометрия, Atlas ID и сохранённые модели не переписываются. База данных мигрирует только после явного действия пользователя.

## Почему точки разрешений отсутствовали
В диагностическом реестре есть опубликованные старые оружейные текстуры без активных `texture_atlas_bindings`. Связанный компонент ранее показывал точки лишь для уже прикреплённых вариантов, а его опция `allowUpload=false` отключала публикацию из Weapons.

## Путь ранее опубликованной текстуры
1. Открой зарегистрированное оружие. Старые Image ID отображаются как *legacy-точки* без записи в базу данных. При неподходящем имени появляется предупреждение с ожидаемым `<atlas_key>_<width>x<height>_atlas.png`.
2. Нажми legacy-точку, затем подтверди **Index existing Image ID**; либо нажми общую кнопку **Index existing weapon images**. Registry проверяет наличие исходника, фактический SHA256, опубликованный SHA256 и числовой Image ID. **Никакой Open Cloud и Sync Studio.** При невозможности проверить исходник в статусе отображается причина отказа. Дамп проекта не содержит исходные изображения; для индексации они должны присутствовать локально.
3. После индексации точки выводятся из `texture_atlas_consumer_options`. Опубликованные разрешения той же `atlas_key` становятся доступны в той же полосе точек; нажатие новой градации явно подключает и выбирает её. Это **не** запускает Studio Sync.
4. Если исторических текстур несколько, они подключаются как варианты, но активная градация не угадывается; выбери её вручную. Если исторический Image ID единственный, допускается установка той же самой опубликованной текстуры в новую централизованную привязку — без изменения игрового изображения.

## Новый атлас, замена и перепубликация
- **Upload new atlas** использует общий для Location Assets `AtlasSourceReview`, показывает *Old / New preview* и заранее сообщает, будет ли создан новый вариант или заменён Image ID действующего.
- Название со старым форматом явно обозначается как legacy, с показом ожидаемого стандартизированного файла. Исходник на диске не переименовывается. При изменении семейства отдельно предупреждаем, что получится **новый** atlas key, а не ревизия ранее привязанного.
- Для замены общей опубликованной градации требуется флажок подтверждения, потому что новый Roblox Image ID затронет всех использующих её потребителей. Старые Image ID остаются в истории.
- Обновлённая привязка помечается `pending_studio_sync`; затем **Sync Studio** выполняется отдельно. Ошибки экспорта реестров выводятся, а не скрываются.
- Кнопка **Connect existing atlas** ищет все опубликованные атласы центрального каталога. Это касается и стрел: оружие и стрелы используют один `AtlasRegistry`.

## Модель
- `Publish Model` выполняет `create_model_asset` только для ещё не опубликованного FBX, либо `update_model_asset` с прежним Model ID только при изменении SHA256. Для неизменённого FBX публикация не запускается.
- Публикация модели никогда не публикует текстуру «заодно» из нового интерфейса: вызов API явно ставит `includeLegacyTextures=false`. Старый API-путь сохранён только для обратной совместимости со старыми клиентами.
- **Sync Studio** остаётся отдельной кнопкой. При модели + атласе нужно сначала завершить явные операции публикации, затем синхронизировать.

## Тестирование и ограничения
- `system/verify/test_m308_weapon_location_atlas_parity.py`: реальные SQLite и PNG, ложные ответы Open Cloud, проверка сохранения Image ID, вариантов, истории замены, статусов синхронизации и неизменённого FBX.
- `node system/verify/weapon_atlas_ui_m308.js`: точки, семейные разрешения, legacy-предупреждение, возможность Upload и отсутствие побочных вызовов при рендеринге.
- Конкретную публикацию в Roblox Open Cloud, наличие полных исходных PNG/JPEG на пользовательском компьютере и реальные изменения в Studio необходимо проверить вручную. Тесты их не эмулируют полностью.
