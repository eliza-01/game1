Теперь понял, что тебе нужно. У тебя не просто меш, который следует за костью, а полноценный объект со своим скелетом, и этот скелет должен перемещаться вместе с объектом.

Сейчас на примере фонаря у тебя:
- house_armature → outside_lantern_01_socket — кость на доме, которая задаёт точку крепления.
- lantern_01 — меш фонаря.
- lantern_01_armature → light_01_socket — собственный скелет фонаря с костью для света.
Правильное решение: перемещать к сокету не только меш, а весь риг фонаря. При этом кость дома должна оставаться на доме, а light_01_socket должна перемещаться вместе с фонарём и сохранять своё положение относительно его геометрии.
