# Character UI · art direction and Figma handoff

## Design source

Figma file/page/frame URLs: **not provided**. Do not invent them.

## Direction (proposal for approval)

- Original, readable fantasy-MMORPG UI: restrained aged-metal/wood/stone accents where appropriate, clear contrast, dense but orderly item slots, no excessive decoration.
- Treat classic Lineage-style interfaces as **high-level references** for information hierarchy and mood only. No tracing, ripped assets, copied frames or trademarks.
- Produce a component-level design (inventory panel, weapon region, slot grid, slot states) and a reference screenshot at the target resolution.

## Asset policy

- **Roblox-native:** structure, text, grid, hit targets, scrolling and real state.
- **Figma/custom images:** decorated frame segments, corners, stylized backgrounds, icons and textures.
- Export scale-dependent ornaments as 9-slice-ready art when appropriate. Keep source editable in Figma (or record the original art file), and preserve transparent exports with sufficient resolution.
- Track `component → source Figma node/file → export file → Roblox image asset ID → intended usage`. IDs are blank until uploaded/verified.
- A Figma-to-Studio import plugin is optional; test on one frame and verify native editability, scaling, reimport behavior and script preservation before adoption.

## Required review evidence

Reference Figma frame, Roblox Play screenshot(s) at agreed viewport, sample data shown and observed deviations. Record `not_run` for viewports without evidence.

## Art questions

Exact palette, typography, ornament density, transparency, animation, iconography, target reference images and Figma location require owner approval.
