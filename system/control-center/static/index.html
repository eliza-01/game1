runtime animation playback · stat scaling

animation speed

playback speed is derived from gameplay stats here, not authored per animation clip. the rule is direct: playback % = stat / units per 1%. a runtime debug override can still temporarily replace the calculated value during Play.

shared scalingone rule applies to every matching animation state for that character or monster.
animation speed scaling

gameplay stat → playback %

each animation block is configured independently. Gameplay stat selects the runtime stat; Stat units for +1% playback controls its conversion to animation speed. Example: value 2 means every 2 stat points add 1% playback.
