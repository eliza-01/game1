01 · scan and register

character animation folder

scan any folder containing studio-exported .rbxm/.rbxmx. the selected character prefix is optional, so human_female_hands_idle and hands_idle resolve identically. files that do not match a rule can be assigned manually after the scan.

filename rules
human_female_hands_idle.rbxm → hands / idle human_female_hands_attack_01.rbxm → hands / attack / 01 human_female_1hs_attack_02.rbxm → 1hs / attack / 02 human_female_bow_aim.rbxm → bow / aim human_female_idle.rbxm → base / idle Atk02_1HS_FFighter.rbxm → 1hs / attack / 02
pattern: [character_]context_slot[_variant]. context is base, hands, 1hs, 2hs or bow. unassigned files can be bound manually without renaming them.
