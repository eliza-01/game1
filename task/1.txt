Иллюстрация интерфейса. Кнопка в настоящем Asset Manager активна при готовых ресурсах и подключённом Open Cloud.
Когда есть неопубликованные части, вкладка подсвечивается и пульсирует. После публикации всех ресурсов индикатор ожидания исчезает.

2. Атлас больше не блокируется
В Texture · atlas неопубликованный атлас отображается с понятным статусом Publish required.

Его можно открыть для публикации непосредственно через точку или Publish this atlas. Повторно выбирать исходный PNG/JPG не нужно.

3. Отображение процесса
При публикации видны последовательные этапы:

Публикация Atlas в Roblox Open Cloud.

Сохранение FBX-настроек при необходимости.

Публикация Model.

Подтверждение полученных Image ID и Model ID.

Во время запросов показывается вращающийся индикатор и название текущей операции — без вымышленных процентов.

Если Atlas уже успешно опубликован, а Model завершился ошибкой, следующая попытка не будет повторно публиковать атлас.

Перепубликация уже существующего общего Atlas не выполняется автоматически. Для неё сохраняется прежняя операция с предпросмотром и подтверждением.

4. Архитектура
Добавлены отдельные серверный сервис первой публикации и клиентская политика определения ожидающих ресурсов.

Используются существующие AtlasRegistry, механизм Open Cloud и независимая публикация Model. Studio Sync автоматически не запускается.
